# Installing the NestJS CLI (command-line interface)

Source: https://learn.nestjs.com/courses/591712/lectures/18346216

## Text

Installing Node.js:

https://www.nodejs.org

## Code

```
// Detect what version of Node is installed
node --version

// Install NestJS CLI -globally
npm i -g @nestjs/cli

// Check your Nest version (once installed)
nest --version

// TIP: Output all Nest commands
nest --help
```
