NestJS Fundamentals: สร้าง REST API ตั้งแต่ศูนย์ถึงโปรดักชัน

คอร์สนี้มี 66 บทและใช้โปรเจกต์เดียวต่อเนื่องตั้งแต่ต้นจนจบ เราจะสร้าง REST API สำหรับร้านกาแฟชื่อ iluvcoffee เริ่มจาก scaffold โปรเจกต์และทำ CRUD ก่อนต่อ PostgreSQL ด้วย Prisma จากนั้นค่อยจัดการ configuration, building blocks ของ Nest, เอกสาร Swagger และการทดสอบ ส่วนท้ายมีเส้นทางโบนัสสำหรับ MongoDB + Mongoose

เรียนครบแล้ว เราจะ: ออกแบบ API เป็น modules ตาม business domain, ตรวจสอบและแปลงข้อมูลขาเข้าด้วย DTO + ValidationPipe, ทำงานกับฐานข้อมูลทั้ง SQL และ NoSQL อย่างปลอดภัย (relations, transactions, indexes, migrations), แยก configuration ออกจากโค้ดด้วย ConfigModule และเขียนชุดทดสอบที่ยืนยันว่าระบบทำงานจริง

พื้นฐานที่ควรมี: เขียน TypeScript เบื้องต้นได้และพอเข้าใจ HTTP; ติดตั้ง Node.js และ Docker Desktop; มี REST client เช่น Insomnia หรือ Postman สำหรับยิงทดสอบ endpoint
