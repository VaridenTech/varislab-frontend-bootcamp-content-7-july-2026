รู้จัก Config Module

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายได้ว่าทำไม configuration ควรอยู่ใน environment ไม่ใช่ hardcode ในโค้ด
  • ติดตั้ง @nestjs/config และสร้างไฟล์ .env ที่ไม่ถูก track โดย git
  • เปลี่ยนค่าเชื่อมต่อฐานข้อมูลใน TypeOrmModule ให้อ่านจาก process.env

ทำไม configuration ต้องแยกออกจากโค้ด

แอปพลิเคชันมักรันในหลาย environment — development, staging, production — ซึ่งแต่ละที่ใช้ค่าต่างกัน เช่น host ของฐานข้อมูล, credentials หรือ API key แนวปฏิบัติมาตรฐานของชุมชน Node.js คือเก็บค่าเหล่านี้ไว้ใน environment variables ผ่าน object global process.env เพื่อให้โค้ดชุดเดียวรันได้ทุกที่โดยเปลี่ยนแค่ค่าแวดล้อม

@nestjs/config ช่วยให้เรื่องนี้ง่ายขึ้น: เมื่อเรียก ConfigModule.forRoot() มันจะอ่านไฟล์ .env ที่ root ของโปรเจกต์ แล้ว merge คู่ key/value เข้ากับ process.env ให้อัตโนมัติ

npm i @nestjs/config
// app.module.ts
import { ConfigModule } from '@nestjs/config';

@Module({
  imports: [
    ConfigModule.forRoot(),
    // ...imports อื่น ๆ
  ],
})
export class AppModule {}

สร้างไฟล์ .env และกันไม่ให้หลุดขึ้น git

สร้างไฟล์ .env ที่ root directory ของ iluvcoffee แล้วย้ายค่าเชื่อมต่อ PostgreSQL ที่เรา hardcode ไว้ตั้งแต่บทที่ 22 เข้ามาเก็บแทน

DATABASE_USER=postgres
DATABASE_PASSWORD=pass123
DATABASE_NAME=postgres
DATABASE_PORT=5432
DATABASE_HOST=localhost

ไฟล์ .env มี credentials จริง ห้าม commit ขึ้น repository เด็ดขาด — เพิ่มบรรทัด *.env ใน .gitignore ก่อนทำอย่างอื่น แล้วตรวจด้วย git status ว่าไฟล์ไม่โผล่ในรายการ

# .gitignore
# Env
*.env

ให้ TypeOrmModule อ่านค่าจาก process.env

จากนั้นแก้ AppModule ให้การตั้งค่า TypeORM ดึงจาก environment แทนค่า hardcode สังเกตเครื่องหมาย + หน้า process.env.DATABASE_PORT — environment variable เป็น string เสมอ จึงต้องแปลงเป็น number ก่อนส่งให้ TypeORM

TypeOrmModule.forRoot({
  type: 'postgres',
  host: process.env.DATABASE_HOST,
  port: +process.env.DATABASE_PORT,
  username: process.env.DATABASE_USER,
  password: process.env.DATABASE_PASSWORD,
  database: process.env.DATABASE_NAME,
  autoLoadEntities: true,
  synchronize: true,
}),

ย้ายค่าเชื่อมต่อฐานข้อมูลเข้า .env

ติดตั้ง @nestjs/config, สร้าง .env พร้อมค่าทั้งห้า, เพิ่ม *.env ใน .gitignore, import ConfigModule.forRoot() ใน AppModule แล้วเปลี่ยน options ของ TypeOrmModule.forRoot() ให้อ่านจาก process.env ทั้งหมด

npm i @nestjs/config # สร้างไฟล์ .env ที่ root แล้วเติมค่า DATABASE_* # เพิ่ม *.env ใน .gitignore npm run start:dev

ผลลัพธ์ที่คาดหวัง

แอป start ขึ้นและเชื่อมต่อ PostgreSQL ได้เหมือนเดิมทุกประการ ทั้งที่ในโค้ดไม่มี credentials ปรากฏอีกแล้ว และ git status ไม่แสดงไฟล์ .env ในรายการไฟล์ที่จะถูก commit

ตรวจว่าใช้งานได้จริง

  • GET /coffees ยังตอบข้อมูลจากฐานข้อมูลได้ปกติหลังย้ายค่าเข้า .env
  • ลองเปลี่ยน DATABASE_PASSWORD ใน .env เป็นค่าผิดแล้ว restart — แอปต้องต่อฐานข้อมูลไม่ได้ ยืนยันว่าค่าถูกอ่านจากไฟล์จริง (แก้กลับเมื่อทดสอบเสร็จ)
  • git status ไม่มี .env โผล่ในรายการ untracked/staged
  • port ที่ส่งให้ TypeORM เป็น number (มี + แปลงค่า) ไม่ใช่ string
