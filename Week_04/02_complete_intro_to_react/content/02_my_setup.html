Node.js

คุณต้องติดตั้ง Node.js สักเวอร์ชัน และควรเป็นเวอร์ชันหลัง v20.16 ฉันเขียนหลักสูตรนี้ด้วยเวอร์ชัน 20.16 แต่ก็น่าจะรองรับอนาคตได้ดีพอสมควร

ฉันใช้ fnm จัดการเวอร์ชัน Node.js ของฉัน (คล้ายกับ nvm)

ฉัน คิดว่า หลักสูตรนี้น่าจะทำงานได้กับเวอร์ชันล่าสุดของ bun หรือ deno แต่ยังไม่ได้ทดสอบ โปรดระวังหากตัดสินใจเลือกเส้นทางนี้

คำถามพบบ่อยเกี่ยวกับเครื่องมือ

คุณใช้เครื่องมืออะไรบ้าง?

  • Visual Studio Code – ฉันเคยทำงานที่ Microsoft ในทีม VS Code จึงไม่น่าแปลกใจที่ฉันจะใช้มันในหลักสูตรนี้ เราจะใช้ extension สองสามตัวด้วย ซึ่งฉันจะบอกเมื่อถึงตอนนั้น
  • Firefox – ฉันอยากให้มีสิ่งอื่นนอกเหนือจาก Chromium อยู่ด้วย จึงสนับสนุน Firefox เท่าที่ทำได้ จะใช้เบราว์เซอร์ใดก็ได้ เพราะในหลักสูตรนี้ไม่สำคัญ
  • Terminal.app – ฉันเคยใช้ iTerm2 และ Hyper แต่สุดท้ายก็ชอบความเร็วของ Terminal เริ่มต้น

คุณใช้ <font/theme/extension> อะไร?

  • Visual Studio Code
    • Dark+ Theme – ติดตั้งมาเป็นค่าเริ่มต้น แต่ตอนนี้ไม่ใช่ธีมเริ่มต้นแล้ว ฉันชินกับมันมากจนเปลี่ยนไม่ได้
    • MonoLisa font – ฉันชอบฟอนต์และมองมันทั้งวัน จึงยอมจ่ายเงินได้ ฉันเปิดใช้ ligatures อยู่ นั่นจึงเป็นเหตุผลที่คุณอาจเห็น glyph แปลก ๆ หากต้องการ ligatures แต่ไม่อยากจ่าย บทความ ligature ที่ลิงก์ไว้มีตัวเลือกบางตัว ฉันชอบ Cascadia Code ของ Microsoft
    • vscode-icons – ไอคอนสวย ๆ มากมายสำหรับ VS Code และใช้ฟรี
  • Terminal
    • zsh – ปัจจุบันมาพร้อม macOS แล้ว และฉันขี้เกียจมากเกินกว่าจะเปลี่ยนกลับไป bash
    • Dracula theme – ฉันชอบสีพาสเทล ถ้า Dark+ ไม่ฝังลึกอยู่ในสายเลือด ฉันก็คงใช้มันใน VS Code ด้วย
    • Starship Prompt – prompt ที่เจ๋งและสวยงาม อีกทั้งยังบอกด้วยว่าคุณอยู่ในโปรเจกต์ประเภทใด ซึ่งบางครั้งก็มีประโยชน์
    • CaskaydiaCove Nerd Font – ทำงานร่วมกับ Starship prompt เพื่อให้คุณมีโลโก้ JS และ glyph พิเศษทั้งหมด ฟอนต์นี้พัฒนามาจาก Cascadia Code
