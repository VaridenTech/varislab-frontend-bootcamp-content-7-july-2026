บทเรียน 35 · Wrap Up

ยินดีด้วย! ก้าวต่อไปของคุณ

Congrats

ยินดีด้วย!! คุณทำได้!

นี่เป็นเนื้อหาจำนวนมากที่ต้องรับมือ ดังนั้นขอชื่นชมที่คุณเรียนจนจบ หวังว่ามันสนุก และอาจทำให้คุณสนับสนุนร้านพิซซ่าในท้องถิ่นไปด้วย!

ตอนนี้คุณพร้อมเต็มที่สำหรับการเขียน React อย่างมืออาชีพ ทุกอย่างที่เรียนที่นี่คือ 95%+ ของสิ่งที่คุณต้องใช้เพื่อเขียน React ในบริษัทเทคโนโลยีใด ๆ ส่วนอีก 5% คือสิ่งที่ฉันจะสอนใน Intermediate React v6 ซึ่งเกี่ยวกับ server-side React และเทคนิค performance ขั้นสูงมากกว่า แต่สำหรับตอนนี้ นี่คือเกือบทั้งหมดที่คุณต้องรู้!

แล้วจากนี้ควรทำอะไร?

  • Intermediate React v5 ยังเกี่ยวข้องมาก! เรียนหลักสูตรนี้เพื่อรู้เพิ่มเกี่ยวกับ Tailwind, server-side rendering, hooks เพิ่มเติม, Redux และสิ่งเจ๋ง ๆ อีกมาก ฉันจะอัปเดตหน้านี้เมื่อ Intermediate React v6 ใหม่ออกมา
  • เรียนตามส่วนที่เหลือของ Frontend Masters React Learning Path
  • สร้างแอปของคุณเอง!! ฉันเน้นไม่พอว่า สำหรับแนวคิดแบบนี้ คุณต้องลงมือสร้างเอง เลือกไอเดียที่งี่เง่าที่สุดในหัวแล้วทำมัน ไม่มีอะไรแทนประสบการณ์ได้!
    • เว็บไซต์ e-commerce ขายถุงเท้าข้างเดียว เพื่อจับคู่ถุงเท้าที่ไม่มีคู่
    • text editor สำหรับ AI prompts
    • แอปเพลงที่ให้เพิ่มเพลงจาก Spotify, Apple Music และ Tidal ได้
    • client สำหรับอ่าน Thread, X และ Bluesky ในแอปเดียว
  • เรียน Next.js, Remix/React-Router (ในไม่ช้าสองอย่างนี้จะเป็นสิ่งเดียวกัน) หรือวิธีอื่นในการทำ React บน server
  • เรียน React + Tailwind

มีเส้นทางต่อจากนี้ได้มากมายและทุกทางสนุก! หวังว่าคุณจะชอบหลักสูตรนี้ และฉันหวังว่าจะได้สอนคุณอีกในเร็ว ๆ นี้!
