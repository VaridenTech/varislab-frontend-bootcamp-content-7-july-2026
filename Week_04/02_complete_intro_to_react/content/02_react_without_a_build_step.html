บทเรียน 02 · React แบบเรียบง่าย (No Frills React)

React โดยไม่ต้องมีขั้นตอน Build

React without a Build Step

บทเรียน React ส่วนใหญ่มักเริ่มด้วยการให้คุณรันคำสั่งสร้างโปรเจกต์สำเร็จรูป แล้วคุณก็ได้โฟลเดอร์ที่เต็มไปด้วยไฟล์ซึ่งไม่รู้ว่าแต่ละไฟล์มีไว้ทำอะไร เราจะไม่ทำแบบนั้น

บทนี้เราจะเขียน React ล้วน ๆ — ไม่มีขั้นตอน compile ไม่มี JSX ไม่มี Babel ไม่มี Webpack หรือ Vite มีเพียงไฟล์ HTML หนึ่งไฟล์กับไฟล์ JavaScript หนึ่งไฟล์ที่เบราว์เซอร์อ่านได้ตรง ๆ เป้าหมายคือให้คุณเห็นชัดว่าแก่นแท้ของ React มีอยู่แค่ไหน และเครื่องมือทั้งหลายที่เราจะเพิ่มเข้ามาในบทถัด ๆ ไปนั้นเข้ามาแก้ปัญหาอะไรให้เรา

สิ่งที่ต้องเตรียม

  • เบราว์เซอร์ — ตัวไหนก็ได้ที่คุณใช้อยู่ทุกวัน (Chrome, Edge, Firefox หรือ Safari)
  • โปรแกรมแก้ไขโค้ด — แนะนำ Visual Studio Code แต่ตัวใดที่คุณถนัดก็ใช้ได้
  • Node.js เวอร์ชัน 20 ขึ้นไป — บทนี้ยังไม่จำเป็นต้องมีก็ได้ แต่จะใช้เปิดเซิร์ฟเวอร์ทดสอบ และจะจำเป็นแน่นอนตั้งแต่บทเรื่อง npm เป็นต้นไป ตรวจสอบว่าติดตั้งแล้วหรือยังด้วยคำสั่ง node -v ใน terminal ถ้าขึ้นเป็นตัวเลขเวอร์ชันก็พร้อมแล้ว

ขั้นที่ 1: สร้างโปรเจกต์และไฟล์ HTML

สร้างโฟลเดอร์เปล่าสำหรับโปรเจกต์นี้ เราจะเรียกมันว่า pizza-app เพราะจะค่อย ๆ สร้างระบบสั่งพิซซ่าขึ้นมาด้วยกันตลอดทั้งหลักสูตร เปิดโฟลเดอร์นั้นด้วย editor ของคุณ แล้วสร้างไฟล์ index.html ตามนี้

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Pizza app</title>
  </head>

  <body>
    <div id="root">not rendered</div>
    <script src="https://unpkg.com/react@18.3.1/umd/react.development.js"></script>
    <script src="https://unpkg.com/react-dom@18.3.1/umd/react-dom.development.js"></script>
    <script src="./src/App.js"></script>
  </body>
</html>

มาไล่ดูทีละส่วนว่าแต่ละบรรทัดมีไว้ทำไม

  • โครงข้างบนเป็นเอกสาร HTML5 มาตรฐานทั่วไป ไม่มีอะไรพิเศษเกี่ยวกับ React เลย ถ้าส่วนนี้ยังไม่คุ้นตา แนะนำให้ทบทวนพื้นฐาน HTML สักเล็กน้อยก่อน
  • <div id="root"> คือจุดที่เราจะให้ React เข้ามาแสดงผลแอปทั้งหมด ข้อความ not rendered ข้างในเป็นตัวช่วยตรวจสอบ ถ้าเปิดหน้าเว็บแล้วยังเห็นข้อความนี้อยู่ แปลว่า React ยังทำงานไม่สำเร็จ ส่วนชื่อ root ไม่ได้บังคับ แต่เป็นธรรมเนียมที่ใช้กันทั่วไป
  • script สองตัวแรกคือตัว React เอง
    • ตัวแรกคือ React ซึ่งให้เราสร้างและอธิบาย component ทั้งหมด แต่มันแสดงผลด้วยตัวเองไม่ได้ มันเป็นเพียง API
    • ตัวที่สองคือ React DOM ซึ่งเป็นชั้นที่ทำหน้าที่แสดงผลจริง เนื่องจากเราแสดงผลลงในเบราว์เซอร์จึงใช้ React DOM ถ้าไปทำแอปมือถือก็เปลี่ยนเป็น React Native โดยที่ความรู้เรื่อง component ยังใช้ได้เหมือนเดิม — นี่คือความหมายของ “learn once, write anywhere” ที่พูดถึงในบทที่แล้ว คุณต้องมีทั้งสองตัว และลำดับของสองบรรทัดนี้ไม่สำคัญ
  • script ตัวสุดท้ายคือโค้ดของเราเอง มันต้องอยู่ หลัง สองตัวข้างบน ไม่อย่างนั้นโค้ดเราจะทำงานตอนที่ตัวแปร React ยังไม่มีอยู่ แล้วจะได้ error ว่า React is not defined

💡 การโหลด React จาก CDN แบบนี้เหมาะกับการเรียนรู้และการทดลองเท่านั้น ไฟล์ที่ลงท้ายด้วย .development.js มีข้อความเตือนและเครื่องมือ debug ครบถ้วน จึงมีขนาดใหญ่และช้ากว่าปกติมาก เว็บที่ใช้งานจริงจะติดตั้ง React ผ่าน npm และผ่านขั้นตอน build ซึ่งเราจะทำกันในบทถัด ๆ ไป

ขั้นที่ 2: เขียน React ตัวแรก

สร้างโฟลเดอร์ชื่อ src และสร้างไฟล์ App.js ไว้ข้างในนั้น แล้วใส่โค้ดนี้ลงไป

const App = () => {
  return React.createElement(
    "div",
    {},
    React.createElement("h1", {}, "Pixel Perfect Pizzas")
  );
};

const container = document.getElementById("root");
const root = ReactDOM.createRoot(container);
root.render(React.createElement(App));

เท่านี้คือแอป React ที่เรียบง่ายที่สุดเท่าที่จะเป็นไปได้แล้ว

ขั้นที่ 3: เปิดดูผลลัพธ์

คุณจะเปิดไฟล์ index.html ด้วยเบราว์เซอร์ตรง ๆ ก็ได้ แต่แนะนำให้เปิดผ่านเซิร์ฟเวอร์เล็ก ๆ มากกว่า เพราะการเปิดไฟล์ตรง ๆ (โปรโตคอล file://) จะติดข้อจำกัดหลายอย่างเมื่อโปรเจกต์โตขึ้น ถ้าคุณมี Node.js อยู่แล้ว ให้รันคำสั่งนี้ในโฟลเดอร์โปรเจกต์

npx serve

แล้วเปิดที่อยู่ที่ terminal แสดงขึ้นมา (โดยปกติคือ http://localhost:3000) คุณควรเห็นข้อความ Pixel Perfect Pizzas เป็นหัวข้อใหญ่บนหน้าเว็บ ถ้ายังเห็นคำว่า not rendered อยู่ ให้เปิด Console ในเครื่องมือนักพัฒนาของเบราว์เซอร์ (กด F12) เพื่อดูข้อความ error

🔍 ปัญหาที่พบบ่อย — React is not defined: ลำดับของ script tag สลับกัน หรือ CDN โหลดไม่สำเร็จ · Cannot read properties of null ที่บรรทัด createRoot: ค่า id ของ div ไม่ตรงกับที่เขียนใน getElementById · หน้าเว็บว่างเปล่าไปเลย: ตรวจสอบว่า path ./src/App.js ถูกต้องและชื่อไฟล์สะกดตรงกันทั้งตัวพิมพ์เล็กพิมพ์ใหญ่

โค้ดที่เพิ่งเขียนทำงานอย่างไร

  • สิ่งแรกที่เราทำคือสร้าง component ของเราเองชื่อ App แก่นของ React คือการสร้าง component เล็ก ๆ แล้วนำมาประกอบกันเป็น component ที่ใหญ่ขึ้นเรื่อย ๆ
  • component มีสองแบบ คือ function component กับ class component สิ่งที่เราเขียนคือ function component ซึ่งเป็นแบบมาตรฐานที่ใช้กันในปัจจุบัน (เราจะได้เห็น class component ในบทเรื่อง Error Boundaries)
  • function component ต้อง คืนค่าเป็นสิ่งที่อธิบายหน้าตาของ UI ออกมา ซึ่งก็คือสิ่งที่ React.createElement สร้างขึ้น
  • ฟังก์ชันของ component ต้อง ทำงานเร็ว เพราะมันจะถูกเรียกซ้ำบ่อยมากทุกครั้งที่ข้อมูลเปลี่ยน ถือเป็น hot code path
  • ภายในฟังก์ชันนี้ห้ามไปแก้ไข state ใด ๆ ที่อยู่ข้างนอก พูดในเชิงฟังก์ชันคือมันต้องเป็น pure function เพราะคุณไม่มีทางรู้ว่า React จะเรียกมันเมื่อไหร่หรือกี่ครั้ง
  • React.createElement สร้าง instance ของ component ขึ้นมาหนึ่งตัว ถ้าคุณส่ง string เข้าไป มันจะสร้าง DOM tag ตาม string นั้น เราจึงใช้ "div" และ "h1" ได้ตรง ๆ และถ้าใส่ "x-custom-date-picker" มันก็จะสร้างออกมาให้เช่นกัน (แปลว่าใช้ web component ร่วมได้)
  • object ว่าง {} ซึ่งเป็น argument ตัวที่สอง (จะใส่ null แทนก็ได้) คือ attribute ที่เราส่งให้ tag หรือ component นั้น อะไรที่ใส่ตรงนี้จะถูกส่งต่อไปยัง element เช่น id หรือ style
  • argument ตัวที่สามเป็นต้นไปคือ “ลูก” ของ element นั้น จะเป็นข้อความ หรือเป็น element ที่สร้างจาก React.createElement อีกทีก็ได้ นี่คือวิธีที่เราซ้อน element เข้าไปเป็นชั้น ๆ
  • ฝั่งการแสดงผล เราใช้ document.getElementById ดึง div ที่มีอยู่แล้วในไฟล์ HTML ออกมา แล้วส่ง element นั้น (ที่เราตั้งชื่อว่า container) เข้า ReactDOM.createRoot เพื่อบอก React ว่าให้แสดงผลแอปตรงจุดนี้
  • สังเกตว่าเราส่ง React.createElement(App) เข้า root.render ไม่ใช่ส่ง App ตรง ๆ เพราะเราต้องการ instance ของ App มาแสดงผล เปรียบเทียบง่าย ๆ ว่า App คือ “รุ่นรถ” เช่น Honda Civic ซึ่งเป็นสายรถทั้งสายที่มีตัวเลือกมากมาย ส่วน instance คือ “รถหนึ่งคัน” ที่ถูกผลิตออกมาจริง ๆ จากรุ่นนั้น

ReactDOM.createRoot เป็น API ที่เข้ามาแทนของเดิมตั้งแต่ React 18 ส่วน ReactDOM.render แบบเก่ายังพอใช้ได้แต่ถูกเลิกใช้แล้ว และจะทำให้แอปทำงานในโหมด “legacy” ซึ่งไม่ได้ใช้ความสามารถใหม่ ๆ ที่มาพร้อม React 18 และ 19 หากคุณเจอโค้ดที่ใช้ ReactDOM.render ให้รู้ไว้ว่านั่นคือโค้ดยุคก่อนหน้า

📁 เทียบกับเฉลยได้ — โค้ดที่เสร็จแล้วของบทนี้อยู่ในโฟลเดอร์ 01_without_build_sample/ ซึ่งวางอยู่ระดับเดียวกับโฟลเดอร์ content/ ที่เก็บบทเรียนเหล่านี้ แนะนำให้พิมพ์เองให้จบก่อนแล้วค่อยเปิดเทียบ ถ้าติดตรงไหนจริง ๆ ค่อยแอบดู

ลองทำเอง

ก่อนไปบทถัดไป ลองแก้โค้ดของคุณตามโจทย์เหล่านี้ดู การพิมพ์เองและเจอ error เองคือส่วนที่ทำให้จำได้จริง

  1. เพิ่ม h2 ที่มีคำโปรยของร้านเข้าไปใต้ h1 ภายใน div เดียวกัน (คำใบ้: เพิ่ม argument ตัวที่สี่ให้ createElement ของ div)
  2. ใส่สีให้หัวข้อโดยส่ง attribute ผ่าน argument ตัวที่สอง เช่น { style: { color: "crimson" } }
  3. สร้าง component ใหม่ชื่อ Pizza ที่คืนค่าเป็น div ซึ่งมีชื่อพิซซ่าและคำอธิบายอยู่ข้างใน แล้วเรียกใช้มันภายใน App ด้วย React.createElement(Pizza)
  4. ลองย้าย <script src="./src/App.js"> ไปไว้ ก่อน script ของ React ดูว่าเกิด error อะไรขึ้น แล้วย้ายกลับที่เดิม การได้เห็น error ด้วยตาตัวเองจะช่วยให้คุณแก้ปัญหาเดียวกันได้เร็วขึ้นในอนาคต

สรุป

  • React ใช้งานได้โดยไม่ต้องมีเครื่องมือ build ใด ๆ เลย มีแค่ script สองตัวกับ JavaScript ธรรมดา
  • ทุกอย่างใน React สุดท้ายแล้วคือการเรียก React.createElement เพื่ออธิบายว่าหน้าจอควรมีหน้าตาแบบไหน
  • ReactDOM.createRoot(container).render(...) คือสะพานเชื่อมระหว่างโลกของ React กับ DOM จริงในเบราว์เซอร์
  • เขียนแบบนี้จริง ๆ แล้วเยิ่นเย้อมาก ลองนึกภาพหน้าเว็บที่มี element ซ้อนกันสิบชั้น — ความน่ารำคาญนี้แหละคือเหตุผลที่ JSX ถือกำเนิดขึ้น และเป็นสิ่งที่เราจะไปเรียนกันหลังจากติดตั้งเครื่องมือครบแล้ว
