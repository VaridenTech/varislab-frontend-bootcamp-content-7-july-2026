React Compiler: ตัวช่วย optimize อัตโนมัติ

React Compiler

เราแทบไม่ได้พูดถึง performance hacks ของ React เลย แต่มีอยู่บ้าง โดยทั่วไป React ในสถานะ “unoptimized” ก็เร็วเพียงพออยู่แล้ว และการเพิ่ม hacks เหล่านี้อาจลดเวลาได้หนึ่ง millisecond ตรงนั้นตรงนี้ แต่โดยรวมไม่คุ้ม เว้นแต่จะได้ผลลัพธ์มาก เพราะมันทำให้เขียนโค้ดยากขึ้น

โดยเฉพาะเรากำลังพูดถึง useMemo และ useCallback เครื่องมือสองตัวนี้ให้คุณควบคุมว่า React จะ re-render แอปเมื่อไร หากคุณ render spreadsheet มหึมาที่ไม่เปลี่ยนบ่อยแต่ parent ของมันเปลี่ยน คุณใช้ useMemo เพื่อบอกว่า “เฮ้ สิ่งนี้ไม่จำเป็นต้อง re-render เว้นแต่เงื่อนไขนี้จะจริง” ซึ่งช่วยได้จริงเมื่อเป็นสิ่งใหญ่แบบนี้ คอร์สนี้ไม่ได้สอนสองตัวนี้เป็นเรื่องหลักด้วยซ้ำ เพราะใช้ไม่บ่อย และ developers ใหม่บางคนมักเผลออยากใช้มันตลอดเวลา มันจะทำให้ภายหลังเข้าใจยากว่าทำไมบางอย่าง render และบางอย่างไม่ render และทำให้หา bugs ยากขึ้น

เข้าสู่ React Compiler (เดิมชื่อ React Forget) ทีม React ที่ Facebook จะทำ optimizations เหล่านี้ให้คุณ มันจะตรวจพบว่า “เฮ้ component นี้ไม่ควรเปลี่ยนเลย เดี๋ยวใส่ useMemo ให้เอง” ข้อดีคือได้ performance มาฟรีโดย developer ไม่ต้องคิดเลย มันค่อนข้าง conservative ในการทำ จึงควรทำงานได้ราบรื่น

หากคุณเจอกรณีที่มันกำลัง memoize บางอย่างแต่คุณไม่ต้องการ ให้ใส่ "use no memo"; ไว้บนสุดของ file แล้ว React Compiler จะข้าม file นั้น

มารัน checker กับแอปกัน

npx react-compiler-healthcheck@beta

แอปของเราพร้อมแล้ว! คุณสามารถรันสิ่งนี้กับ codebase ของคุณเองเพื่อดูว่ามันใช้ได้หรือไม่

ไปติดตั้ง plugin กัน

# also prone to change as they're rapidly iterating on this
npm i -D babel-plugin-react-compiler@beta --force

ทีนี้เพิ่มสิ่งนี้ใน vite.config.ts

// replace react()
react({
  babel: {
    plugins: [
      [
        "babel-plugin-react-compiler",
        {
          target: "19",
        },
      ],
    ],
  },
}),

ตอนนี้รันแอป! หากทุกอย่างถูกต้อง คุณจะสังเกตเห็น ไม่มีอะไร หน้าตาจะไม่ต่างเดิมเลย แต่เปิด React dev tools แล้วดู components คุณน่าจะเห็น components จำนวนมากมี “Memo ✨” ต่อท้าย นี่คือ components ที่ React Compiler สามารถ optimize ให้อัตโนมัติ

และเท่านั้นเอง! เมื่อเวลาผ่านไปสิ่งนี้จะดีขึ้นมาก ทีม React บอกว่าปลอดภัยที่จะลองกับ codebase วันนี้ ดังนั้นคุณอาจลองดูว่ามันใช้ได้กับคุณหรือไม่ และทีมงานก็เปิดรับ feedback บน GitHub repo ของโปรเจกต์อยู่
