Components

เมื่อทำสิ่งนั้นแล้ว มาย้ายโค้ดออกจาก script tag บน DOM ไปยังไฟล์ script ของตัวเองกัน (เป็นแนวทางปฏิบัติที่ดี)

แก้ไขโค้ดใน App.js ให้เป็นดังนี้:

const Pizza = () => {
  return React.createElement("div", {}, [
    React.createElement("h1", {}, "The Pepperoni Pizza"),
    React.createElement("p", {}, "Mozzarella Cheese, Pepperoni"),
  ]);
};

const App = () => {
  return React.createElement("div", {}, [
    React.createElement("h1", {}, "Pixel Perfect Pizzas"),
    React.createElement(Pizza),
    React.createElement(Pizza),
    React.createElement(Pizza),
  ]);
};

const container = document.getElementById("root");
const root = ReactDOM.createRoot(container);
root.render(React.createElement(App));

🚨 คุณจะเห็นคำเตือนใน console ของเบราว์เซอร์ว่า Warning: Each child in a list should have a unique "key" prop. คำเตือนสำหรับนักพัฒนาของ React พยายามช่วยให้โค้ดของคุณทำงานเร็วขึ้น โดยพื้นฐาน React จะพยายามติดตาม component ที่สลับลำดับกัน ในรายการ มันทำเช่นนั้นโดยให้คุณกำหนด key เฉพาะที่ติดตามได้ หากเห็นว่าสองสิ่งสลับตำแหน่งกัน มันจะย้าย component แทนที่จะ render ใหม่

หมายเหตุผู้แปล: คำเตือนนี้เป็นเรื่องปกติของบทนี้ ไม่ใช่ว่าคุณทำผิด มันจะติดอยู่ใน console ไปจนถึงบทที่ 9 ที่เราเปลี่ยนมาใช้ JSX แล้วเขียน child เรียงต่อกันตรง ๆ โดยไม่ต้องใส่ array ครอบ คำเตือนก็จะหายไปเอง · ที่เราคง array ไว้ตรงนี้เพราะอยากให้เห็นชัด ๆ ว่า createElement รับ child หลายตัวได้อย่างไร (ถ้าอยากลองให้คำเตือนหายตั้งแต่ตอนนี้ ให้ส่ง child เป็น argument เรียงกันแทน array คือ createElement("div", {}, ลูกคนที่หนึ่ง, ลูกคนที่สอง)) · ประเด็นที่อยากให้ติดตัวไปคือ ให้แยกให้ออกระหว่างคำเตือนที่ "รู้ที่มาแล้วและตั้งใจปล่อยไว้" กับคำเตือนที่ยังไม่รู้ที่มา — อย่างหลังต้องหยุดอ่านทุกครั้ง เพราะนิสัยกวาดตาข้าม console แดง ๆ คือต้นทางของบั๊กที่หายากที่สุด

  • หากต้องการให้ element มี child หลายตัว เพียงส่ง array ของ element เข้าไป
  • เราสร้าง component ใหม่ตัวที่สอง คือ component Pizza component นี้แทนพิซซ่าหนึ่งถาด เมื่อคุณมีแนวคิดที่แยกจากกันและแสดงด้วย markup ก็ควรแยกมันเป็น component เช่นที่เราทำที่นี่
  • เพราะเรามี component Pizza ใหม่ เราจึงใช้มันได้หลายครั้ง! เพียงเรียก React.createElement หลายครั้ง
  • ใน createElement parameter สองตัวสุดท้ายเป็น optional เนื่องจาก Pizza ไม่มี props หรือ children (มันอาจมีได้ แต่เรายังไม่ได้ทำให้มันใช้) เราจึงละไว้ได้

โอเค ตอนนี้เรามีพิซซ่าหลายถาดได้ แต่ยังไม่ใช่ component ที่มีประโยชน์นัก เพราะพิซซ่าทุกถาดไม่ใช่พิซซ่าเปปเปอโรนี มาทำให้ซับซ้อนขึ้นอีกนิด

const Pizza = (props) => {
  return React.createElement("div", {}, [
    React.createElement("h1", {}, props.name),
    React.createElement("p", {}, props.description),
  ]);
};

const App = () => {
  return React.createElement("div", {}, [
    React.createElement("h1", {}, "Pixel Perfect Pizzas"),
    React.createElement(Pizza, {
      name: "The Pepperoni Pizza",
      description: "Mozzarella Cheese, Pepperoni",
    }),
    React.createElement(Pizza, {
      name: "The Hawaiian Pizza",
      description: "Sliced Ham, Pineapple, Mozzarella Cheese",
    }),
    React.createElement(Pizza, {
      name: "The Big Meat Pizza",
      description: "Bacon, Pepperoni, Italian Sausage, Chorizo Sausage",
    }),
  ]);
};

const container = document.getElementById("root");
const root = ReactDOM.createRoot(container);
root.render(React.createElement(App));

ตอนนี้เรามี component ที่ยืดหยุ่นกว่าเดิมและรับ props จาก parent ได้ Props คือ variable ที่ parent (App) ส่งให้ children (instance ของ Pizza) ตอนนี้แต่ละอันจึงแตกต่างกันได้! และมีประโยชน์กว่าเดิมมาก เพราะ component Pizza นี้แทนได้ไม่ใช่แค่พิซซ่าเปปเปอโรนี แต่แทนพิซซ่าใดก็ได้ นี่คือพลังของ React! เราสร้าง component หลายตัวที่นำกลับมาใช้ได้ แล้วใช้ component เหล่านี้สร้าง component ที่ใหญ่ขึ้น ซึ่งจะรวมกันเป็น component ที่ใหญ่กว่าอีก นี่คือวิธีสร้างแอป React!
