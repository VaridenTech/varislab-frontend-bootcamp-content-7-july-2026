Git

Git เป็นส่วนสำคัญของทุกโปรเจกต์ และน่าจะเป็นสิ่งที่หลายคนคุ้นเคยอยู่แล้ว ติดตั้ง Git หากยังไม่ได้ติดตั้ง จากนั้นเริ่มโปรเจกต์ของคุณเป็น git repo ด้วย git init ที่ root ของโปรเจกต์ (VSCode และเครื่องมืออีกหลายตัวก็ทำสิ่งนี้ได้เช่นกัน)

หากยังไม่ได้ทำ ให้สร้าง .gitignore ที่ root ของโปรเจกต์เพื่อ ignore สิ่งที่เราไม่ต้องการ commit ใส่สิ่งนี้ลงไปได้เลย:

node_modules
dist/
.env
.DS_Store
coverage/
.vscode/

วิธีนี้จะทำให้สิ่งเหล่านี้ไม่ถูกเพิ่มเข้า repo ของเรา Git ยังมีเรื่องให้เรียนอีกมาก ทั้ง branch, merge, rebase และการทำงานร่วมกับคนอื่นผ่าน pull request ซึ่งอยู่นอกขอบเขตของคอร์สนี้ แต่แค่ init, add, commit และ .gitignore ก็เพียงพอกับทุกอย่างที่เราจะทำต่อจากนี้แล้ว
