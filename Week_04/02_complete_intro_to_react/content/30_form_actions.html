Form Actions ใน React 19

Form Actions

โอเค มาอัปเกรดแอปของเราเป็น React 19 กันจริง ๆ

🚨 โปรดใส่ใจตรงนี้ เพราะคุณต้องหาว่าควรติดตั้ง React เวอร์ชันใด

ตรวจสอบเวอร์ชัน React ที่เผยแพร่บน npm ได้ด้วยคำสั่ง npm view react dist-tags หาก React 19 ยังเป็น canary/rc/next (ทั้งสามหมายถึงอย่างเดียวกัน) คุณสามารถรัน npm i react@rc react-dom@rc คุณจะเห็น warnings มากมายเกี่ยวกับเวอร์ชันไม่ตรงกันใน command-line ซึ่งไม่เป็นไรเลย

หาก React 19 เป็น latest แล้ว ให้รัน npm install react@19 react-dom@19 แล้วทำตามคำแนะนำนี้ ระวังให้มากเพราะสิ่งต่าง ๆ อาจเปลี่ยนไปแล้ว!!

มาคุยเรื่อง form actions กัน web interfaces จำนวนมากคือการจัดการ form inputs ดังนั้นทีม React จึงตัดสินใจทำให้เรื่องนี้ง่ายขึ้น จริง ๆ คล้ายสิ่งที่เราทำไปแล้ว เพียงมี boilerplate น้อยกว่า เปิด contact.lazy.jsx แล้วปรับหน้านี้ให้ใช้ form action

mutationFn: function (formData) { // change to formData
  // remove e.preventDefault
  // remove formData constructor
  return postContact(
    formData.get("name"),
    formData.get("email"),
    formData.get("message"),
  );
},

// change onSubmit to action
<form action={mutation.mutate}>

เท่านั้นเอง! มันเป็น convenience function ที่ทำให้จัดการ submits ได้ง่ายขึ้น ไม่มีอะไรผิดกับวิธีเดิมของเรา และมันจะยังทำงานเหมือนเดิมต่อไป

มาแปลง order.lazy.jsx ด้วย

// extract submission function from form
function addToCart() {
  setCart([...cart, { pizza: selectedPizza, size: pizzaSize, price }]);
}
// update to action
<form action={addToCart}>[…]</form>;

เหมือนด้านบน แต่ที่เจ๋งคือ หากใช้บางอย่างเช่น Next.js หรือ Remix เราใช้ directive 'use server' ตรงนี้และทำให้เป็น server action ได้ เช่น

function addToCart(formData) {
  "use server";
  sql(`INSERT INTO cart (user_id, pizza_type, size) VALUES ($1, $2)`, [
    formData.pizza_type,
    formData.size,
  ]);
}

เพราะมันอยู่บน server เราจึง insert เข้า database ได้อย่างปลอดภัย จากภายใน React component โดยตรง React/Next.js จะจัดการรายละเอียดทั้งหมดของการ execute บน server ให้ เจ๋งใช่ไหม? เราจะพูดถึงเพิ่มใน Intermediate React v6

มาทำอีก trick ที่เจ๋งกัน มี hook ใหม่ชื่อ useFormStatus ที่ให้ children components รู้ว่าตัวเองอยู่ใน form ที่กำลัง submit อยู่หรือไม่ โดยไม่ต้องส่งข้อมูลจำนวนมากไปมา

ใน contact.lazy.jsx

// at top
import { useFormStatus } from "react-dom"; // note react-dom, not react

// replace the two inputs
<ContactInput name="name" type="text" placeholder="Name" />
<ContactInput name="email" type="email" placeholder="Email" />

// at the bottom
function ContactInput(props) {
  const { pending } = useFormStatus();
  return (
    <input
      disabled={pending}
      name={props.name}
      type={props.type}
      placeholder={props.placeholder}
    />
  );
}
  • นี่เป็นตัวอย่างง่าย ๆ แต่ลองนึกภาพว่า inputs ของคุณซับซ้อนมาก มี design system, tool tips และ UI อื่น ๆ อีกมาก ซึ่งพบได้บ่อยใน React codebases ขนาดใหญ่ สิ่งนี้อาจมีประโยชน์มาก
  • อีกอย่าง หากฉันมี components เล็กมากอย่าง ContactInput ฉันก็จะใส่ไว้ใน file เดียวกันเหมือนที่ทำตรงนี้ มันเป็น pattern ที่มีประโยชน์ บางคนเคร่งครัดและยืนยันว่า one file, one component แต่ฉันไม่ใช่คนเคร่งแบบนั้น
  • เราไม่ได้ทำ button หรือ text area เพื่อความกระชับ แต่คุณทำได้
  • เพราะเรารันใน local pending state จะสั้นมาก แต่คุณจะสังเกตเห็น background กระพริบเป็นสีเทา นั่นคือ disabled state

และนั่นคือ form actions!
