npm

npm ไม่ได้ย่อมาจาก Node.js Package Manager แต่มันคือ package manager สำหรับ Node.js (พวกเขาไม่ได้บอกว่ามันย่อมาจากอะไร) และยังมีแพ็กเกจทั้งหมดในวงการ front end ด้วย npm มีเครื่องมือ command line ชื่อ npm เช่นกัน npm ให้คุณนำโค้ดจาก npm registry ซึ่งเป็นชุดของ open source module ที่ผู้คนเขียนไว้ เพื่อให้คุณใช้ในโปรเจกต์ได้ ทุกครั้งที่คุณรัน npm install react (ยังไม่ต้องทำตอนนี้) มันจะติดตั้ง React เวอร์ชันล่าสุดจาก registry

หากต้องการเริ่มโปรเจกต์ npm ให้รัน npm init -y ที่ root ของโปรเจกต์ หากยังไม่ได้ติดตั้ง Node.js โปรดไปติดตั้งด้วย เมื่อคุณรัน npm init มันจะถามคำถามหลายข้อ หากไม่รู้คำตอบหรือไม่สนใจ เพียงกด enter คุณแก้ไข package.json ภายหลังได้เสมอ วิธีนี้จะทำให้เราเริ่มติดตั้งและบันทึกแพ็กเกจได้

pnpm

อีกทางเลือกหนึ่งคือใช้ pnpm pnpm เป็น package manager ใหม่กว่าที่เลือก tradeoff ต่างจาก npm โดยเฉพาะวิธีเลือกจัดระเบียบ directory node_modules npm รักษาโครงสร้างไฟล์แบบแบนและติดตั้งทุกอย่างแบบแบน ขณะที่ pnpm ใช้ symlink มากกว่า ทั้งสองแบบใช้ได้ดี เลือกสิ่งที่เหมาะกับคุณได้เลย ฉันจะใช้ npm เพราะนักเรียนใช้งานได้ง่ายกว่า
