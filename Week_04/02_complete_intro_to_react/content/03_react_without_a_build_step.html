React โดยไม่ต้องมีขั้นตอน Build

React without a Build Step

เริ่มด้วยการเขียน React ล้วนกันเถอะ ไม่มีขั้นตอน compile ไม่มี JSX ไม่มี Babel ไม่มี Webpack หรือ Vite มีเพียง JavaScript บนหน้าเว็บ

เริ่มโปรเจกต์ของคุณ สร้างไดเรกทอรีโปรเจกต์ภายใน repository ฉันจะเรียกของฉันว่า padre-ginos เพราะเราจะสร้างระบบสั่งพิซซ่าตลอดหลักสูตรนี้ เปิดไดเรกทอรีนั้นใน VS Code หรือ editor ที่คุณเลือก สร้างไฟล์ index.html แล้วเพิ่ม markup นี้:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Padre Gino's</title>
  </head>

  <body>
    <div id="root">not rendered</div>
    <script src="https://unpkg.com/react@18.3.1/umd/react.development.js"></script>
    <script src="https://unpkg.com/react-dom@18.3.1/umd/react-dom.development.js"></script>
    <script src="./src/App.js"></script>
  </body>
</html>

มารันกัน เราอาจเปิดไฟล์นี้ตรง ๆ ในเบราว์เซอร์ก็ได้ แต่ฉันชอบใช้ serve รัน npx serve แล้วเปิด http://localhost:3000/ ในเบราว์เซอร์

  • นี่คือเอกสาร HTML5 ที่ค่อนข้างมาตรฐาน หากยังสับสน ฉันมีหลักสูตรอื่นชื่อ Intro to Web Dev ที่ช่วยคุณได้
  • เรากำลังเพิ่ม root div อีกสักครู่เราจะ render แอป React ของเราที่นี่ มันไม่จำเป็นต้องชื่อ root แต่เป็นธรรมเนียมที่ใช้กันทั่วไป
  • เรามี script tag สองตัว
    • ตัวแรกคือ library ของ React library นี้เป็นส่วนเชื่อมต่อสำหรับโต้ตอบกับ React; method ทั้งหมด (ยกเว้นหนึ่งตัว) จะใช้ผ่าน library นี้ แต่มันไม่มีความสามารถ render ตัวเอง เป็นเพียง API
    • library ตัวที่สองคือชั้นสำหรับ render เนื่องจากเรากำลัง render ไปยังเบราว์เซอร์ จึงใช้ React DOM มี React library อื่นด้วย เช่น React Native, React Unity, React Babylon.js, React Email, React Figma, React Blessed และอื่น ๆ คุณต้องมี script tag ทั้งสองตัว ลำดับไม่สำคัญ
  • script tag สุดท้ายคือที่ที่เราจะใส่โค้ดของเรา โดยปกติคุณจะไม่ทำแบบนี้ แต่ฉันอยากเริ่มให้เรียบง่ายที่สุด script tag นี้ต้องอยู่หลังอีกสองตัว

หากต้องการเพิ่ม CSS ตอนนี้ คลิกที่นี่เพื่อรับ stylesheet ของหลักสูตรนี้ สร้างไฟล์ชื่อ styles.css แล้ววางไฟล์ก่อนหน้าลงไป จากนั้นเพิ่ม link tag ในไฟล์ html ของคุณ <link rel="stylesheet" href="./style.css" /> เราจะเชื่อมไปยังไฟล์ CSS ที่อยู่ที่ /api/pubic/styles.css ในอีกเล็กน้อยของหลักสูตร แต่ก่อนหน้านั้น เราต้องตั้งค่าบางอย่างก่อน (ระหว่างบทเรียน Vite)

หมายเหตุผู้แปล: เพื่อให้ขั้นตอนนี้ทำงาน ให้ใช้ชื่อไฟล์ในเครื่องและค่า href ให้ตรงกันเป็น style.css และ path ที่ถูกต้องคือ /api/public/styles.css (ต้นฉบับสะกดเป็น pubic)

สร้างไดเรกทอรีใหม่ชื่อ src และไฟล์ใหม่ชื่อ App.js ในไดเรกทอรีนั้น แล้วใส่สิ่งนี้ลงไป

const App = () => {
  return React.createElement(
    "div",
    {},
    React.createElement("h1", {}, "Pixel Perfect Pizzas")
  );
};

const container = document.getElementById("root");
const root = ReactDOM.createRoot(container);
root.render(React.createElement(App));

นี่เป็นแอป React ที่เรียบง่ายที่สุดเท่าที่คุณสร้างได้

  • สิ่งแรกที่เราทำคือสร้าง component ของเราเอง คือ App แก่นของ React คือการสร้าง component แล้วนำ component เหล่านั้นมาสร้าง component เพิ่ม
  • component มีสองประเภท คือ function component และ class component นี่คือ function component เราจะได้เห็น class component ในไม่ช้า
  • function component ต้องคืนค่า markup (ซึ่งก็คือสิ่งที่ React.createElement สร้าง)
  • render function ของ component เหล่านี้ต้องเร็ว เพราะ function นี้จะถูกเรียกบ่อยมาก เป็น hot code path
  • ภายใน render function คุณไม่สามารถแก้ไข state ใด ๆ ได้ หากกล่าวในเชิง functional function นี้ต้องเป็น pure คุณไม่รู้ว่า function จะถูกเรียกอย่างไรหรือเมื่อใด จึงไม่สามารถแก้ไข ambient state ได้
  • React.createElement สร้างinstanceหนึ่งของ component บางตัว หากส่งstringเข้าไป มันจะสร้าง DOM tag จาก string นั้น เราใช้ h1 และ div tag เหล่านั้นจะถูกส่งออกไปยัง DOM หากเราใส่ x-custom-date-picker มันก็จะส่งออกเช่นกัน (จึงใช้ web components ได้ด้วย)
  • object ว่างตัวที่สอง (คุณจะใส่ null ก็ได้) คือ attributes ที่เราส่งให้ tag หรือ component สิ่งใดก็ตามที่เราใส่ในนี้จะถูกส่งออกไปยัง element (เช่น id หรือ style)
  • ก่อนอื่นเราใช้ document.getElementById เพื่อหยิบ div ที่มีอยู่จากเอกสาร HTML จากนั้นนำ element นั้น (ที่เราเรียกว่า container) ส่งเข้า ReactDOM.createRoot นี่คือวิธีบอก React ว่าเราต้องการให้มัน render แอปตรงไหน โปรดสังเกตว่าภายหลังเราสามารถเรียก root.render อีกครั้งเพื่อเปลี่ยนหน้าตาของ root ของแอป React (ฉันแทบไม่จำเป็นต้องทำเช่นนั้น)
  • สังเกตว่าเราใช้ React.createElement กับ App เป็น parameter ของ root.render เราต้องการinstanceของ App เพื่อ render ออกมา App คือ class ของ component และเราต้อง render instance หนึ่งของ class นั่นคือสิ่งที่ React.createElement ทำ: มันสร้าง instance ของ class ลองเปรียบเทียบว่า App ในฐานะclassของ component เหมือน Honda มีสายรถชื่อ Civic เป็นสายรถทั้งสายที่มีตัวเลือกและ parameter มากมาย instance ของ Civic คือรถหนึ่งคันที่เฉพาะเจาะจง เป็นตัวอย่างที่เป็นรูปธรรมของสายรถ Civic

ReactDOM.createRoot เป็น API ใหม่ตั้งแต่ React v18 ส่วน ReactDOM.render แบบเก่ายังใช้ได้อยู่ (และถูกเลิกใช้แล้ว) แต่จะ render แอปของคุณในโหมด “legacy” ซึ่งจะไม่ใช้ฟีเจอร์ใหม่สนุก ๆ ทั้งหมดที่มาพร้อม React v18
