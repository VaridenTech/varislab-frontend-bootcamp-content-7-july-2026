Intro

🚨 คุณไม่จำเป็นต้องดูหรืออ่านหลักสูตรเวอร์ชันก่อนหน้า นี่เป็นเพียงการปรับปรุงหลักสูตรครั้งที่เก้าเท่านั้น

สวัสดี และยินดีต้อนรับสู่ Complete Intro to React เวอร์ชัน 9 ในหลักสูตรนี้ คุณจะเริ่มจากไม่รู้อะไรเลยเกี่ยวกับ React ไปจนพร้อมทำงานได้ หลักสูตรนี้สอนแนวคิดแกนกลางทั้งหมดของ React โดยมุ่งให้เป็นประโยชน์ที่สุด คุณจะเรียน React ด้วยแนวทางจากหลักการพื้นฐาน เราจะเริ่มโดยไม่มีเครื่องมือ build หรือสิ่งทำนองนั้นเลย มีเพียง JavaScript ล้วนและ React จากนั้นเราจะค่อย ๆ เพิ่มเครื่องมืออย่าง Vite, JSX, ESLint, Prettier และอื่น ๆ เพื่อให้คุณเรียนรู้วิธีสร้าง stack ของตนเองตั้งแต่ต้น ฉันจะสอนเครื่องมือบางอย่างใน ecosystem การทดสอบ และสิ่งที่จะมาถึงใน React ด้วย

หลักสูตรนี้เหมาะกับใคร?

คุณนั่นเอง! หลักสูตรนี้เหมาะสำหรับทุกคนที่อยากเริ่มต้นใช้ React หรืออยากต่อยอดความเชี่ยวชาญ ไม่จำเป็นต้องมีประสบการณ์มาก่อน อย่างไรก็ตาม ฉันรับประกันว่าทุกคนที่สนใจ React จะได้เรียนรู้บางสิ่งจากที่นี่ หลักสูตรนี้อาจไม่ควรเป็นหลักสูตรเขียนโปรแกรมหรือ JavaScript แรกของคุณ แต่หากไม่ใช่ ก็เหมาะสำหรับทุกคน เราใช้ Node.js บ้างเพื่อรัน API เล็ก ๆ และสำหรับเครื่องมือ build แต่ไม่จำเป็นต้องมีประสบการณ์ Node.js จริงจัง ฉันจะให้คำสั่งที่จำเป็นในการรันไว้

ฉันคือใคร?

ฉันชื่อ Brian Holt และเขียน React มานานมาก ฉันส่งโค้ด React ชุดแรกของ Reddit ขึ้นใช้งานจริงในปี 2014

We shipped reddit's first production @reactjs code last week, our checkout process.https://t.co/KUInwsCmAF

— Brian Holt (@holtbt) July 28, 2014

ต่อมาฉันได้เขียน React ที่บริษัทใหญ่หลากหลายแห่ง และมันเป็นเครื่องมือหลักของฉันมานานกว่าทศวรรษแล้ว เรียกได้ว่ามันเป็นสิ่งที่กำหนดเส้นทางอาชีพของฉันเลย

ปัจจุบันฉันทำงานเป็น staff product manager ที่ Neon ทำงานเกี่ยวกับเครื่องมือสำหรับนักพัฒนาและประสบการณ์ของนักพัฒนา ฉันชอบทำเครื่องมือและประสบการณ์สำหรับนักพัฒนามาก จนสุดท้ายได้ทำงานด้านเครื่องมือและกลยุทธ์ ก่อนหน้า Neon ฉันเคยทำงานที่ Snowflake, Microsoft, LinkedIn, Netflix, Reddit และสตาร์ตอัปอื่น ๆ อีกบางแห่ง ฉันเคยทำมาทุกอย่างตั้งแต่ VP of product, dev rel ไปจนถึง staff engineering tech lead

ตอนที่ไม่ได้ทำงานหรือสอน คุณจะพบฉันใช้เวลาอยู่กับภรรยา ลูกชาย และลูกสาวที่กำลังจะลืมตาดูโลก! ฉันอาศัยอยู่ใน Seattle ตลอดหกปีที่ผ่านมา แต่ตอนนี้กำลังย้ายไป Sacramento เพื่อรับแสงแดดมากขึ้นและอยู่ใกล้หิมะที่ยอดเยี่ยมสำหรับเล่นสโนว์บอร์ดที่ Tahoe! 🏂 ฉันยังชอบ hazy IPA, Islay Scotch, ปั่นจักรยานทางไกล และเล่น Dota 2 แบบไม่เก่งนักด้วย

จะแจ้งปัญหาได้ที่ไหน

ฉันเขียนหลักสูตรเหล่านี้และพยายามไม่ให้มีข้อผิดพลาด แต่เมื่อสอนเนื้อหานานกว่าสิบชั่วโมง ข้อผิดพลาดย่อมหลีกเลี่ยงไม่ได้ ทั้งในไวยากรณ์ตรงนี้และในหลักสูตร อย่างไรก็ตาม ฉันและทีมที่ยอดเยี่ยมของ Frontend Masters กำลังแก้ไขข้อผิดพลาดอย่างต่อเนื่อง เพื่อให้ผู้ที่มาเรียนภายหลังได้รับเนื้อหาที่ดีที่สุด หากคุณพบข้อผิดพลาด เราอยากแก้ไขมัน วิธีที่ดีที่สุดคือ เปิด pull request หรือแจ้ง issue ใน GitHub repository แม้ว่าฉันยินดีเสมอที่จะพูดคุยและให้คำแนะนำผ่านโซเชียลมีเดีย แต่ฉันไม่สามารถเป็นฝ่ายสนับสนุนด้านเทคนิคให้ทุกคนได้ และหากคุณแจ้งบน GitHub ผู้ที่มาเรียนภายหลังก็ค้นหาคำตอบเดียวกับที่คุณได้รับใน Google ได้

repository ทำงานอย่างไร

คลาสนี้มี repository สองแห่ง: เว็บไซต์ที่คุณกำลังอยู่ และ โปรเจกต์ตัวอย่าง หากต้องการเตรียมพร้อม ให้ clone หรือ ดาวน์โหลด repository ของโปรเจกต์:

git clone https://github.com/btholt/citr-v9-project.git

ทุกขั้นตอนของโปรเจกต์นี้จะมีโฟลเดอร์ที่เป็นภาพรวมสถานะของโปรเจกต์ ณ ขั้นตอนนั้น หากคุณติดขัด อยากคัดลอกและวางโค้ดยาว ๆ ที่ไม่อยากพิมพ์ หรือแค่อยากดูโค้ด ณ จุดนั้น ก็ทำได้เลย! เป้าหมายหลักคือให้คุณเรียนรู้ ดังนั้นตราบใดที่คุณกำลังเรียนรู้ ก็ไม่มีการโกง!

รูปแบบการตั้งชื่อจะเป็น XX-<name of the lesson> เพื่อให้คุณพอเห็นลำดับและรู้ว่าขั้นตอนนั้นมาจากบทเรียนใด ในแต่ละ snapshot คุณต้องรัน npm install อีกครั้ง เพราะแต่ละอันเป็นสำเนาโปรเจกต์ทั้งชุดอีกชุดหนึ่ง

เราจะเริ่มจากศูนย์ แต่คุณต้องดาวน์โหลด repository ไว้ เพราะมีไดเรกทอรี api ที่จะใช้ในภายหลังของหลักสูตร

และขออีกเรื่องสุดท้าย! โปรดกดดาวให้ repository นี้ ช่วยให้คนค้นพบหลักสูตรได้ง่ายขึ้น และช่วยเยียวยาอีโก้อันเปราะบางของฉันด้วย
