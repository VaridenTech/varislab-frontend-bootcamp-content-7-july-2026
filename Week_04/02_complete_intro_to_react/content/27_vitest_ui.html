การใช้ Vitest UI

Vitest UI

อีกเครื่องมือสนุกที่ให้คุณใช้คือ Vitest UI มันให้คุณเห็นและจัดการ tests ทั้งหมดจาก web browser มาเพิ่มมันกัน

npm i -D @vitest/ui@^4.1.0

และใน package.json ของคุณ

// in scripts
"test:ui": "vitest --ui"

ตอนนี้จาก command line รัน npm run test:ui แล้วมันควรเปิด browser ของคุณพร้อม Vitest UI สะดวกมาก โดยเฉพาะที่ที่คุณต้อง run individual tests ซ้ำ ๆ และไม่มี VS Code extension module graph ก็เป็น visualization ที่เจ๋งด้วย
