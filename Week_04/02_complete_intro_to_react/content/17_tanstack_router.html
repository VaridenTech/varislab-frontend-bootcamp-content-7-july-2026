การทำ Routing ด้วย TanStack Router

TanStack Router

TanStack Router

ตอนนี้เราเดินทางมาถึงจุดที่อยากมีหลายหน้าในแอปแล้ว เราจึงต้องมีเครื่องมือ router สักอย่างเพื่อทำสิ่งนั้น เราอาจใช้ history API ของเบราว์เซอร์โดยตรงก็ได้ แต่มีหลายวิธีมากที่จะทำพลาด และเราก็มีไลบรารี React สำหรับ routing ที่ยอดเยี่ยมให้เลือกใช้มากมาย

ตามประวัติแล้ว ฉันสอน react-router ในคอร์สนี้ มันมีมานานและผ่านการทดสอบมาอย่างดี คอร์สนี้เกือบทุกเวอร์ชันใช้มัน (มีช่วงสั้น ๆ ที่ใช้ Reach Router แต่หลังจากนั้นก็ถูกรวมกลับเข้า React Router) มันเป็นเครื่องมือที่ยอดเยี่ยมและเป็นพื้นฐานของ Remix ซึ่งเป็น React framework แบบ full-stack ที่ยอดเยี่ยม Remix และ React Router กำลังรวมกัน และในที่สุดจะกลายเป็นสิ่งเดียวกัน หากอยากเรียนรู้เพิ่มเติมจากฉัน คอร์สเวอร์ชัน 8 ใช้ React Router

TanStack Router

วันนี้เราจะใช้ TanStack Router ซึ่งเป็น router ที่ยอดเยี่ยมอีกตัว เหตุใดจึงเปลี่ยน? มีสองเหตุผล:

  • นี่เป็นคอร์สที่เน้น client-side และ TanStack Router สร้างมาเพื่อ use case ฝั่ง client React Router และ Remix หันไปเน้นประสบการณ์ full-stack มากขึ้น (แม้ยังทำงานแบบ client-side อย่างเดียวได้)
  • ใน Intermediate React เราจะครอบคลุม use case แบบ full-stack มากขึ้น ซึ่งฉันจะใช้ Next.js เพื่อแสดง feature เหล่านั้น

สรุปคือ คุณมีตัวเลือกดี ๆ มากมาย ฉันชอบ TanStack Router และคิดว่ามันเป็นเครื่องมือที่ดีให้คุณเริ่มต้น มาลุยกัน

เริ่มจากติดตั้งมันก่อน

npm install @tanstack/react-router@1.65.0
npm install -D @tanstack/router-plugin@1.65.0 @tanstack/router-devtools@1.65.0

เราต้องติดตั้ง router แล้วจะใช้ทั้งเครื่องมือ generate code และ dev tools ของมัน (dev tools ใช้เฉพาะระหว่างพัฒนา จึงเป็น -D) มาเพิ่มมันใน vite.config.js ก่อน

// at top
import { TanStackRouterVite } from "@tanstack/router-plugin/vite";

// add before react() in plugins
plugins: [TanStackRouterVite(), react()],

TanStack Router ทำงานด้วย convention ที่อิงไฟล์ คุณสร้าง routes ตามรูปแบบเฉพาะ แล้ว TanStack Router จะเชื่อมทุกอย่างให้เอง โดยสร้างไฟล์ชื่อ routeTree.gen.ts แม้โปรเจกต์นี้จะไม่ใช่ TypeScript แต่การเป็น TypeScript ทำให้ VS Code อ่าน types จาก routes และช่วยด้วยคำแนะนำกับ error อัจฉริยะได้ ฉันแนะนำให้เพิ่มไฟล์นี้ใน .gitignore ด้วย เพราะมันจะถูก generate อัตโนมัติทุกครั้งที่ build เอาล่ะ ไปสร้างไฟล์ที่ต้องใช้กัน

สร้างไดเรกทอรี routes ในไดเรกทอรี src สร้างไฟล์ __root.jsx ในที่นั้น ไฟล์นี้จะเป็น template พื้นฐานสำหรับทุก route ส่วนใหญ่จะมาจาก App.jsx

import { useState } from "react";
import { createRootRoute, Outlet } from "@tanstack/react-router";
import { TanStackRouterDevtools } from "@tanstack/router-devtools";
import PizzaOfTheDay from "../PizzaOfTheDay";
import Header from "../Header";
import { CartContext } from "../contexts";

export const Route = createRootRoute({
  component: () => {
    const cartHook = useState([]);
    return (
      <>
        <CartContext.Provider value={cartHook}>
          <div>
            <Header />
            <Outlet />
            <PizzaOfTheDay />
          </div>
        </CartContext.Provider>
        <TanStackRouterDevtools />
      </>
    );
  },
});
  • เราเพิ่ม <Outlet/> แทน Order component ตอนนี้เราสลับ routes ใหม่เข้าตรงนั้นได้แล้ว! สังเกตว่า Header และ PizzaOfTheDay จะอยู่เสมอ
  • เราเพิ่ม dev tools ที่ยอดเยี่ยมของ TanStack เราจะดูมันอีกครู่หนึ่ง แต่มันอยู่มุมซ้ายล่าง คลิกมันได้เมื่อแอปโหลดแล้ว
  • <> และ </> ใช้เมื่ออยาก render sibling components สองตัว (context กับ dev tools ของเรา) แต่ไม่อยากเพิ่ม div สุ่ม ๆ React กำหนดให้ return top-level component ได้เพียงหนึ่งตัว และเราทำได้ด้วย <> กับ </>

เยี่ยมเลย ทีนี้ไปแก้ App.jsx

// add at top
// remove useState import from react import
import { RouterProvider, createRouter } from "@tanstack/react-router";
import { routeTree } from "./routeTree.gen";

const router = createRouter({ routeTree });

// replace App
const App = () => {
  return (
    <StrictMode>
      <RouterProvider router={router} />
    </StrictMode>
  );
};

นี่แค่นำ routeTree ที่ generate แล้วเข้ามาและใช้ในโปรเจกต์ ไฟล์นี้ควรใช้สำหรับ render ไฟล์เท่านั้น ส่วนอื่น ๆ น่าจะอยู่ใน __root.jsx

ย้าย Order.jsx จากไดเรกทอรีฐานเข้าไปใน routes หากระบบถาม ให้ตอบ yes เพื่อ update paths เปลี่ยนชื่อเป็น order.lazy.jsx แล้วแก้ให้เป็น route

// at top
import { createLazyFileRoute } from "@tanstack/react-router";

// make sure you modified the relative paths here – VS Code may have done this for you already
import { CartContext } from "../contexts";
import Cart from "../Cart";
import Pizza from "../Pizza";

export const Route = createLazyFileRoute("/order")({
  component: Order,
});

function Order() {
  // Order component code …
}
  • ตรงนี้เรากำลังสร้าง route ใหม่ เรากำหนด URL ของมันคือ /order และ component ที่จะ render คือ Order
  • เราทำให้มัน lazy ตอนนี้มันจะแยก code และ lazy-load route ให้เรา วิธีนี้ช่วยมากในแอปขนาดใหญ่ ในแอปเล็ก ๆ นี้มันอาจช้าลงจริง ๆ เพราะเพิ่ม 1KB ให้แอปไม่ได้ทำให้ช้า แต่การเดินทางไปกลับเพิ่มหนึ่งครั้งทำให้ช้า เมื่อทำ lazy loading โปรดวัดว่ามันช่วยหรือไม่ อย่างไรก็ดี นี่คือวิธีทำ

แค่นั้นเอง! เมื่อก่อนการ code split ยากมาก ในคลาสเก่า ๆ ของฉันเราต้องทำงานหนักกว่าจะได้ผล แต่ตอนนี้มีเพียงเท่านี้ เจ๋งมาก

มาเพิ่มหน้า home กัน! สร้างไฟล์ชื่อ index.lazy.jsx ในโฟลเดอร์ routes

import { createLazyFileRoute, Link } from "@tanstack/react-router";

export const Route = createLazyFileRoute("/")({
  component: Index,
});

function Index() {
  return (
    <div className="index">
      <div className="index-brand">
        <h1>Padre Gino's</h1>
        <p>Pizza & Art at a location near you</p>
      </div>
      <ul>
        <li>
          <Link to="/order">Order</Link>
        </li>
        <li>
          <Link to="/past">Past Orders</Link>
        </li>
      </ul>
    </div>
  );
}
  • ไม่มีอะไรใหม่ตรงนี้ ยกเว้นอาจเป็น links link components เหล่านี้ทำให้ TanStack Router ควบคุม browser history ได้ง่าย จึงควรใช้มัน

สุดท้ายแก้ Header เพื่อให้ link กลับหน้า home ได้

// at the top
import { Link } from "@tanstack/react-router";

// surround the logo with a link
<Link to={"/"}>
  <h1 className="logo">Padre Gino's Pizza</h1>
</Link>

ทั้งหมดนี้ควรทำงานแล้ว เปิดแอปแล้วดูว่ามันโหลดหรือไม่

  • สังเกตว่าจะมี flash เล็กน้อยก่อนโหลด นั่นคือการ lazy-load route หากเป็นแอปจริง เราคงสร้างประสบการณ์ loading ที่น่าพอใจกว่า ฉันขอทิ้งเป็นแบบฝึกหัดให้คุณทำ
  • มาคุยเรื่อง cart ไปหน้า order เพิ่มของลง cart หลายอย่าง แล้วกลับหน้า home สังเกตว่ายังมีของอยู่ใน cart! กลับหน้า order ก็ยังอยู่ เพราะ __root.jsx (ที่เก็บ cart state) ไม่เคยถูก un-render หากมันอยู่ใน Cart.jsx หรือ order.lazy.jsx มันจะหายไปทุกครั้งที่ navigate ออกไป เพราะเมื่อ component ถูก un-render มันจะสูญเสีย state ทั้งหมด นี่คือเหตุผลหนึ่งที่ Context ทรงพลังมาก
  • ลองดู dev tools ที่ render อยู่มุมซ้ายล่าง (ไม่ต้องห่วง มันจะถูกตัดออกอัตโนมัติใน production) คลิกเข้าไปสำรวจ มีของเจ๋ง ๆ ให้ใช้ฟรีมากมาย

คุณทำได้แล้ว! การทำ routing ง่ายแค่นี้เอง มันมาไกลมากจากยุคแรก ๆ ของ React
