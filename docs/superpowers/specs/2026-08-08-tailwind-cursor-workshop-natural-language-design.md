# Natural-language edit for the Tailwind + Cursor workshop

## Goal

Revise the written content in `Week_05_06/01_tailwind_cursor_workshop/content` so it sounds like a Thai instructor speaking naturally in class. The writing should be friendly, direct, and easy to follow without sounding generated or over-polished.

## Scope

- Review and edit all 17 HTML files: the workshop index and lessons 01–16.
- Edit learner-facing prose in headings, paragraphs, lists, blockquotes, captions, and navigation labels when needed.
- Preserve the lesson order, HTML structure, links, examples, exercises, and technical meaning.
- Do not edit `lesson.css`, images, or other non-prose assets.
- Do not rewrite source code, terminal commands, API names, filenames, CSS classes, route paths, or literal UI labels.

## Voice

- Use natural Thai that sounds like a teacher explaining the material in person.
- Keep common developer terms in English where Thai developers normally use them, including prompt, component, responsive, accessibility, refactor, layout, props, state, and Agent.
- Prefer short, concrete sentences and familiar transitions.
- Retain useful warmth and personality, but remove forced jokes, exaggerated claims, dramatic metaphors, artificial slogans, and repetitive rhetorical contrasts.
- Avoid literal English-to-Thai sentence patterns when a simpler Thai construction communicates the same idea.
- Do not make every paragraph follow the same rhythm or template.

## Editing approach

Use a conservative full pass. Read every learner-facing passage and revise only where wording is stiff, formulaic, overly dramatic, repetitive, or unnatural. Keep passages that already read naturally. This avoids both a superficial keyword cleanup and an unnecessary wholesale rewrite.

## Verification

- Confirm that every HTML file has been reviewed.
- Inspect the diff to ensure edits are limited to learner-facing language and intended consistency fixes.
- Check that HTML remains structurally valid enough for all local links and tags to be preserved.
- Scan for recurring AI-style phrasing and inconsistent spellings of common technical terms.
- Confirm that no code block, command, stylesheet, or image was unintentionally changed.
