# แบบทดสอบ React บทที่ 01–09

## เป้าหมาย

สร้างแบบทดสอบภาษาไทย 12 ข้อจากเนื้อหา `01_intro.html` ถึง `09_jsx.html` เพื่อวัดทั้งความเข้าใจแนวคิด React และการใช้เครื่องมือพื้นฐานที่ผู้เรียนพบในบทเหล่านี้

## รูปแบบไฟล์

- บันทึกผลลัพธ์ที่ `extra/react-intro-01-09-quiz.json`
- ใช้โครงสร้างเดียวกับ `extra/quiz-questions-sample.json`
- แต่ละข้อมี `prompt`, `choices`, `correctChoice` และ `explanation`
- ข้อที่ต้องอ่านโค้ดมี `body` เป็น HTML `<pre><code>...</code></pre>`
- แต่ละข้อมี 3 ตัวเลือก และ `correctChoice` นับตำแหน่งจาก 1

## การกระจายเนื้อหา

แบบทดสอบต้องครอบคลุมทั้งเก้าบท โดยให้น้ำหนักเพิ่มกับหัวข้อแกนหลัก:

- บท 01: React, declarative UI และ `UI = f(state)`
- บท 02–03: การ render โดยไม่ใช้ build step, component และ props
- บท 04–08: npm, formatting, ESLint, Git และ Vite
- บท 09: JSX, expression, props กับ TypeScript และนามสกุลไฟล์

รวม 12 ข้อ โดยบางบทแกนหลักมีมากกว่าหนึ่งข้อ แต่ไม่มีบทใดถูกละไว้

## หลักการเขียนคำถาม

- ใช้ภาษาไทยที่ชัดเจนและเหมาะกับผู้เริ่มต้น
- วัดความเข้าใจ ไม่ใช้รายละเอียดปลีกย่อยที่ต้องท่องจำโดยไม่จำเป็น
- ผสมคำถามเชิงแนวคิด คำสั่งเครื่องมือ และการอ่านโค้ด
- ตัวลวงต้องสมเหตุสมผล แต่ไม่กำกวมหรือหลอกด้วยถ้อยคำ
- คำอธิบายระบุเหตุผลของคำตอบอย่างกระชับและอิงเนื้อหาในบทเรียน

## การตรวจสอบ

- parse ไฟล์ด้วย JSON parser
- ยืนยันว่ามี 12 ข้อ
- ยืนยันว่าทุกข้อมี 3 ตัวเลือกและ `correctChoice` อยู่ในช่วง 1–3
- ตรวจด้วยตนเองว่าคำตอบและคำอธิบายสอดคล้องกับบทเรียนต้นทาง
