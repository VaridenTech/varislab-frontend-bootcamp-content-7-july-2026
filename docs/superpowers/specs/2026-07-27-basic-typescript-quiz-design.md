## ผลลัพธ์

- สร้างไฟล์ `Week_03/02_basic_typescript/content/quiz_01_to_07.md`
- มีคำถาม 15 ข้อ
- แต่ละข้อมีตัวเลือก A–D และมีคำตอบที่ถูกต้องเพียงหนึ่งข้อ
- ทุกข้อมีบรรทัดเฉลยและคำอธิบายภาษาไทย
- ใช้ Markdown และรูปแบบหัวข้อเดียวกับไฟล์ตัวอย่าง

## การกระจายเนื้อหา

- บทที่ 1–2: ความสัมพันธ์ระหว่าง JavaScript กับ TypeScript, ปัญหา Dynamic/Weak Typing และการตรวจไฟล์ JavaScript — 3 ข้อ
- บทที่ 3: Type Annotation, Literal/Union Type, Function, Array/Object และ Type Narrowing — 5 ข้อ
- บทที่ 4: การ Compile, `tsconfig.json`, Interface, Generics และ Utility Types — 4 ข้อ
- บทที่ 5: Workflow การย้ายโปรเจกต์ JavaScript มาเป็น TypeScript — 1 ข้อ
- บทที่ 6–7: Ecosystem, Type Declaration, Type Assertion, Runtime Validation และภาพรวม — 2 ข้อ

บทสรุปในบทที่ 7 ใช้เป็นกรอบตรวจว่าคำถามครอบคลุมผลการเรียนรู้ทั้งหมด ไม่จำเป็นต้องแยกเป็นคำถามท่องจำเฉพาะบท

## ระดับคำถาม

ใช้แนวทางสมดุล โดยผสมคำถามสามลักษณะ:

- ความเข้าใจแนวคิดและคำสั่งพื้นฐาน
- การอ่านโค้ดและระบุผลของ Type Checker
- การเลือกเครื่องมือหรือ Workflow ให้เหมาะกับสถานการณ์

ตัวลวงต้องสมเหตุสมผลแต่ไม่กำกวม ไม่ใช้ความรู้ที่อยู่นอกบทเรียนเป็นเงื่อนไขในการตอบ และกระจายตำแหน่งคำตอบที่ถูกต้องระหว่าง A–D

## การตรวจสอบ

- ตรวจว่ามี 15 ข้อและทุกข้อมี A–D ครบ
- ตรวจว่าทุกข้อมีเฉลยเพียงหนึ่งข้อ และเฉลยตรงกับคำอธิบาย
- ตรวจ Syntax ในตัวอย่าง TypeScript และคำสั่ง CLI
- ตรวจว่าคำถามทุกข้ออ้างอิงเนื้อหาในบทที่ 1–7
- ตรวจรูปแบบ Markdown เทียบกับไฟล์ตัวอย่าง
