บทเรียน 20 · ตะกร้าสินค้า (Cart)

ปุ่ม Add to Cart และ Mini Cart

Add to Cart & Mini Cart

บทที่แล้วเราสร้างเครื่องยนต์ของตะกร้าเสร็จแล้ว แต่ยังไม่มีใครได้ใช้มันเลย บทนี้เราจะต่อสายให้ครบวงจรแรก: กดปุ่ม Add To Cart บนหน้า Product → สินค้าเข้า store → modal เด้งยืนยัน → ตัวเลขบนไอคอนตะกร้าที่ Header ขยับตาม งานแบ่งเป็นสามชิ้น: modal ยืนยัน, การอัปเดตหน้า Product และ mini cart (badge) บน Header

AddToCartModalContent — modal ยืนยันการเพิ่มสินค้า

เวลาผู้ใช้กดเพิ่มสินค้า ต้องมี feedback ทันทีว่า "สำเร็จแล้วนะ" ไม่อย่างนั้นเขาจะกดซ้ำอีกสามรอบเพราะไม่แน่ใจ (แล้วได้ของ 4 ชิ้นโดยไม่ตั้งใจ) เราจะทำ modal ยืนยันโดยไม่เขียน modal ใหม่ — component Modal กลางที่สร้างไว้ตั้งแต่บทที่ 10 กับ Button จากบทที่ 09 รอเราหยิบมาประกอบอยู่แล้ว

สร้าง src/features/cart/components/AddToCartModalContent/AddToCartModalContent.tsx:

import React from "react";
import Button from "@/shared/components/Button/Button";
import Modal from "@/shared/components/Modal/Modal";

interface AddToCartModalContentProps {
  isOpen: boolean;
  onClose: () => void;
}

const AddToCartModalContent: React.FC<AddToCartModalContentProps> = ({
  isOpen,
  onClose,
}) => (
  <Modal isOpen={isOpen} onRequestClose={onClose}>
    <div className="text-center">
      <h3 className="fs-20 fw-bold mb-10">Product Added to Cart</h3>
      <p className="mb-20">
        The product has been successfully added to your cart!
      </p>
      <div className="inline-block">
        <Button onClick={onClose}>Close</Button>
      </div>
    </div>
  </Modal>
);

export default AddToCartModalContent;

จุดที่น่าสังเกต:

  • เป็นการ compose ล้วน ๆ — ไฟล์นี้ไม่รู้จัก react-modal เลยด้วยซ้ำ มันรับ isOpen/onClose แล้วส่งต่อให้ Modal กลาง (prop ฝั่ง Modal ชื่อ onRequestClose ตามธรรมเนียมของ react-modal) — เนื้อในเป็นแค่ข้อความกับปุ่ม Close นี่คือผลตอบแทนของการลงทุนสร้าง shared components ไว้ก่อนในบทที่ 9–10: feature ใหม่ประกอบเสร็จใน 20 กว่าบรรทัด
  • ไม่มี logic ตะกร้าอยู่ในนี้ — component นี้ไม่เรียก useCart ไม่รู้ว่าสินค้าอะไรถูกเพิ่ม มันเป็น "หน้าตา" เพียว ๆ ที่ถูกควบคุมจากพ่อ (หน้า Product) ผ่าน props สองตัว ทำให้ทดสอบง่ายและเอาไปใช้ที่อื่นได้ถ้าต้องการ
  • class ที่ใช้คือ utility กลางทั้งหมด — text-center, fs-20, mb-20 จาก _utilities.scss บทที่ 04 ไม่ต้องมี .module.scss ของตัวเอง

อัปเดตหน้า Product — ต่อปุ่มเข้ากับ store จริง

ย้อนไปบทที่ 18 เราจงใจปล่อยให้ handler ของปุ่ม Add To Cart บน ProductDetailInfo เป็นแค่ตัวหลอก เพราะตอนนั้นยังไม่มี store ให้เรียก ตอนนี้มีครบแล้ว เปิด src/pages/Product/Product.tsx แล้วอัปเกรดเป็นเวอร์ชันสมบูรณ์ สิ่งที่เปลี่ยนมี 4 จุด:

หนึ่ง — import เพิ่มสามรายการ: ดึง useState เข้ามาในบรรทัด import React เดิม และเพิ่ม import ของ modal กับ hook ตะกร้า:

import React, { useState } from "react";
// ...import เดิมจากบทที่ 18 คงอยู่ครบ...
import AddToCartModalContent from "@/features/cart/components/AddToCartModalContent/AddToCartModalContent";
import { useCart } from "@/features/cart/useCart";

สอง — state ของ modal และ hook ตะกร้า: บนหัว component เพิ่ม state คุมการเปิดปิด modal, ดึง addToCart จาก store และฟังก์ชันเปิด/ปิดสั้น ๆ สองตัว:

const [isModalOpen, setIsModalOpen] = useState(false);
// ...useParams และ useQuery เดิม...
const { addToCart } = useCart();

const onOpenModal = () => setIsModalOpen(true);
const onCloseModal = () => setIsModalOpen(false);

สาม — handler ตัวจริง: onAddToCart เลิกเป็นตัวหลอก มันแปลงข้อมูลสินค้าจาก API ให้เป็น CartItem แล้วส่งเข้า store จากนั้นเปิด modal:

const onAddToCart = () => {
  if (productDetail) {
    addToCart({
      id: productDetail.id,
      title: productDetail.title,
      price: productDetail.price,
      quantity: 1,
      image: productDetail.thumbnail,
      originalPrice: calculateOriginalPrice(
        productDetail.price,
        productDetail.discountPercentage,
      ),
    });
    onOpenModal();
  }
};

สี่ — วาง modal ใน JSX: ก่อนปิด <div> นอกสุด เพิ่มหนึ่งบรรทัด:

<AddToCartModalContent isOpen={isModalOpen} onClose={onCloseModal} />

รวมทุกจุดแล้ว Product.tsx ฉบับสมบูรณ์หน้าตาแบบนี้:

import React, { useState } from "react";
import ClipLoader from "react-spinners/ClipLoader";
import { useParams } from "react-router";
import { useQuery } from "@tanstack/react-query";
import ReviewSection from "./components/ReviewSection";
import CategoryBanner from "@/pages/Category/components/CategoryBanner/CategoryBanner";
import ProductImageGallery from "@/features/products/components/ProductImageGallery/ProductImageGallery";
import { calculateOriginalPrice } from "@/shared/utils/price.utils";
import ProductDetailInfo from "@/features/products/components/ProductDetailInfo/ProductDetailInfo";
import AddToCartModalContent from "@/features/cart/components/AddToCartModalContent/AddToCartModalContent";
import { useCart } from "@/features/cart/useCart";
import { productQueries } from "@/features/products/queries";
import ErrorMessage from "@/shared/components/ErrorMessage/ErrorMessage";

const Product: React.FC = () => {
  const [isModalOpen, setIsModalOpen] = useState(false);
  const { id } = useParams<{ id: string }>();
  const {
    data: productDetail,
    isLoading,
    isError,
  } = useQuery({
    ...productQueries.detail(id ?? ""),
    enabled: !!id,
  });
  const { addToCart } = useCart();

  const onOpenModal = () => setIsModalOpen(true);
  const onCloseModal = () => setIsModalOpen(false);

  const onAddToCart = () => {
    if (productDetail) {
      addToCart({
        id: productDetail.id,
        title: productDetail.title,
        price: productDetail.price,
        quantity: 1,
        image: productDetail.thumbnail,
        originalPrice: calculateOriginalPrice(
          productDetail.price,
          productDetail.discountPercentage,
        ),
      });
      onOpenModal();
    }
  };

  if (isLoading) {
    return (
      <div className="text-center mb-30">
        <ClipLoader
          size={40}
          aria-label="Loading Spinner"
          data-testid="loader"
        />
      </div>
    );
  }

  if (isError || !productDetail) {
    return (
      <div className="container">
        <ErrorMessage message="We couldn't load this product. Please try again." />
      </div>
    );
  }

  const {
    title,
    images,
    description,
    brand,
    reviews,
    rating,
    price,
    discountPercentage,
    sku,
    stock,
    availabilityStatus,
    shippingInformation,
    warrantyInformation,
  } = productDetail;
  const originalPrice = calculateOriginalPrice(price, discountPercentage);

  return (
    <div>
      <CategoryBanner name={title} />
      <section className="pt-60">
        <div className="container">
          <div className="flex mb-35">
            <div className="width-50">
              <div className="pr-10">
                <ProductImageGallery images={images} />
              </div>
            </div>
            <div className="width-50">
              <div className="pl-10">
                <ProductDetailInfo
                  title={title}
                  brand={brand}
                  rating={rating}
                  reviewsCount={reviews.length}
                  price={price}
                  originalPrice={originalPrice}
                  discountPercentage={discountPercentage}
                  description={description}
                  sku={sku}
                  stock={stock}
                  availabilityStatus={availabilityStatus}
                  shippingInfo={shippingInformation}
                  warrantyInfo={warrantyInformation}
                  onButtonClick={onAddToCart}
                />
              </div>
            </div>
          </div>
          <div className="pb-30">
            <h3 className="fs-24">Reviews</h3>
            <ReviewSection rating={rating} reviews={reviews} />
          </div>
        </div>
      </section>

      <AddToCartModalContent isOpen={isModalOpen} onClose={onCloseModal} />
    </div>
  );
};

export default Product;

เรื่องที่ควรหยุดคิดสักนิดใน handler นี้:

  • การแปลงร่างข้อมูลเกิดที่นี่ — API ให้ Product ก้อนใหญ่ แต่ store ต้องการ CartItem ที่เราออกแบบไว้บทที่แล้ว หน้า Product คือคนแปลง: thumbnail กลายเป็น image, quantity ตั้งเป็น 1 เสมอ (กดหนึ่งครั้ง = หนึ่งชิ้น และถ้ากดซ้ำ reducer จะรวมเข้าแถวเดิมให้เอง — เราจ่ายค่ากติกานี้ไว้แล้วใน ADD_TO_CART)
  • originalPrice คำนวณแล้วเก็บติดไปเลย — เราใช้ calculateOriginalPrice ตัวเดียวกับที่หน้านี้ใช้แสดงราคาก่อนลดอยู่แล้ว เก็บผลลัพธ์ลงตะกร้าไปด้วย เพื่อให้หน้า Cart โชว์ราคาเต็มกับยอด "You Save" ได้ในบทหน้าโดยไม่ต้องยิง API ถามราคาสินค้าซ้ำทีละตัว
  • ลำดับใน handler สื่อความหมาย — addToCart(...) ก่อน แล้วค่อย onOpenModal(): ยืนยันหลังจากของเข้าตะกร้าแล้วจริง ๆ ส่วน if (productDetail) กันกรณีที่ type บอกว่า data อาจยังไม่มา (ในทางปฏิบัติปุ่มยังไม่ render ถ้าข้อมูลไม่มา แต่ TypeScript ไม่รู้เรื่องนั้น)
  • useCart ใช้ได้เพราะบทที่แล้วเราเสียบ provider ไว้แล้ว — หน้า Product render อยู่ใต้ AppProviders ผ่าน router ดังนั้น CartContext หาเจอแน่นอน ถ้าคุณลืมแก้ providers.tsx ในบทที่ 19 บรรทัดนี้จะโยน error "useCart must be used within a CartProvider" ใส่หน้าคุณทันที — ยามที่เราตั้งไว้ทำงานแล้ว

CartSummary — mini cart บน Header

ผู้ใช้เพิ่มของแล้วก็จริง แต่พอปิด modal ไปก็ไม่เหลือร่องรอยอะไรบนจอว่าตะกร้ามีของ ธรรมเนียมของเว็บขายของคือไอคอนตะกร้ามุมขวาบนพร้อมตัวเลขจำนวนชิ้น สร้าง src/features/cart/components/CartSummary/CartSummary.tsx:

import React, { useMemo } from "react";
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome";
import { faCartShopping } from "@fortawesome/free-solid-svg-icons";
import styles from "./CartSummary.module.scss";
import { useCart } from "@/features/cart/useCart";

interface CartSummaryProps {
  onIconClick: () => void;
}

const CartSummary: React.FC<CartSummaryProps> = ({ onIconClick }) => {
  const { cart } = useCart();

  const totalItems = useMemo(
    () => cart.items.reduce((sum, item) => sum + item.quantity, 0),
    [cart.items],
  );

  return (
    <div className="relative" onClick={onIconClick}>
      <FontAwesomeIcon className="pointer fs-20" icon={faCartShopping} />
      {totalItems > 0 && (
        <span
          className={`${styles.cartCount} fs-12 fw-bold text-center`}
          aria-label="Cart item count"
        >
          {totalItems}
        </span>
      )}
    </div>
  );
};

export default CartSummary;

และไฟล์คู่กัน src/features/cart/components/CartSummary/CartSummary.module.scss:

@use "../../../../styles/variables";

.cartCount {
  position: absolute;
  top: -12px;
  right: -12px;
  background-color: variables.$red01;
  color: variables.$white;
  border-radius: 50%;
  padding: 3px 6px;
  min-width: 18px;
}

แกะทีละส่วน:

  • นับ "จำนวนชิ้น" ไม่ใช่ "จำนวนแถว" — reduce บวก quantity ของทุกแถวรวมกัน ถ้าตะกร้ามีสินค้าตัวเดียวจำนวน 3 ชิ้น badge ต้องโชว์ 3 ไม่ใช่ 1 (cart.items.length จะให้คำตอบผิดทันทีที่มีการกดซ้ำ)
  • useMemo กับ dependency [cart.items] — คำนวณผลรวมใหม่เฉพาะตอน items เปลี่ยนจริง และเพราะ reducer ของเรา immutable ทุกการแก้ไขจะได้ array reference ใหม่เสมอ useMemo จึงจับการเปลี่ยนแปลงได้แม่นยำ — วินัยจากบทที่แล้วมาส่งผลตรงนี้
  • badge โผล่เฉพาะตอนมีของ — {totalItems > 0 && ...} ตะกร้าว่าง = ไอคอนเกลี้ยง ๆ ไม่มีเลข 0 แปะให้รก และ aria-label="Cart item count" ช่วยให้ screen reader อ่านตัวเลขลอย ๆ นี้รู้เรื่อง (แถมเราจะใช้ label นี้หา element ตอนเขียนเทสต์ด้วย)
  • การจัดตำแหน่ง badge — ตัวเลขใช้ position: absolute เกาะมุมขวาบนของกล่องที่มี class relative (utility จากบทที่ 04) ดันขึ้น-ออกไป 12px ให้ลอยเหนือไอคอน สีพื้นดึงจาก variables.$red01 ผ่าน @use ตามแพตเทิร์น SCSS module ที่ใช้กันมาทั้งโปรเจกต์
  • onIconClick เป็น prop — component นี้ไม่ตัดสินใจเองว่าคลิกแล้วไปไหน คนใช้ (Header) เป็นคนบอก การแยกแบบนี้ทำให้ CartSummary ไม่ต้องรู้จัก router เลย

อัปเดต Header — เสียบ CartSummary เข้ามุมขวา

Header เวอร์ชันบทที่ 07 ของเรามีโลโก้กับเมนู แต่มุมขวายังโล่ง ตอนนี้ได้เวลาเติมของที่ค้างไว้ เปิด src/shared/components/Header/Header.tsx: จุดที่เพิ่มคือ import CartSummary, ดึง goToCartSummary จาก useProductRoute (hook บทที่ 07 ที่มีเมธอดนี้รออยู่แล้ว — พาไป /cart) และวาง <CartSummary /> ปิดท้ายแถว flex ไฟล์ฉบับสมบูรณ์:

import React from "react";
import { Link } from "react-router";
import CartSummary from "@/features/cart/components/CartSummary/CartSummary";
import useProductRoute from "@/shared/hooks/useProductRoute";

const Header: React.FC = () => {
  const { goToCartSummary } = useProductRoute();

  return (
    <header className="pt-25 pb-25">
      <div className="container">
        <div className="flex space-between align-item-center">
          <Link className="nav-link fw-bold fs-24" to="/">
            My Store
          </Link>

          <nav>
            <ul className="flex gap-20 m-0 p-0 list-none">
              <li>
                <Link to="/" className="nav-link">
                  Home
                </Link>
              </li>
              <li>
                <Link to="/categories" className="nav-link">
                  Products
                </Link>
              </li>
            </ul>
          </nav>

          <CartSummary onIconClick={goToCartSummary} />
        </div>
      </div>
    </header>
  );
};

export default Header;

สังเกตทิศทางของ dependency ตรงนี้สักนิด: Header เป็น shared component แต่ import ของจาก features/cart ได้ เพราะ Header คือจุดประกอบของทั้งแอปอยู่แล้ว ส่วน CartSummary เองอยู่ใน features/cart/components ไม่ใช่ shared — มันรู้จัก useCart จึงเป็นสมบัติของ feature cart เต็มตัว การวางไฟล์ตามว่า "ใครรู้จักอะไร" แบบนี้คือแก่นของโครงสร้าง feature-based ที่เราคุยกันไว้ในบทที่ 05

อีกจุดคือ Header render อยู่ใน MainLayout ซึ่งอยู่ใต้ AppProviders — ดังนั้น useCart ใน CartSummary ทำงานได้จากทุกหน้า และเพราะทุกคนอ่านจาก context ใบเดียวกัน การกดปุ่มบนหน้า Product จะทำให้ badge บน Header ขยับทันทีโดยที่สอง component นี้ไม่รู้จักกันเลย — นี่แหละพลังของการยก state ขึ้นไปไว้บน Context

💡 Checkpoint — รัน npm run dev แล้วไล่ตาม flow นี้: เปิดสินค้าสักตัว → กด Add To Cart → modal "Product Added to Cart" เด้งขึ้น → กด Close → มุมขวาบนมี badge สีแดงเลข 1 บนไอคอนตะกร้า → กด Add To Cart ซ้ำอีกครั้ง → badge กลายเป็น 2 (สินค้าเดิมถูกรวมจำนวน ไม่ใช่เพิ่มแถวใหม่ — ฝีมือ reducer บทที่แล้ว) → refresh หน้า → badge ยังอยู่ครบ เพราะ localStorage จากบทที่ 19 ทำงานเงียบ ๆ ให้ตลอด → คลิกไอคอนตะกร้า → ไปโผล่หน้า /cart ที่ยังเป็น stub ว่าง ๆ อยู่ ถูกต้องแล้ว — หน้านั้นคืองานของบทถัดไป
