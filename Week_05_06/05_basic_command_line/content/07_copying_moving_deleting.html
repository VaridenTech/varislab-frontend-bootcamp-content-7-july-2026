คัดลอก ย้าย และลบ

บทที่แล้วสร้างโฟลเดอร์ฝึกมือ my-cli-lab พร้อมไฟล์ข้างในไว้แล้ว บทนี้จะพาคุณจัดการไฟล์เหล่านั้นด้วย สามคำสั่งที่ใช้บ่อยที่สุดใน terminal ได้แก่ cp (copy), mv (move) และ rm (remove) ทั้งสามคำสั่งไม่มีหน้าต่างยืนยันแบบที่ Finder หรือ File Explorer มีให้ จึงต้องเข้าใจให้แม่นก่อนใช้งานจริง

คัดลอกด้วย cp

cp รับ argument สองตัวคือไฟล์ต้นทางและปลายทาง ลองคัดลอก README.md เป็นไฟล์สำรองในโฟลเดอร์เดียวกัน 

$ cd ~/my-cli-lab
$ cp README.md README.backup.md
$ ls
README.backup.md	README.md	notes		src

ตอนนี้มีไฟล์ README.backup.md เพิ่มขึ้นมา เป็นสำเนาอิสระจาก README.md แก้ไขไฟล์ใดไฟล์หนึ่งจะไม่กระทบอีกไฟล์เลย

ถ้าลองคัดลอกทั้งโฟลเดอร์ด้วยวิธีเดียวกันจะเจอ error 

$ cp src src-backup
cp: src is a directory (not copied).

cp ธรรมดาคัดลอกได้แค่ไฟล์เดี่ยว ๆ เท่านั้น เพราะโฟลเดอร์มีเนื้อหาซ้อนอยู่ข้างในหลายชั้น cp จึงไม่กล้าเดาเองว่าต้องคัดลอกลึกแค่ไหน ต้องสั่งชัดเจนด้วย flag -r (recursive) เพื่อบอกว่าให้ไล่คัดลอกทุกไฟล์และทุกโฟลเดอร์ย่อยข้างในไปด้วย 

$ cp -r src src-backup
$ ls
README.backup.md	README.md	notes		src		src-backup
$ ls -R src-backup
index.js	utils

src-backup/utils:
format.js

คราวนี้ src-backup มีโครงสร้างเหมือน src ทุกประการ ทั้ง index.js และ utils/format.js ที่ซ้อนอยู่ข้างใน

ย้ายด้วย mv

mv มีรูปแบบ argument เหมือน cp ทุกอย่าง ต่างกันตรงที่ไฟล์ต้นทางจะหายไปจากตำแหน่งเดิม แทนที่จะมีสำเนาเหลืออยู่สองที่ 

$ mv README.backup.md notes/
$ ls
README.md	notes		src		src-backup
$ ls notes
README.backup.md

README.backup.md หายไปจากโฟลเดอร์ปัจจุบันแล้ว เพราะย้ายเข้าไปอยู่ใน notes/ แทน สังเกตว่า mv ไม่ต้อง flag -r เหมือน cp แม้จะย้ายทั้งโฟลเดอร์ เพราะการย้ายไม่ต้องอ่านเนื้อหาข้างในทีละไฟล์ แค่เปลี่ยนตำแหน่งอ้างอิงของไฟล์เท่านั้น

เปลี่ยนชื่อก็คือ mv

command line ไม่มีคำสั่ง rename แยกต่างหาก เพราะสำหรับ shell แล้ว “เปลี่ยนชื่อ” กับ “ย้าย” คือการกระทำเดียวกัน นั่นคือเปลี่ยนตำแหน่งที่ไฟล์ถูกอ้างอิงถึง ต่างกันแค่ว่าเปลี่ยนแค่ชื่อหรือเปลี่ยนทั้ง path เท่านั้น เรื่องนี้ทำให้มือใหม่หลายคนงงเมื่อเจอครั้งแรก เพราะคุ้นเคยกับ Finder หรือ File Explorer ที่แยกเมนู “Rename” กับ “Move” ออกจากกันชัดเจน 

$ mv notes docs
$ ls
README.md	docs		src		src-backup

คำสั่งนี้ “เปลี่ยนชื่อ” notes เป็น docs โดยที่ตำแหน่งยังอยู่ในโฟลเดอร์ปัจจุบันเหมือนเดิม เบื้องหลังคือ mv คำสั่งเดียวกันกับที่ใช้ย้ายไฟล์ข้ามโฟลเดอร์นั่นเอง ถ้าอยากเปลี่ยนชื่อ พร้อมย้ายไปโฟลเดอร์อื่นในคำสั่งเดียวก็ทำได้ เช่น mv notes archive/old-notes

ลบด้วย rm

rm ลบไฟล์ที่ระบุทันที เริ่มจากลบไฟล์สำรองที่ย้ายเข้า docs ไปก่อนหน้านี้ 

$ rm docs/README.backup.md
$ ls docs

ls docs ไม่แสดงอะไรเลยเพราะโฟลเดอร์นี้กลับมาว่างเปล่าอีกครั้ง เช่นเดียวกับ cp คำสั่ง rm ธรรมดาก็ลบโฟลเดอร์ตรง ๆ ไม่ได้เหมือนกัน ต้องเติม -r เพื่อไล่ลบทุกอย่างข้างในให้หมดก่อน 

$ rm -r src-backup
$ ls
README.md	docs		src

src-backup พร้อมทุกไฟล์ข้างในถูกลบไปทั้งโฟลเดอร์ในคำสั่งเดียว

ระวัง: rm ไม่มีถังขยะ

rm ลบไฟล์ทันทีแบบถาวร ไม่มี Recycle Bin หรือ Trash ให้กู้คืน และไม่มีคำสั่ง undo ไฟล์ที่หายไปแล้วคือหายไปเลย ยิ่งเมื่อรวม flag -r (recursive) กับ -f (force) เป็น rm -rf จะยิ่งอันตรายกว่าเดิม เพราะ -f ปิดการถามยืนยันทุกกรณี แม้แต่กรณีที่ไฟล์เขียนป้องกันไว้ก็ยังลบผ่านโดยไม่มีคำเตือนใด ๆ

นิสัยที่ช่วยกันความผิดพลาดได้จริงคือ รัน ls กับ target ก่อนรัน rm ทุกครั้ง เพื่อดูให้แน่ใจว่ากำลังจะลบอะไรบ้าง โดยเฉพาะก่อนใช้ wildcard อย่าง rm * ที่จะกล่าวถึงในบทที่ 9 ระหว่างที่ยังไม่ชิน แนะนำให้ใช้ rm -i แทน ซึ่งจะถามยืนยันทีละไฟล์ก่อนลบจริง ให้มีโอกาสยกเลิกทันเวลา

บน Windows: Git Bash ใช้ cp, mv, rm ได้เหมือน macOS ส่วนใน PowerShell คำสั่งเทียบเท่าคือ Copy-Item, Move-Item และ Remove-Item และไฟล์ที่ลบด้วยคำสั่งเหล่านี้ก็ไม่เข้า Recycle Bin เช่นกัน

แบบฝึกหัด

ในโฟลเดอร์ ~/my-cli-lab ทำตามลำดับต่อไปนี้ โดยรัน ls เช็กผลลัพธ์หลังทุกขั้นตอน

  1. คัดลอก README.md เป็น README.backup.md
  2. เปลี่ยนชื่อโฟลเดอร์ notes เป็น docs
  3. ย้าย README.backup.md เข้าไปใน docs/
  4. ลบไฟล์สำรองนั้นทิ้ง
ดูเฉลย

cp สร้างสำเนาแยกไว้ก่อนโดยไม่กระทบไฟล์ต้นฉบับ จากนั้น mv ทำหน้าที่สองอย่างในแบบฝึกหัดนี้คือเปลี่ยนชื่อโฟลเดอร์ (ย้ายภายในตำแหน่งเดิม) และย้ายไฟล์ข้ามโฟลเดอร์ (ย้ายไปตำแหน่งใหม่) ซึ่งเป็นคำสั่งเดียวกันทั้งคู่ ส่วนการรัน ls คั่นระหว่างแต่ละขั้นตอน คือ safety net ที่ทำให้เห็นสถานะจริงก่อนพิมพ์คำสั่งถัดไป ถ้าพลาดตั้งแต่ขั้นแรกจะได้รู้ตัวทันที ไม่ใช่มารู้ตัวหลัง rm ไปแล้ว 

$ cd ~/my-cli-lab
$ cp README.md README.backup.md
$ mv notes docs
$ mv README.backup.md docs/
$ ls docs
README.backup.md
$ rm docs/README.backup.md
$ ls docs
