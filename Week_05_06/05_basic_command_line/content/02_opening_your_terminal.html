เปิด Terminal ครั้งแรก

บทที่แล้วเราคุยกันว่า terminal, shell และ prompt คืออะไร บทนี้จะพาคุณเปิด terminal ขึ้นมาจริง ๆ ไม่ว่าคุณจะใช้เครื่องแบบไหนก็ตาม แล้วลองพิมพ์คำสั่งแรกดู

เปิด Terminal บน macOS

วิธีที่เร็วที่สุดคือใช้ Spotlight กด Cmd + Space แล้วพิมพ์ Terminal จากนั้นกด Enter เพื่อเปิดโปรแกรม Terminal ที่ติดตั้งมากับเครื่องอยู่แล้ว

macOS ใช้ shell ชื่อ zsh เป็นค่าเริ่มต้นมาตั้งแต่ macOS Catalina เป็นต้นมา ตัวอย่างในคอร์สนี้จึงอ้างอิงพฤติกรรมของ zsh เป็นหลัก

เปิด Terminal บน Linux

ดิสโทรส่วนใหญ่ตั้งค่าคีย์ลัด Ctrl + Alt + T ไว้เปิด terminal ได้ทันที ถ้าคีย์ลัดนี้ไม่ทำงาน ให้ค้นหาโปรแกรมชื่อ Terminal จากเมนูแอปพลิเคชันของดิสโทรที่ใช้อยู่แทน

เปิด Terminal บน Windows

Windows มี Command Prompt และ PowerShell ติดตั้งมาให้อยู่แล้ว แต่คำสั่งของทั้งสองตัว ต่างจากคำสั่งที่สอนในคอร์สนี้ค่อนข้างมาก เพื่อให้ทุกคนพิมพ์คำสั่งชุดเดียวกันได้ทั้งห้อง ให้ติดตั้งและใช้ Git Bash แทน

บน Windows: ให้ติดตั้ง Git for Windows แล้วเปิดโปรแกรม Git Bash ใช้ตลอดคอร์สนี้ เพราะคำสั่งจะตรงกับที่สอนทุกบท ถ้าองค์กรของคุณติดตั้ง WSL ไว้แล้วก็ใช้ WSL ได้เช่นกัน ส่วน PowerShell และ Command Prompt ใช้คำสั่งคนละชุด บทเรียนจะบอกคำสั่งเทียบเท่าให้ในกล่องแบบนี้เมื่อจำเป็น

อ่าน Prompt ให้เป็น

เมื่อเปิด terminal ขึ้นมา สิ่งแรกที่เห็นคือ prompt ซึ่งบอกข้อมูลหลายอย่างในบรรทัดเดียว ตัวอย่างเช่น 

mint@macbook ~/projects %

prompt บรรทัดนี้แบ่งออกเป็นสี่ส่วน

  • mint คือ username ของผู้ใช้ที่ล็อกอินอยู่
  • macbook คือ hostname หรือชื่อเครื่อง
  • ~/projects คือโฟลเดอร์ปัจจุบันที่ terminal ยืนอยู่
  • % คือสัญลักษณ์ที่บอกว่า prompt พร้อมรับคำสั่งแล้ว ใน zsh มักใช้ % ส่วนใน bash มักใช้ $ ความหมายเหมือนกัน

สามคำสั่งแรกของคุณ

ลองพิมพ์สามคำสั่งนี้ทีละบรรทัด แล้วดูว่า terminal ตอบกลับมาว่าอย่างไร

$ whoami
mint

$ date
Fri Aug 14 10:32:41 +07 2026

$ pwd
/Users/mint

whoami บอกชื่อผู้ใช้ที่กำลังล็อกอินอยู่ date บอกวันเวลาปัจจุบัน ของเครื่อง ส่วน pwd ย่อมาจาก “print working directory” แปลว่า “บอกโฟลเดอร์ที่ทำงานอยู่ตอนนี้” terminal จะมีโฟลเดอร์ปัจจุบันอยู่เสมอ เหมือนกับหน้าต่าง Finder หรือ Explorer ที่เปิดค้างอยู่ในโฟลเดอร์ใดโฟลเดอร์หนึ่งตลอดเวลา

ปิด Terminal

พิมพ์คำสั่ง exit แล้วกด Enter เพื่อปิด shell ปัจจุบัน หรือจะกดปิดหน้าต่าง terminal ตรง ๆ เหมือนโปรแกรมอื่นก็ได้เช่นกัน

ข้อผิดพลาดที่พบบ่อย: พิมพ์เครื่องหมาย $ หรือ % จากตัวอย่างเข้าไปด้วย ทั้งที่มันเป็นส่วนหนึ่งของ prompt เท่านั้น อีกเรื่องที่คนพลาดบ่อยคือคิดว่า terminal จะเปิดอยู่ที่โฟลเดอร์เดียวกับที่ VS Code เปิดค้างไว้ ซึ่งไม่จริง terminal จะไม่ไปโฟลเดอร์นั้นเองจนกว่าเราจะสั่งย้ายด้วยคำสั่ง cd ซึ่งเป็นเรื่องของบทถัดไป

แบบฝึกหัด

เปิด terminal ของคุณขึ้นมาจริง ๆ แล้วรันคำสั่ง whoami, date และ pwd ทีละคำสั่ง จดผลลัพธ์ที่ได้ไว้ จากนั้นตอบคำถามว่า terminal เริ่มต้นที่โฟลเดอร์ไหน และโฟลเดอร์นั้นเป็นโฟลเดอร์เดียวกับโปรเจกต์ของคอร์สนี้หรือไม่

ดูเฉลย

เมื่อเปิด terminal ขึ้นมาใหม่ ค่า pwd ที่ได้เกือบทุกครั้งจะเป็น home directory ของผู้ใช้ ซึ่งหน้าตาต่างกันไปตามระบบปฏิบัติการ บน macOS จะเป็น /Users/<ชื่อ> บน Linux จะเป็น /home/<ชื่อ> และใน Git Bash บน Windows จะเป็น /c/Users/<ชื่อ>

โฟลเดอร์นี้แทบไม่เคยเป็นโฟลเดอร์โปรเจกต์ของคอร์สโดยตรง เพราะ home directory คือจุดเริ่มต้นกลาง ๆ ของผู้ใช้ ไม่ใช่ที่เก็บโปรเจกต์ใดโปรเจกต์หนึ่งเป็นการเฉพาะ การย้าย terminal ไปยังโฟลเดอร์โปรเจกต์จริงจะเป็นเนื้อหาของบทถัดไปเรื่องการเดินทางในระบบไฟล์
