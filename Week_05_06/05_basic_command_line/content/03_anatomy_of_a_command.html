โครงสร้างของคำสั่ง

ตอนนี้คุณเปิด terminal เป็นแล้ว และรันคำสั่งง่าย ๆ อย่าง pwd กับ whoami มาแล้ว บทนี้จะแกะโครงสร้างของคำสั่งที่ซับซ้อนขึ้น เพื่อให้คุณอ่านคำสั่งที่เจอในเอกสารหรือบทเรียนถัดไปได้เอง แม้จะไม่เคยเห็นคำสั่งนั้นมาก่อน

คำสั่งประกอบด้วยสามส่วน

ลองดูคำสั่งนี้เป็นตัวอย่าง

$ ls -l /etc

คำสั่งหนึ่งบรรทัดแบ่งออกเป็นสามส่วนเสมอ ได้แก่ command, option (หรือเรียกว่า flag) และ argument แต่ละส่วนตอบคำถามคนละอย่าง

ส่วน ในตัวอย่างนี้คือ ตอบคำถามว่า
Command ls ทำอะไร (list ไฟล์และโฟลเดอร์)
Option (flag) -l ทำแบบไหน (แสดงผลแบบ long format)
Argument /etc ทำกับอะไร (โฟลเดอร์ /etc)

Flag แบบสั้นและแบบยาว

flag ส่วนใหญ่มีสองรูปแบบให้เลือกใช้ แบบสั้นขึ้นต้นด้วยขีดเดียวตามด้วยตัวอักษรตัวเดียว เช่น -a ส่วนแบบยาวขึ้นต้นด้วยสองขีดตามด้วยคำเต็ม เช่น --all ทั้งสองแบบมักมีความหมายเดียวกัน ต่างกันแค่ความยาวที่พิมพ์

flag แบบสั้นพิมพ์เร็วกว่า ส่วน flag แบบยาวอ่านเข้าใจง่ายกว่าเมื่อกลับมาดูคำสั่งภายหลัง หรือเมื่อแชร์คำสั่งให้คนอื่นอ่าน

รวม Flag หลายตัวเข้าด้วยกัน

เมื่อต้องใช้ flag แบบสั้นหลายตัวพร้อมกัน สามารถเขียนแยกกันหรือรวมไว้หลังขีดเดียวก็ได้ ผลลัพธ์เหมือนกันทุกประการ 

$ ls -l -a
total 24
drwxr-xr-x   6 mint  staff   192 Aug 14 10:20 .
drwxr-xr-x   9 mint  staff   288 Aug 14 09:55 ..
-rw-r--r--   1 mint  staff   212 Aug 14 10:20 .gitignore
-rw-r--r--   1 mint  staff  1450 Aug 14 10:18 package.json

$ ls -la
total 24
drwxr-xr-x   6 mint  staff   192 Aug 14 10:20 .
drwxr-xr-x   9 mint  staff   288 Aug 14 09:55 ..
-rw-r--r--   1 mint  staff   212 Aug 14 10:20 .gitignore
-rw-r--r--   1 mint  staff  1450 Aug 14 10:18 package.json

ls -l -a กับ ls -la คือคำสั่งเดียวกัน แค่เขียนคนละรูปแบบ การรวม flag แบบนี้ทำได้เฉพาะ flag แบบสั้นเท่านั้น flag แบบยาวต้องเขียนแยกกันเสมอ

Argument บางคำสั่งมีได้หลายตัว

argument ไม่จำเป็นต้องมีแค่ตัวเดียว บางคำสั่งรับ argument ได้หลายตัวในบรรทัดเดียว เช่น 

$ cp file1.txt file2.txt backup/

คำสั่งนี้มี argument สามตัวคือ file1.txt, file2.txt และ backup/ ความหมายคือคัดลอกทั้ง file1.txt และ file2.txt ไปไว้ในโฟลเดอร์ backup/

อ่านคู่มือของคำสั่ง

ไม่มีใครจำ flag ของทุกคำสั่งได้หมด วิธีที่เร็วที่สุดคือให้คำสั่งบอกตัวมันเองด้วย --help 

$ ls --help
Usage: ls [OPTION]... [FILE]...
List information about the FILEs.

  -a, --all                  do not ignore entries starting with .
  -l                         use a long listing format
  ...

อีกวิธีคือคำสั่ง man (ย่อจาก manual) ซึ่งเปิดคู่มือแบบละเอียดของคำสั่งนั้น เช่น man ls จะเปิดคู่มือของ ls ขึ้นมาเต็มหน้าจอในโปรแกรมอ่านที่เรียกว่า pager กด q เพื่อออกจากหน้าคู่มือแล้วกลับมาที่ prompt

บน Windows: Git Bash ไม่มีคำสั่ง man ให้ใช้ ls --help แทน ส่วนใน PowerShell ให้ใช้ Get-Help Get-ChildItem ซึ่งเป็นคำสั่งเทียบเท่ากับ ls

ข้อผิดพลาดที่พบบ่อย: ลืมเว้นวรรคระหว่าง command กับ flag เช่นพิมพ์ ls-l ติดกัน ซึ่ง shell จะมองว่าเป็นชื่อคำสั่งเดียวที่ไม่มีอยู่จริง อีกกรณีที่พบบ่อยคือคัดลอกเครื่องหมายขีดจากเว็บไซต์หรือแอปแชท แล้วได้ en dash – ติดมาแทนที่จะเป็นขีดกลางธรรมดา - ทำให้ terminal แจ้ง error ที่งงว่าทำไมคำสั่งที่พิมพ์ถูกต้องถึงใช้ไม่ได้

แบบฝึกหัด

กำหนดคำสั่งต่อไปนี้ให้

$ ls -lah ~/Downloads
  1. บอกว่าคำสั่งนี้แบ่งเป็นกี่ส่วน แต่ละส่วนคืออะไร และคำสั่งทั้งหมดทำอะไร
  2. ใช้ --help ค้นหาว่า flag ตัวไหนของ ls ใช้เรียงลำดับไฟล์ตามเวลาที่แก้ไขล่าสุด
ดูเฉลย

ls คือ command -lah คือการรวม flag แบบสั้นสามตัวเข้าด้วยกัน ได้แก่ -l แสดงผลแบบ long format, -a แสดงไฟล์ที่ซ่อนอยู่ด้วย และ -h แสดงขนาดไฟล์ในหน่วยที่มนุษย์อ่านง่าย เช่น KB หรือ MB แทนตัวเลข byte ดิบ ส่วน ~/Downloads คือ argument ที่บอกว่าให้ทำกับโฟลเดอร์ Downloads ของผู้ใช้ปัจจุบัน คำสั่งทั้งหมดจึงแปลว่า “แสดงรายการไฟล์ทั้งหมดในโฟลเดอร์ Downloads รวมไฟล์ที่ซ่อนอยู่ ด้วยรายละเอียดครบและขนาดที่อ่านง่าย”

flag ที่ใช้เรียงลำดับตามเวลาที่แก้ไขล่าสุดคือ -t หาได้จากการรัน ls --help แล้วไล่อ่านหาบรรทัดที่มีคำว่า time ปรากฏอยู่ ซึ่งจะอธิบายไว้ว่า -t ใช้เรียงตามเวลาแก้ไข
