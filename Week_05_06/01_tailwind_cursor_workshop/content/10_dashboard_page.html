The Dashboard Page

🎯 เป้าหมาย

"เสร็จ" ของบทนี้: เนื้อหา 4 แถวครบตาม decomposition ของบทเรียน 06 — การ์ดสถิติ ×4, การ์ดโปรโมท ×2, กราฟ ×2, ตาราง Projects + timeline Orders — โดยข้อมูลทั้งหมดเป็น mock data แยกไฟล์ใน src/data/

ก่อนเริ่ม: กราฟจริง (chart library อย่าง Recharts) อยู่นอกขอบเขต workshop นี้ — เราสร้าง "การ์ดกราฟ" ที่หน้าตาเหมือนดีไซน์ด้วย div/SVG นิ่ง ๆ พอ และต้องบอกใน prompt ชัด ๆ ไม่งั้น Agent จะติดตั้ง library แถมให้ทันที

📝 เขียน Prompt

ได้เวลาใช้วิชาบทเรียน 06–07 แบบเร็วขึ้น: โครงสร้าง = 4 แถวที่ decompose ไว้แล้ว ใส่เนื้อหาจริงให้ครบ — ตัวเลข stat ทั้ง 4, ชื่อโปรเจกต์ทั้ง 6, orders ทั้ง 6 — พิมพ์เองจากภาพ อย่าเขียนว่า "ฯลฯ" (AI จะแต่งข้อมูลเติมเอง แล้วเราต้องมาไล่แก้ให้ตรงดีไซน์ทีหลัง)

สร้างเนื้อหาหน้า Dashboard ใน src/pages/DashboardPage.tsx ตาม screenshot ที่แนบมา

บริบท: app shell (sidebar + navbar) มีแล้ว หน้านี้ render ใน <Outlet /> ของ DashboardLayout
ใช้ design tokens ที่มี: primary, primary-dark, ink, ink-dark, muted, surface, success, danger

ข้อกำหนดทางเทคนิค:
- Tailwind utilities เท่านั้น; การ์ดทุกใบ rounded-2xl bg-white shadow-sm
- Mobile-first: แถว 1 คือ grid-cols-1 → md:grid-cols-2 → xl:grid-cols-4;
  แถว 2 และ 3 คือ grid-cols-1 → lg:grid-cols-2; แถว 4 คือ grid-cols-1 → lg:grid-cols-3
  (ตาราง span 2)
- mock data แยกไฟล์: src/data/stats.ts, src/data/projects.ts, src/data/orders.ts
- ตารางใช้ <table> จริง ไม่ใช่ div เรียงกัน

ขอบเขต: ไม่ติดตั้ง chart library หรือแพ็กเกจใด ๆ เพิ่ม ไม่ทำหน้าอื่น ไม่แก้ sidebar/navbar
