บทเรียน 08 · จาก Screenshot สู่ Prompt (Screenshot to Prompt)

ใช้ Figma ประกอบ Prompt

Working from Figma

Screenshot บอกไม่หมด

Screenshot สื่อโครงสร้างกับบรรยากาศได้ดี แต่ตัวเลขเป๊ะ ๆ — สี hex, ระยะห่างเป็น px, รัศมีมุม, ชื่อฟอนต์ — เดาจากภาพได้แค่ประมาณ เมื่องานจริงมีไฟล์ Figma ให้ (ซึ่งเป็นมาตรฐานของ design handoff ปัจจุบัน) ให้เปิดควบคู่ไปกับ screenshot เสมอ

เปิดไฟล์ Purity UI

เปิดลิงก์ไฟล์ต้นแบบ: Purity UI Dashboard บน Figma Community — ไฟล์ community เปิดดูได้ฟรี และกด Open in Figma เพื่อ duplicate ไปยัง drafts ของเราเอง จะได้คลิกเล่นได้เต็มที่ไม่กลัวพัง

  • เลือก layer — คลิกที่ของที่สนใจ (ดับเบิลคลิกเพื่อเจาะลึกเข้าไปในกลุ่ม) แล้วดูแผง Design ด้านขวา: Fill คือสี, Corner radius คือมุมโค้ง, ขนาดและตำแหน่งอยู่ด้านบน
  • ข้อความ — เลือก text layer จะเห็นฟอนต์ ขนาด น้ำหนัก และ line height
  • ระยะห่าง — เลือกของชิ้นหนึ่ง กด Option (Alt) ค้าง แล้วชี้อีกชิ้น Figma จะโชว์ระยะห่างเป็น px ให้ — ท่านี้ใช้วัด gap ระหว่างการ์ด
  • Dev Mode — ถ้ามีให้เปิด (ปุ่มสลับ </> มุมขวาบน) จะเห็นค่าแบบ CSS ตรง ๆ แต่ไม่มีก็ไม่เป็นไร แผง Design บอกครบแล้ว

อะไรควรลอกจาก Figma ลง prompt / token

อย่าลอกทุกตัวเลข — ลอกเฉพาะค่าที่เป็น "ระบบ" ของดีไซน์

  • สีแบรนด์ — คลิกกล่องไอคอนเขียวมิ้นต์ดู Fill: นี่คือที่มาของ token ในบทเรียน 05 (#4fd1c5 และเพื่อน ๆ) ค่าที่เราตั้งไว้อ่านมาจากไฟล์นี้แหละ
  • ฟอนต์ — Purity ใช้ Helvetica ซึ่งเป็นฟอนต์ระบบของ Mac — เราใช้ font-sans ค่า default ของ Tailwind แทนได้เลย (ระบุใน prompt ว่า "ใช้ font-sans") ไม่ต้องโหลดฟอนต์เพิ่ม
  • รัศมีมุมการ์ด — วัดได้ราว 16px → rounded-2xl — ล็อกเป็นมาตรฐานใน prompt ได้ว่า "การ์ดทุกใบ rounded-2xl"
  • ช่องไฟระหว่างการ์ด — ราว 24px → gap-6

Export assets

ของบางอย่างไม่ควรสร้างด้วยโค้ด แต่ควร export จาก Figma มาใช้ตรง ๆ

  • รูปภาพ — เช่นรูปทีมในการ์ด "Work with the Rockets" หรือพื้นหลังลายคลื่นของ hero: เลือก layer → ส่วน Export ล่างสุดของแผง Design → เลือก PNG (2x สำหรับจอ retina) → วางไฟล์ใน public/images/ ของโปรเจกต์
  • ไอคอน — export เป็น SVG แล้วเปิดไฟล์ copy โค้ด <svg> มาวางเป็น inline SVG ใน component (ตาม rules ของเรา) จะได้คุมสีด้วย currentColor ได้
  • รูป avatar ในตาราง — ใน workshop เราใช้ placeholder จาก https://i.pravatar.cc/150?img=3 (เปลี่ยนเลขท้ายได้หลายหน้า) แทนรูปจริงได้ สะดวกกว่า export ทีละรูป

เมื่อไหร่ screenshot พอ / เมื่อไหร่ต้องเปิด Figma

  • Screenshot พอ — สำหรับโครงสร้าง, layout, ลำดับของ, เนื้อหาข้อความ — คือส่วน "โครงสร้าง" ของ prompt ทั้งหมด
  • เปิด Figma — ตอนตั้ง design tokens (ครั้งเดียวต่อโปรเจกต์), ตอนต้องการค่าที่เป๊ะ (ดีไซเนอร์เพ่งเล็งระยะตรงไหนเป็นพิเศษ), และตอน export assets

คำเตือนสำคัญ: อย่าเสียเวลา inspect ทุก pixel — Agent เก่งเรื่องถอดภาพเป็น layout อยู่แล้ว หน้าที่ของเราคือคุมค่าที่เป็น "ระบบ" (token, spacing scale, รัศมีมุม) ให้ตรง แล้วปล่อยรายละเอียดปลีกย่อยให้รูปสื่อสาร ถ้าผลออกมาเพี้ยนค่อยแก้เป็นจุด ๆ ถูกกว่า inspect ล่วงหน้าทั้งหน้า

แบบฝึก — prompt หน้า Sign Up

เขียน prompt สี่ส่วนสำหรับหน้า Sign Up ด้วยตัวเอง: decompose ภาพ (บทเรียน 06) → เขียนสี่ส่วน (บทเรียน 07) → เปิด Figma อ่านค่าประกอบ เช่นสี hero กับรัศมีการ์ด (บทนี้) จุดที่ต้องคิดเป็นพิเศษ: หน้านี้ไม่มี sidebar — ต้องบอก Agent เรื่องนี้ยังไงในส่วนไหนของ prompt? เก็บ prompt ที่เขียนไว้ — บทเรียน 11 มีเฉลยให้เทียบ

ทักษะ "ถอดดีไซน์เป็น prompt" ครบเครื่องแล้ว ถึงเวลาปล่อยของจริง: บทถัดไปเราจะส่ง prompt แรกให้ Cursor Agent สร้าง app shell
