Functions และ Built-in Modules

หลังจากรู้จัก mixin แล้ว คำถามถัดมาคือ “ถ้าเราไม่ได้อยากปล่อย CSS หลายบรรทัด แต่แค่อยากคำนวณค่าเดียวแล้วส่งกลับมาใช้ใน property ล่ะ?” เครื่องมือที่เหมาะกว่าคือ @function เพราะมัน “คืนค่า” ไม่ได้ “ปล่อย declaration” แบบ mixin

Function คืนค่า ส่วน mixin ปล่อยกฎ CSS

ให้จำภาพง่าย ๆ ว่า function อยู่ฝั่ง “คำนวณค่า” เช่น spacing, width, หรือสีที่ปรับแล้ว ส่วน mixin อยู่ฝั่ง “คัดลอกชุด declaration” ไปใส่ใน selector ที่เรียกใช้ 

@function spacing($step) {
  @return $step * 0.25rem;
}

@mixin card-surface {
  padding: spacing(6);
  border-radius: 1rem;
  background-color: #fff;
}

.card {
  @include card-surface;
  gap: spacing(4);
}

CSS ที่คอมไพล์แล้วจะเป็น:

.card {
  padding: 1.5rem;
  border-radius: 1rem;
  background-color: #fff;
  gap: 1rem;
}

จุดต่างที่ควรจำคือ spacing(4) ถูกแทนด้วยค่า 1rem ก่อน แล้ว property อย่าง gap จึงรับค่านั้นไปใช้อีกที

ประกาศ @function และคืนค่าด้วย @return

function ของ Sass ต้องมี @return เสมอ เพื่อบอกว่าค่าที่จะส่งกลับคืออะไร ถ้าไม่มี Sass จะไม่รู้ว่าจะเอาค่าไหนไปแทนตอนคอมไพล์ 

@function column-width($columns) {
  @return math.div(100%, $columns);
}

.feature-grid {
  grid-template-columns: repeat(3, column-width(3));
}

ตัวอย่างนี้ใช้ math.div() จาก built-in module sass:math เพื่อหลีกเลี่ยง slash division แบบเก่า ที่เลิกแนะนำใน Dart Sass แล้ว 

@use "sass:math";

@function column-width($columns) {
  @return math.div(100%, $columns);
}

.feature-grid {
  display: grid;
  grid-template-columns: repeat(3, column-width(3));
  gap: 1rem;
}

เมื่อคอมไพล์แล้วจะได้ CSS ปกติ:

.feature-grid {
  display: grid;
  grid-template-columns: repeat(3, 33.3333333333%);
  gap: 1rem;
}
ถ้าเห็นโค้ดเก่าประมาณ width: 100% / 3; หรือ helper ที่หารค่าด้วยเครื่องหมาย / ให้ถือว่าเป็น syntax รุ่นเก่าที่ควรแทนด้วย math.div() ในโค้ดใหม่

Built-in modules คือ helper ที่ Sass เตรียมไว้ให้แล้ว

นอกจาก sass:math ยังมีโมดูลอื่นอีกหลายตัว เช่น sass:color, sass:list และ sass:map เรานำเข้าด้วย @use แล้วเรียกผ่าน namespace เพื่อให้รู้ชัดว่าฟังก์ชันนั้นมาจากโมดูลไหน 

@use "sass:color";

$brand: #6f3cc3;

.button-primary {
  background-color: $brand;
  border: 1px solid color.adjust($brand, $red: -16, $green: -16, $blue: -31);
  box-shadow: 0 10px 24px color.change($brand, $alpha: 0.3);
}

CSS ที่คอมไพล์แล้วจะเป็น:

.button-primary {
  background-color: #6f3cc3;
  border: 1px solid #5f2ca4;
  box-shadow: 0 10px 24px rgba(111, 60, 195, 0.3);
}

การใช้ color.adjust() และ color.change() แบบ namespaced อ่านชัดกว่า helper global รุ่นเก่า และสื่อเจตนาว่าเรากำลังปรับ channel ของสีหรือค่า alpha อย่างตรงไปตรงมา ไม่ได้สร้างสีใหม่แบบลอย ๆ

เลือก function หรือ mixin ดี?

สถานการณ์ เครื่องมือที่เหมาะกว่า เหตุผล
ต้องคำนวณค่าเดียวเพื่อใช้ใน property Function คืนค่าไปแทนใน declaration ได้ตรง ๆ
ต้องปล่อย declaration หลายบรรทัดพร้อมกัน Mixin เหมาะกับการ reuse ชุดกฎ CSS
ต้องใช้ helper มาตรฐานของ Sass Built-in modules ลดการเขียน utility ซ้ำและใช้ syntax ปัจจุบันของ Dart Sass

ข้อผิดพลาดที่พบบ่อย

  • สับสนระหว่าง function กับ mixin แล้วพยายาม @include function
  • ลืม @return ทำให้ function ไม่คืนค่า
  • เขียนการหารแบบ / ในโค้ดใหม่ แทนที่จะใช้ math.div()
  • เรียก helper สีแบบ global รุ่นเก่า ทั้งที่ควรใช้ @use "sass:color" และ namespace

แบบฝึกหัด

ให้สร้าง function ชื่อ spacing($step) ที่คืนค่า $step * 0.25rem แล้วใช้กับการ์ดหนึ่งใบดังนี้: padding: spacing(6); และ gap: spacing(3); จากนั้นกำหนด background-color: #ffffff; และ border-radius: 1rem; แล้วดูว่า CSS ที่คอมไพล์แล้วได้ค่า spacing ออกมาเท่าไร

ดูเฉลย 
@function spacing($step) {
  @return $step * 0.25rem;
}

.card {
  display: grid;
  padding: spacing(6);
  gap: spacing(3);
  border-radius: 1rem;
  background-color: #ffffff;
}
/* CSS ที่คอมไพล์แล้ว */
.card {
  display: grid;
  padding: 1.5rem;
  gap: 0.75rem;
  border-radius: 1rem;
  background-color: #ffffff;
}
