Control Flow

SCSS ไม่ได้มีแค่ตัวแปรกับ helper เท่านั้น แต่ยังมี control flow สำหรับตัดสินใจและวนซ้ำด้วย เครื่องมือชุดนี้ช่วยลดงานซ้ำ เวลากฎหลายตัวมีรูปแบบเดิม แต่ต่างกันแค่ค่าไม่กี่จุด

@if และ @else ใช้เลือกกฎตามเงื่อนไข

ถ้า style บางอย่างมีสองสามกรณีที่ชัดเจน เราสามารถใช้เงื่อนไขเพื่อเลือกค่าที่เหมาะสมได้ แต่ควรให้ logic อ่านง่ายและจำนวน branch ไม่มากเกินไป 

@mixin surface($tone) {
  @if $tone == "soft" {
    background-color: #f6f0ff;
    color: #3d1766;
  } @else {
    background-color: #3d1766;
    color: #ffffff;
  }
}

.panel-soft {
  @include surface("soft");
}

.panel-strong {
  @include surface("strong");
}

CSS ที่คอมไพล์แล้วจะเป็น:

.panel-soft {
  background-color: #f6f0ff;
  color: #3d1766;
}

.panel-strong {
  background-color: #3d1766;
  color: #ffffff;
}

@each เหมาะกับการวนชุดข้อมูลที่มีชื่อกำกับ

เมื่อเรามี map ของสีสถานะหลายตัว @each ช่วยสร้าง selector ที่เป็นรูปแบบเดียวกันได้ โดยไม่ต้องคัดลอกโค้ดทีละก้อน 

$alert-colors: (
  success: #1f9d55,
  warning: #d97706,
  danger: #dc2626,
);

@each $name, $value in $alert-colors {
  .alert-#{$name} {
    border-left: 4px solid $value;
    background-color: rgba($value, 0.12);
    color: $value;
    padding: 1rem;
  }
}

CSS ที่คอมไพล์แล้วจะมี selector ตามสมาชิกใน map:

.alert-success {
  border-left: 4px solid #1f9d55;
  background-color: rgba(31, 157, 85, 0.12);
  color: #1f9d55;
  padding: 1rem;
}

.alert-warning {
  border-left: 4px solid #d97706;
  background-color: rgba(217, 119, 6, 0.12);
  color: #d97706;
  padding: 1rem;
}

.alert-danger {
  border-left: 4px solid #dc2626;
  background-color: rgba(220, 38, 38, 0.12);
  color: #dc2626;
  padding: 1rem;
}

@for ... through เหมาะกับช่วงตัวเลขที่รู้ขอบเขตแน่ชัด

ถ้าเราต้องสร้าง utility ตามลำดับตัวเลข เช่น spacing scale, radius scale หรือ column count การวนแบบ @for จะตรงกว่าการเขียนมือ แต่ควรใช้กับช่วงที่สั้นและมีเหตุผลจริง ๆ 

@for $step from 1 through 4 {
  .mt-#{$step} {
    margin-top: $step * 0.25rem;
  }
}

CSS ที่คอมไพล์แล้วจะเป็น:

.mt-1 {
  margin-top: 0.25rem;
}

.mt-2 {
  margin-top: 0.5rem;
}

.mt-3 {
  margin-top: 0.75rem;
}

.mt-4 {
  margin-top: 1rem;
}

คำว่า through หมายถึง “รวมค่าปลายทางด้วย” ถ้าเขียน from 1 through 4 เราจะได้ทั้ง 1, 2, 3 และ 4

ใช้ control flow เท่าที่จำเป็น

เครื่องมือ เหมาะเมื่อไร ข้อควรระวัง
@if / @else มีไม่กี่กรณีที่ logic ชัดเจน อย่าซ้อนเงื่อนไขลึกจนไล่อ่านยาก
@each ต้องวนข้อมูลที่มีชื่อกำกับ เช่น map ของ variants อย่าสร้าง selector เยอะเกินความต้องการจริง
@for ต้องวนช่วงตัวเลขที่รู้ขอบเขตแน่ชัด กำหนดช่วงให้เล็กและสื่อความหมาย

บทนี้ไม่ได้ชวนให้ generate utility ทุกอย่างอัตโนมัติ เพราะยิ่งลูปกว้างและชื่อคลาสยิ่งมาก CSS ปลายทางก็ยิ่งโต และทีมจะต้องจำระบบที่ซับซ้อนขึ้นด้วย

ข้อผิดพลาดที่พบบ่อย

  • ใส่เงื่อนไขหลายชั้นจนหาไม่เจอว่าคลาสหนึ่งได้ค่ามาจาก branch ไหน
  • ใช้ @each สร้างคลาสทั้งชุด ทั้งที่โปรเจกต์ใช้จริงแค่ไม่กี่ตัว
  • ลืมว่า through รวมค่าปลายทาง ทำให้ generate เกินที่ตั้งใจ
  • ตั้งชื่อคลาสจากการวนแบบไม่สื่อความหมาย จนคนอ่านไม่รู้ว่าเลขแต่ละตัวแทนอะไร

แบบฝึกหัด

ให้ใช้ @for เพื่อสร้างคลาส .radius-1 ถึง .radius-3 โดยให้แต่ละคลาสมี border-radius เป็น 0.25rem, 0.5rem และ 0.75rem ตามลำดับ จากนั้นดูว่า CSS ที่คอมไพล์แล้วได้ selector ครบทั้งสามตัวหรือไม่

ดูเฉลย 
@for $step from 1 through 3 {
  .radius-#{$step} {
    border-radius: $step * 0.25rem;
  }
}
/* CSS ที่คอมไพล์แล้ว */
.radius-1 {
  border-radius: 0.25rem;
}

.radius-2 {
  border-radius: 0.5rem;
}

.radius-3 {
  border-radius: 0.75rem;
}
