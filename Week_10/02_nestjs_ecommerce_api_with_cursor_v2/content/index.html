สร้าง E-commerce API ด้วย NestJS + Cursor AI

เส้นทางเรียนรู้แบบต่อเนื่อง 23 บทเรียน: เราจะอ่านโค้ดฝั่ง client ของ React e-commerce app จากคอร์ส React E-commerce แล้วออกแบบสัญญา (contract) ของ API เอง จากนั้นสร้าง ecommerce-api ที่ React app สลับมาใช้แทน dummyjson.com ได้ทันทีโดยไม่ต้องแก้โค้ด นอกจากเปลี่ยนแค่ base URL (VITE_API_BASE_URL) ทุก endpoint ในคอร์สนี้จะถูกสร้างด้วย Cursor Agent จาก prompt ที่มีโครงสร้างชัดเจน แล้วตรวจโค้ดที่ AI สร้างทีละบรรทัดก่อนใช้งานจริง

เนื้อหาต่อยอดจากพื้นฐาน NestJS ของคอร์ส NestJS Fundamentals และอ้างอิงเอกสารทางการของ NestJS และ Prisma เพื่อให้ผู้เรียนตรวจสอบรายละเอียดปัจจุบันได้เอง

เมื่อเรียนจบ: คุณจะแปลงสัญญาของ API ที่จับมาได้ (captured API contract) เป็น prompt ที่ Cursor รันได้อย่างแม่นยำและทำซ้ำได้, ตรวจโค้ด NestJS/Prisma ที่ AI สร้างทีละบรรทัดก่อนเชื่อถือ, มี API ที่รันได้จริงครอบคลุม Products และ Orders พร้อม validation, CORS และเอกสาร Swagger และได้พิสูจน์ผลงานด้วยการรัน React app ของจริงเข้ากับ API ที่สร้างขึ้น

สิ่งที่ควรเตรียม: เรียน NestJS Fundamentals จบแล้ว; ติดตั้งและเคยใช้ Cursor มาแล้วจากคอร์ส React E-commerce + Cursor AI; มี Node.js 24 LTS ขึ้นไป และ Docker Desktop; มีโปรเจกต์ React e-commerce จากคอร์ส React E-commerce อยู่ในเครื่องพร้อมใช้งาน

1–4. ก่อนเริ่ม

Workshop ใช้โปรเจกต์เดียวแบบสะสมชื่อ ecommerce-api: บทหลังต่อยอดจากโค้ดของบทก่อนหน้า จึงควรเรียนตามลำดับ เตรียมเครื่องมือด้วยคำสั่งต่อไปนี้

npm i -g @nestjs/cli
nest new ecommerce-api -p npm
cd ecommerce-api
npm run start:dev
  1. สิ่งที่เราจะสร้างและกติกาของคอร์ส
  2. Scaffold โปรเจกต์ด้วย Nest CLI
  3. อ่านโค้ดฝั่ง client แล้วออกแบบสัญญาเป็นของตัวเอง
  4. Cursor Rules และแม่แบบ Prompt

5–9. ฐานข้อมูล: PostgreSQL + Prisma + ข้อมูลจริง

  1. รัน PostgreSQL ด้วย Docker Compose
  2. ติดตั้ง Prisma และ PrismaModule
  3. ออกแบบ Prisma Model ของสินค้า
  4. รัน Migration แรกและดูตารางจริง
  5. เขียน Seed Generator ด้วย Faker

10–15. Products Endpoints ทีละตัว

  1. GET /products/categories
  2. แปลงแถวจากฐานข้อมูลเป็นรูปทรง Product ใน api-spec.md
  3. GET /products/:id
  4. GET /products พร้อม skip และ limit
  5. GET /products/category/:slug
  6. ทำสัญญาให้รันได้จริงด้วย zod

16–18. Orders: POST /carts/add

  1. ออกแบบ Model ของคำสั่งซื้อ
  2. Validate Payload ของ POST /carts/add
  3. สร้างคำสั่งซื้อและเปิด POST /carts/add

19–23. เชื่อมกับ React app

  1. เปิด CORS และตั้งค่า PORT
  2. เพิ่มเอกสาร API ด้วย Swagger
  3. ตกแต่ง DTO และ Response ให้เอกสารครบ
  4. สลับ React app มาใช้ API ของเรา
  5. สรุปและก้าวต่อไป
