การใช้งาน FS Module (จัดการไฟล์)

FS (File System) Module คือ Module ที่มีมาให้ในตัวของ Node.js ซึ่งมอบ API สำหรับโต้ตอบกับระบบไฟล์ Module นี้ช่วยให้นักพัฒนาทำงานกับไฟล์ได้หลากหลายรูปแบบ เช่น การอ่าน การเขียน การอัปเดต การลบ และการเปลี่ยนชื่อไฟล์

เมธอดที่ใช้บ่อย

หนึ่งในเมธอดที่ใช้บ่อยที่สุดใน FS Module คือ fs.readFile() ซึ่งอ่านเนื้อหาของไฟล์แบบ Asynchronous แล้วส่งเนื้อหานั้นกลับมาผ่านฟังก์ชัน Callback อีกเมธอดที่ได้รับความนิยมคือ fs.writeFile() ซึ่งเขียนข้อมูลลงไฟล์แบบ Asynchronous

เมธอดอื่น ๆ ที่ใช้กันบ่อยได้แก่:

  • fs.mkdir() — สร้างโฟลเดอร์ใหม่
  • fs.readdir() — อ่านรายการสิ่งที่อยู่ภายในโฟลเดอร์
  • fs.stat() — ดึงข้อมูลรายละเอียดเกี่ยวกับไฟล์
  • fs.unlink() — ลบไฟล์
  • fs.rename() — เปลี่ยนชื่อไฟล์

เวอร์ชัน Synchronous vs. Asynchronous

FS Module ยังมีเมธอดเหล่านี้ในเวอร์ชัน Synchronous ให้ใช้ด้วย ซึ่งมีประโยชน์สำหรับสคริปต์ง่าย ๆ หรือแอปพลิเคชันขนาดเล็กที่ประสิทธิภาพไม่ใช่ประเด็นสำคัญ

อย่างไรก็ตาม โดยทั่วไปแล้วแนะนำให้ใช้เมธอดเวอร์ชัน Asynchronous มากกว่า เพราะมันเป็นแบบ Non-blocking และให้ประสิทธิภาพที่ดีกว่าในแอปพลิเคชันขนาดใหญ่

สรุป

โดยรวมแล้ว FS Module เป็นเครื่องมือทรงพลังสำหรับนักพัฒนาที่ทำงานกับ Node.js เพราะช่วยให้พวกเขาโต้ตอบกับระบบไฟล์ได้อย่างง่ายดาย และทำงานกับไฟล์ได้หลากหลายรูปแบบ
