การเขียนโค้ดแบบ Asynchronous ใน Node.js

โค้ดแบบ Asynchronous เป็นแนวคิดสำคัญใน Node.js มันช่วยให้โปรแกรมรันโค้ดแบบ Non-blocking ได้ ซึ่งหมายความว่าโปรแกรมสามารถทำงานอย่างอื่นต่อไปได้ในระหว่างที่รอให้งานหนึ่งเสร็จสิ้น

Callbacks

Callback คือวิธีดั้งเดิมในการจัดการโค้ดแบบ Asynchronous ใน Node.js ฟังก์ชัน Callback จะถูกส่งเข้าไปเป็น Argument ให้กับฟังก์ชันที่ทำงานแบบ Asynchronous และเมื่องานนั้นเสร็จสิ้น ฟังก์ชัน Callback ก็จะถูกเรียกให้ทำงาน

fs.readFile('file.txt', (err, data) => {
  if (err) {
    console.error(err)
    return
  }
  console.log(data)
})

ในตัวอย่างข้างต้น ฟังก์ชัน readFile จะอ่านเนื้อหาของไฟล์ file.txt เมื่ออ่านไฟล์เสร็จ ฟังก์ชัน Callback ก็จะถูกเรียกให้ทำงาน หากเกิดข้อผิดพลาดขึ้นระหว่างการทำงาน ตัวข้อผิดพลาดจะถูกส่งเข้าไปให้ฟังก์ชัน Callback เป็น Argument ตัวแรก

Promises

Promise เป็นวิธีที่สะอาดกว่าในการจัดการโค้ดแบบ Asynchronous ใน Node.js โดย Promise แทนค่าที่อาจจะยังไม่พร้อมใช้งานในตอนนี้ และช่วยให้คุณเชื่อมต่อการทำงานแบบ Asynchronous หลาย ๆ อย่างเข้าด้วยกันได้

const fs = require('fs/promises')

fs.readFile('file.txt')
  .then(data => {
    console.log(data)
  })
  .catch(err => {
    console.error(err)
  })

ในตัวอย่างข้างต้น ฟังก์ชัน readFile จะคืนค่าเป็น Promise เมื่อ Promise นั้นสำเร็จ (Resolved) ฟังก์ชัน then จะถูกเรียกให้ทำงาน แต่ถ้า Promise ล้มเหลว (Rejected) ฟังก์ชัน catch จะถูกเรียกแทน

Async/Await

Async/Await เป็นวิธีที่ใหม่กว่าในการจัดการโค้ดแบบ Asynchronous ใน Node.js มันช่วยให้เขียนโค้ด Asynchronous ได้อ่านง่ายและกระชับกว่า โดยใช้ Keyword async และ await

const fs = require('fs/promises')

async function readFile() {
  try {
    const data = await fs.readFile('file.txt')
    console.log(data)
  } catch (err) {
    console.error(err)
  }
}

readFile()

ในตัวอย่างข้างต้น ฟังก์ชัน readFile ถูกกำกับไว้ด้วย async ซึ่งทำให้เราสามารถใช้ Keyword await เพื่อรอให้ฟังก์ชัน readFile ทำงานเสร็จก่อนที่จะรันโค้ดบรรทัดถัดไป และหากเกิดข้อผิดพลาดขึ้นระหว่างการทำงาน มันจะถูกดักจับด้วยบล็อก try/catch

การจัดการข้อผิดพลาด (Error Handling)

การจัดการข้อผิดพลาดเป็นส่วนสำคัญของการเขียนโค้ดแบบ Asynchronous ใน Node.js ในทุกตัวอย่างข้างต้น การจัดการข้อผิดพลาดทำได้ด้วยบล็อก try/catch หรือด้วยฟังก์ชัน catch

สิ่งสำคัญคือต้องจัดการข้อผิดพลาดให้เหมาะสมเพื่อไม่ให้แอปพลิเคชันหยุดทำงาน นอกจากนี้ การให้ข้อความแสดงข้อผิดพลาดที่สื่อความหมายก็เป็นสิ่งสำคัญ เพราะจะช่วยในการแก้ไขปัญหา (Debug) ได้มาก
