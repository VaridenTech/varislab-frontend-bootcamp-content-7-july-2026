Require vs. Import

ใน Node.js นั้น require และ import คือสองวิธีในการนำ Module จากภายนอกเข้ามาใช้ในโค้ดของเรา ทั้งสองมีจุดประสงค์เดียวกัน แต่ก็มีความแตกต่างบางอย่างที่ควรรู้ไว้

Require

require คือฟังก์ชันที่มีมาให้ในตัวของ Node.js ซึ่งช่วยให้คุณโหลด Module จากภายนอกได้ มันทำงานแบบ Synchronous หมายความว่ามันจะหยุดขวางการทำงานของโค้ดส่วนที่เหลือจนกว่า Module จะโหลดเสร็จ ตัวอย่างเช่น:

const fs = require('fs');
const data = fs.readFileSync('file.txt', 'utf8');
console.log(data);

ในตัวอย่างนี้ เรากำลังโหลด Module fs ซึ่งเป็น Module ที่ใช้โต้ตอบกับระบบไฟล์ จากนั้นเราใช้เมธอด readFileSync เพื่ออ่านเนื้อหาของไฟล์ที่ชื่อ file.txt และสุดท้ายเราแสดงเนื้อหานั้นออกทาง Console

Import

import คือวิธีที่ใหม่กว่าในการนำ Module จากภายนอกเข้ามาใช้ในโค้ด มันเป็นส่วนหนึ่งของมาตรฐาน ES6 (ECMAScript 2015) และทำงานแบบ Asynchronous ตัวอย่างเช่น:

import fs from 'fs/promises';
async function readFile() {
  const data = await fs.readFile('file.txt', 'utf8');
  console.log(data);
}
readFile();

ในตัวอย่างนี้ เราใช้คำสั่ง import เพื่อโหลด Module fs/promises ซึ่งเป็น Module ที่ใช้โต้ตอบกับระบบไฟล์ด้วย Promise จากนั้นเรานิยามฟังก์ชัน async ชื่อ readFile ซึ่งใช้เมธอด readFile เพื่ออ่านเนื้อหาของไฟล์ที่ชื่อ file.txt และสุดท้ายเราแสดงเนื้อหานั้นออกทาง Console

การ Export

นอกจากการโหลด Module จากภายนอกแล้ว คุณอาจต้องการ Export โค้ดของคุณเองออกไปเป็น Module เพื่อให้ส่วนอื่น ๆ ของแอปพลิเคชันนำไปใช้ได้ด้วย ซึ่งมีหลายวิธีขึ้นอยู่กับระบบ Module ที่คุณใช้อยู่

CommonJS

CommonJS คือระบบ Module ที่ Node.js ใช้ ในการ Export Module แบบ CommonJS คุณสามารถใช้ Object module.exports หรือ exports ได้ ตัวอย่างเช่น:

// module.js
function hello(name) {
  console.log(`Hello, ${name}!`);
}
module.exports = { hello };

// app.js
const module = require('./module');
module.hello('world');

ในตัวอย่างนี้ เรานิยามฟังก์ชันชื่อ hello ไว้ใน Module ที่ชื่อ module.js จากนั้นเรา Export ฟังก์ชันนั้นออกไปด้วย module.exports ส่วนในไฟล์ app.js เราโหลด Module นั้นด้วย require แล้วเรียกใช้ฟังก์ชัน hello

ES6 Modules

ES6 Modules คือระบบ Module ที่ใหม่กว่า ซึ่งรองรับโดย Browser บางตัวและโดย Node.js ผ่าน Flag --experimental-modules ในการ Export Module แบบ ES6 คุณสามารถใช้ Keyword export ได้ ตัวอย่างเช่น:

// module.js
function hello(name) {
  console.log(`Hello, ${name}!`);
}
export { hello };

// app.js
import { hello } from './module.js';
hello('world');

ในตัวอย่างนี้ เรานิยามฟังก์ชันชื่อ hello ไว้ใน Module ที่ชื่อ module.js จากนั้นเรา Export ฟังก์ชันนั้นออกไปด้วย Keyword export ส่วนในไฟล์ app.js เราโหลด Module นั้นด้วย import แล้วเรียกใช้ฟังก์ชัน hello

สรุป

โดยสรุปแล้ว require และ import คือสองวิธีในการโหลด Module จากภายนอกใน Node.js ทั้งสองมีความแตกต่างกันบ้างในเรื่องรูปแบบการเขียนและพฤติกรรม แต่ต่างก็มีจุดประสงค์เดียวกัน นอกจากนี้ยังมีวิธีการ Export โค้ดของคุณเองออกไปเป็น Module ได้หลายแบบ ขึ้นอยู่กับระบบ Module ที่คุณใช้อยู่
