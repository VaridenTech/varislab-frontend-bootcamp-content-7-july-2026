Require vs. Import

Node.js โหลด Module ได้สองรูปแบบหลักคือ require และ import ทั้งคู่มีหน้าที่นำโค้ดจากอีก Module มาใช้ แต่รูปแบบและระบบเบื้องหลังต่างกันเล็กน้อย

Require

require เป็นฟังก์ชันที่ Node.js มีให้สำหรับโหลด Module แบบ Synchronous โค้ดส่วนถัดไปจะเริ่มหลังจากโหลด Module เสร็จแล้ว ตัวอย่างเช่น:

const fs = require('fs');
const data = fs.readFileSync('file.txt', 'utf8');
console.log(data);

โค้ดนี้โหลด fs สำหรับทำงานกับระบบไฟล์ แล้วใช้ readFileSync อ่าน file.txt ก่อนแสดงเนื้อหาทาง Console

Import

import เป็นรูปแบบที่มาพร้อมมาตรฐาน ES6 (ECMAScript 2015) และเป็นวิธีที่ใหม่กว่าในการนำ Module เข้ามาใช้ ตัวอย่างเช่น:

import fs from 'fs/promises';
async function readFile() {
  const data = await fs.readFile('file.txt', 'utf8');
  console.log(data);
}
readFile();

ตัวอย่างนี้ Import fs/promises เพื่อทำงานกับไฟล์ผ่าน Promise จากนั้นฟังก์ชัน readFile ใช้ await อ่าน file.txt แล้วแสดงเนื้อหาทาง Console

การ Export

นอกจากการโหลด Module จากภายนอกแล้ว คุณอาจต้องการ Export โค้ดของคุณเองออกไปเป็น Module เพื่อให้ส่วนอื่น ๆ ของแอปพลิเคชันนำไปใช้ได้ด้วย ซึ่งมีหลายวิธีขึ้นอยู่กับระบบ Module ที่คุณใช้อยู่

CommonJS

CommonJS คือระบบ Module ที่ Node.js ใช้ ในการ Export Module แบบ CommonJS คุณสามารถใช้ Object module.exports หรือ exports ได้ ตัวอย่างเช่น:

// module.js
function hello(name) {
  console.log(`Hello, ${name}!`);
}
module.exports = { hello };

// app.js
const module = require('./module');
module.hello('world');

ในตัวอย่างนี้ เรานิยามฟังก์ชันชื่อ hello ไว้ใน Module ที่ชื่อ module.js จากนั้นเรา Export ฟังก์ชันนั้นออกไปด้วย module.exports ส่วนในไฟล์ app.js เราโหลด Module นั้นด้วย require แล้วเรียกใช้ฟังก์ชัน hello

ES6 Modules

ES6 Modules คือระบบ Module ที่ใหม่กว่า ซึ่งรองรับโดย Browser บางตัวและโดย Node.js ผ่าน Flag --experimental-modules ในการ Export Module แบบ ES6 คุณสามารถใช้ Keyword export ได้ ตัวอย่างเช่น:

// module.js
function hello(name) {
  console.log(`Hello, ${name}!`);
}
export { hello };

// app.js
import { hello } from './module.js';
hello('world');

ในตัวอย่างนี้ เรานิยามฟังก์ชันชื่อ hello ไว้ใน Module ที่ชื่อ module.js จากนั้นเรา Export ฟังก์ชันนั้นออกไปด้วย Keyword export ส่วนในไฟล์ app.js เราโหลด Module นั้นด้วย import แล้วเรียกใช้ฟังก์ชัน hello

สรุป

สรุปคือ require ใช้คู่กับ CommonJS ส่วน import ใช้คู่กับ ES Modules เลือกใช้ระบบใดระบบหนึ่งให้สอดคล้องกันทั้งตอน Import และ Export โค้ดจะตามต่อได้ง่ายที่สุด
