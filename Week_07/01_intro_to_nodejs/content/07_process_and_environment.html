Process และ Environment

Process

Node.js มี Global Object ชื่อ process สำหรับดูข้อมูลและควบคุมโปรแกรมที่กำลังรันอยู่ Property และ Method ที่เจอบ่อยมีดังนี้:

  • process.argv — Array ที่เก็บ Argument ที่ถูกส่งเข้ามาทาง Command Line ของ Process ปัจจุบัน
  • process.pid — ID ของ Process ปัจจุบัน
  • process.env — Object ที่เก็บ Environment Variables ของ Process ปัจจุบัน
  • process.exit() — สั่งจบการทำงานของ Process ปัจจุบัน โดยจะระบุ Exit Code ด้วยก็ได้

ตัวอย่างการใช้ Property process.argv เพื่อดึง Argument ที่ถูกส่งเข้ามาทาง Command Line ของสคริปต์ Node.js:

// script.js
console.log(process.argv);

หากเรารันสคริปต์นี้ด้วยคำสั่ง node script.js arg1 arg2 ผลลัพธ์ที่ได้จะเป็น:

[ 'node', '/path/to/script.js', 'arg1', 'arg2' ]

จะเห็นว่า process.argv เก็บ Path ของ Node.js, Path ของสคริปต์ และ Argument สองตัวที่เราส่งเข้ามาตามลำดับ

Environment

Environment คือชุดตัวแปรที่โปรแกรมอ่านได้ระหว่างทำงาน (Runtime) Node.js เก็บตัวแปรเหล่านี้ไว้ใน process.env ในรูปคู่ Key-Value

ตัวอย่างการใช้ Object process.env เพื่อเข้าถึง Environment Variable:

// script.js
console.log(process.env.NODE_ENV);

หากเรารันสคริปต์นี้ด้วยคำสั่ง NODE_ENV=production node script.js ผลลัพธ์ที่ได้จะเป็น:

production

ตัวอย่างนี้อ่าน Environment Variable ชื่อ NODE_ENV ผ่าน process.env ได้โดยตรง

สรุป

process จึงเป็นช่องทางที่โปรแกรม Node.js ใช้คุยกับสภาพแวดล้อมรอบตัว ทั้งรับ Argument, อ่านค่าตั้งต้น และสั่งจบการทำงาน เราจะได้ใช้ process.argv ต่อทันทีตอนสร้าง CLI
