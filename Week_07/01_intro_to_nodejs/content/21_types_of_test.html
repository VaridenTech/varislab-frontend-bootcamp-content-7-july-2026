ประเภทของการทดสอบ (Types of Test)

เราเลือกทดสอบแอป Node.js ได้หลายระดับ แต่ละระดับตอบคำถามคนละแบบ การเข้าใจความต่างจะช่วยให้เลือกเขียนเทสต์ได้เหมาะกับสิ่งที่อยากตรวจ

Unit Testing

Unit Testing ตรวจโค้ดชิ้นเล็กแบบแยกเดี่ยว เช่น ฟังก์ชันหรือเมธอดหนึ่งตัวใน Module เป้าหมายคือจับข้อผิดพลาดให้ได้ใกล้ต้นเหตุ ก่อนที่ปัญหาจะลามไปส่วนอื่นของแอป

Integration Testing

Integration Testing ตรวจว่าส่วนต่าง ๆ ทำงานร่วมกันได้จริงหรือไม่ เช่น Module สองตัวส่งข้อมูลหากันถูกต้อง หรือแอปคุยกับฐานข้อมูลและ API ภายนอกได้ตามที่คาด เทสต์ระดับนี้ช่วยจับปัญหาที่ไม่เห็นตอนทดสอบแต่ละส่วนแยกกัน

End-to-End (E2E) Testing

End-to-End Testing ทดสอบเส้นทางใช้งานทั้งระบบ ตั้งแต่ UI ไปจนถึง Backend เป้าหมายคือจำลองสิ่งที่ผู้ใช้ทำจริงและตรวจว่าทุกส่วนทำงานต่อกันจนจบ

API Testing

API Testing ส่ง Request ไปยัง Endpoint แล้วตรวจ Response ที่ได้ เราใช้ดูว่า API รับข้อมูลหลายรูปแบบ จัดการกรณีผิดพลาด และเชื่อมกับส่วนอื่นของแอปได้ถูกต้องหรือไม่

สรุป

ไม่มีเทสต์ประเภทเดียวที่ตอบได้ทุกอย่าง โปรเจกต์จริงจึงมักผสมหลายระดับเข้าด้วยกัน โดยเลือกให้เหมาะกับความเสี่ยงและพฤติกรรมที่ต้องการตรวจ
