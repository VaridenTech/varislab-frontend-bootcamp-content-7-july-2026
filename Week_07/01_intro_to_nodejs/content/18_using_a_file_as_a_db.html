การใช้ไฟล์เป็นฐานข้อมูล (File as a DB)

ปัญหาที่ค้างไว้ตั้งแต่บทที่ 9 คือรายการของเราหายไปทุกครั้งที่โปรแกรมจบ ถึงเวลาแก้แล้ว เราจะใช้ FS Module ร่วมกับไฟล์ JSON เป็นฐานข้อมูลเก็บรายการ Todo ของเรา

ให้สร้างไฟล์ db.json ไว้ที่ Root แล้วใส่ Array ว่างลงไป:

[]

แค่นั้นเลย ข้อมูลของเราคือ Array ของ Todo ตรง ๆ ไม่ต้องมีอะไรห่อไว้อีกชั้น พออ่านไฟล์นี้เข้ามาแล้วแปลงเป็น JavaScript เราจะได้ Array มาใช้ได้ทันที

สร้างไฟล์ todos.js

ต่อไป ให้สร้างโฟลเดอร์ src แล้วสร้างไฟล์ todos.js ไว้ข้างใน ไฟล์นี้จะเป็นที่รวม Logic ทั้งหมดของแอปเรา แยกออกมาจาก index.js ที่ทำหน้าที่รับคำสั่งอย่างเดียว

ในบทนี้เราจะเขียนแค่ส่วนที่คุยกับไฟล์ก่อน:

import fs from 'node:fs/promises'

const DB_PATH = new URL('../db.json', import.meta.url).pathname

// --- ส่วนที่คุยกับไฟล์ ---

export const readTodos = async () => {
  const data = await fs.readFile(DB_PATH, 'utf-8')
  return JSON.parse(data)
}

export const saveTodos = async (todos) => {
  await fs.writeFile(DB_PATH, JSON.stringify(todos, null, 2))
}

คำอธิบายโค้ด

อันดับแรกเรา Import FS Module เข้ามา อย่างไรก็ตาม เราต้องการใช้ Async/Await ซึ่งทำงานร่วมกับ Promise ดังนั้นแทนที่จะใช้เมธอดของ fs เวอร์ชัน Callback เราจะ Import เมธอดของ fs เวอร์ชัน Promise ที่ Node.js มีให้มาใช้แทน โดยสังเกตที่ node:fs/promises

ต่อมาเรากำหนด DB_PATH คือตำแหน่งที่ไฟล์ db.json อยู่ ตรงนี้เราต้องเขียนแบบนี้เพราะ import.meta.url จะบอกตำแหน่งของไฟล์ todos.js เอง แล้วเราถอยขึ้นไปหนึ่งชั้นด้วย ../ เพื่อไปหา db.json ที่อยู่ Root ถ้าเราเขียนแค่ './db.json' เฉย ๆ Node.js จะไปหาไฟล์จากโฟลเดอร์ที่เรารันคำสั่ง ซึ่งอาจเป็นที่ไหนก็ได้ในเครื่อง

จากนั้นเราสร้างฟังก์ชันขึ้นมา 2 ตัว:

  • readTodos — อ่านไฟล์ db.json เข้ามาเป็นข้อความ แล้วใช้ JSON.parse แปลงเป็น Array ของ JavaScript
  • saveTodos — รับ Array เข้ามา แปลงกลับเป็นข้อความด้วย JSON.stringify แล้วเขียนทับลงไฟล์ ส่วน null, 2 ที่ใส่ไว้คือการบอกให้จัดย่อหน้าสวย ๆ 2 Space เวลาเราเปิดไฟล์ดูเองจะได้อ่านง่าย

สังเกตว่าทั้งสองฟังก์ชันนี้ไม่ได้รู้เรื่อง Todo อะไรเลย มันแค่อ่านกับเขียนไฟล์เท่านั้น ส่วน Logic ที่ว่าจะเพิ่มหรือลบรายการยังไง เราจะเขียนในบทถัดไป
