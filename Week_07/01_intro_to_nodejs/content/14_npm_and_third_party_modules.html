NPM และโมดูลจากภายนอก (3rd Party Modules)

Node.js มีโมดูลจากภายนอกให้เลือกใช้จำนวนมาก เราจัดการโมดูลเหล่านี้ผ่าน Node Package Manager (NPM) ซึ่งเป็นเครื่องมือ Command Line สำหรับติดตั้ง อัปเดต และลบแพ็กเกจ

เริ่มต้นด้วย package.json

เริ่มจากสร้าง package.json ในโฟลเดอร์โปรเจกต์ ไฟล์นี้เก็บ Metadata ของโปรเจกต์และรายชื่อ Dependency ที่ต้องใช้ สร้างได้ด้วย npm init แล้วตอบคำถามตามหน้าจอ

การติดตั้งแพ็กเกจ

เมื่อตั้งค่า package.json แล้ว ให้ใช้ npm install <package-name> ติดตั้งแพ็กเกจ npm จะเก็บโค้ดไว้ใน node_modules และเพิ่มชื่อแพ็กเกจเป็น Dependency ใน package.json ให้อัตโนมัติ

หากเติม Flag -g แพ็กเกจจะถูกติดตั้งแบบ Global และใช้ได้กับทุกโปรเจกต์ แต่ส่วนใหญ่ควรติดตั้งแบบ Local เพื่อให้แต่ละโปรเจกต์ใช้เวอร์ชันของตัวเองและลดปัญหาเวอร์ชันชนกัน

การรัน Script ด้วย NPM

เราสร้างคำสั่งลัดสำหรับโปรเจกต์ไว้ใต้ Field scripts ใน package.json ได้ ตัวอย่างนี้เพิ่ม Script สำหรับรัน node server.js:

"scripts": {
  "start": "node server.js"
}

จากนั้นเราก็สามารถรัน Script นี้ได้ด้วยคำสั่ง npm run start

การ Import Module มาใช้ในโค้ด

ในการ Import Module มาใช้ในโค้ดของเรา เราใช้คำสั่ง import ตัวอย่างเช่น หากเราต้องการใช้ Module express เราสามารถ Import ได้ด้วยโค้ดต่อไปนี้:

import express from 'express'

โค้ดนี้ Import Module express เข้ามาและกำหนดให้กับตัวแปรชื่อ express จากนั้นเราก็สามารถใช้ความสามารถต่าง ๆ ที่ Module express มีให้ในโค้ดของเราได้

ลองติดตั้งของจริงกันสักครั้ง

อ่านอย่างเดียวคงไม่เห็นภาพ มาลองติดตั้งแพ็กเกจจริง ๆ กันสักตัว ให้สร้างโฟลเดอร์ใหม่แยกออกมาต่างหาก (อย่าทำในโฟลเดอร์แอปของเรานะ อันนี้เราจะลองเล่นเฉย ๆ) แล้วรัน:

npm init -y
npm pkg set type=module
npm i cowsay

จากนั้นสร้างไฟล์ demo.js แล้วเขียน:

import cowsay from 'cowsay'

console.log(cowsay.say({ text: 'สวัสดี npm!' }))

รันด้วย node demo.js แล้วคุณจะเห็นวัวพูดได้:

 _____________
< สวัสดี npm! >
 -------------
        \   ^__^
         \  (oo)\_______
            (__)\       )\/\
                ||----w |
                ||     ||

ลองเปิดไฟล์ package.json ดู จะเห็นว่า cowsay ถูกเพิ่มเข้าไปใน dependencies ให้อัตโนมัติ และลองเปิดโฟลเดอร์ node_modules ดูก็ได้ โค้ดของ cowsay ที่เราเพิ่งโหลดมาอยู่ในนั้นทั้งหมด

นี่คือทั้งหมดที่ npm ทำ — ไปโหลดโค้ดของคนอื่นมาไว้ในโปรเจกต์เรา แล้วจดไว้ใน package.json ว่าเราใช้อะไรบ้าง

แล้วแอป Todo ของเราล่ะ?

เราจะไม่ติดตั้งแพ็กเกจใด ๆ เลยในแอป Todo ของเรา เพราะทุกอย่างที่เราต้องใช้ Node.js มีมาให้ครบอยู่แล้ว ทั้งการอ่าน Argument, การอ่านเขียนไฟล์ และการสร้างเซิร์ฟเวอร์

การรู้จัก npm ยังสำคัญมากอยู่ดี เพราะโปรเจกต์จริงเกือบทุกตัวที่คุณจะเจอต่อจากนี้ล้วนใช้มัน แต่สำหรับแอปเล็ก ๆ แบบนี้ การไม่พึ่งแพ็กเกจภายนอกเลยจะช่วยให้คุณเห็นชัดว่าอะไรคือความสามารถของ Node.js เองจริง ๆ

สรุป

NPM จึงเป็นทั้งตัวติดตั้งแพ็กเกจ ตัวจัดการ Dependency และที่เก็บ Script ของโปรเจกต์ เมื่อเจอโค้ดที่คนอื่นแก้ปัญหาไว้ดีแล้ว เราก็นำมาใช้ต่อได้โดยไม่ต้องเริ่มใหม่ทุกครั้ง
