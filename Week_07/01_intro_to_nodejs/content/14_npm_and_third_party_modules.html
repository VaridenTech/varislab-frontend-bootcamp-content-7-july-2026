NPM และโมดูลจากภายนอก (3rd Party Modules)

ใน Node.js เรามีโมดูลจากภายนอกให้เลือกใช้มากมายเพื่อขยายความสามารถของโค้ดเรา เราสามารถจัดการโมดูลเหล่านี้ได้ด้วย Node Package Manager (NPM) ซึ่งเป็น Command-line Interface ที่ช่วยให้เราติดตั้ง อัปเดต และลบแพ็กเกจได้

เริ่มต้นด้วย package.json

เริ่มแรก เราต้องสร้างไฟล์ package.json ในโฟลเดอร์โปรเจกต์ของเราก่อน ไฟล์นี้เก็บข้อมูล Metadata เกี่ยวกับโปรเจกต์และ Dependency ที่จำเป็นต่อการรันโปรเจกต์ เราสามารถสร้างไฟล์นี้ได้ด้วยคำสั่ง npm init แล้วตอบคำถามตามที่ระบบถาม

การติดตั้งแพ็กเกจ

เมื่อเราตั้งค่าไฟล์ package.json เรียบร้อยแล้ว เราก็สามารถเริ่มติดตั้งแพ็กเกจด้วยคำสั่ง npm install <package-name> ได้ คำสั่งนี้จะติดตั้งแพ็กเกจและบันทึกไว้ในโฟลเดอร์ node_modules ของโปรเจกต์ พร้อมทั้งเพิ่มแพ็กเกจนั้นเป็น Dependency ในไฟล์ package.json ของเราด้วย

เรายังสามารถติดตั้งแพ็กเกจแบบ Global ได้ด้วย Flag -g แพ็กเกจเหล่านี้จะถูกติดตั้งไว้ในโฟลเดอร์ส่วนกลางและใช้ได้กับทุกโปรเจกต์ อย่างไรก็ตาม แนะนำให้ติดตั้งแพ็กเกจแบบ Local เพื่อหลีกเลี่ยงปัญหาความเข้ากันได้ของเวอร์ชัน

การรัน Script ด้วย NPM

ในการรัน Script ผ่าน NPM เราสามารถกำหนด Script เหล่านั้นไว้ในไฟล์ package.json ภายใต้ Field scripts ตัวอย่างเช่น เราสามารถกำหนด Script สำหรับเริ่มเซิร์ฟเวอร์ด้วยคำสั่ง node server.js โดยเพิ่มบรรทัดต่อไปนี้ลงในไฟล์ package.json:

"scripts": {
  "start": "node server.js"
}

จากนั้นเราก็สามารถรัน Script นี้ได้ด้วยคำสั่ง npm run start

การ Import Module มาใช้ในโค้ด

ในการ Import Module มาใช้ในโค้ดของเรา เราใช้คำสั่ง import ตัวอย่างเช่น หากเราต้องการใช้ Module express เราสามารถ Import ได้ด้วยโค้ดต่อไปนี้:

import express from 'express'

โค้ดนี้ Import Module express เข้ามาและกำหนดให้กับตัวแปรชื่อ express จากนั้นเราก็สามารถใช้ความสามารถต่าง ๆ ที่ Module express มีให้ในโค้ดของเราได้

ลองติดตั้งของจริงกันสักครั้ง

อ่านอย่างเดียวคงไม่เห็นภาพ มาลองติดตั้งแพ็กเกจจริง ๆ กันสักตัว ให้สร้างโฟลเดอร์ใหม่แยกออกมาต่างหาก (อย่าทำในโฟลเดอร์แอปของเรานะ อันนี้เราจะลองเล่นเฉย ๆ) แล้วรัน:

npm init -y
npm pkg set type=module
npm i cowsay

จากนั้นสร้างไฟล์ demo.js แล้วเขียน:

import cowsay from 'cowsay'

console.log(cowsay.say({ text: 'สวัสดี npm!' }))

รันด้วย node demo.js แล้วคุณจะเห็นวัวพูดได้:

 _____________
< สวัสดี npm! >
 -------------
        \   ^__^
         \  (oo)\_______
            (__)\       )\/\
                ||----w |
                ||     ||

ลองเปิดไฟล์ package.json ดู จะเห็นว่า cowsay ถูกเพิ่มเข้าไปใน dependencies ให้อัตโนมัติ และลองเปิดโฟลเดอร์ node_modules ดูก็ได้ โค้ดของ cowsay ที่เราเพิ่งโหลดมาอยู่ในนั้นทั้งหมด

นี่คือทั้งหมดที่ npm ทำ — ไปโหลดโค้ดของคนอื่นมาไว้ในโปรเจกต์เรา แล้วจดไว้ใน package.json ว่าเราใช้อะไรบ้าง

แล้วแอป Todo ของเราล่ะ?

เราจะไม่ติดตั้งแพ็กเกจใด ๆ เลยในแอป Todo ของเรา เพราะทุกอย่างที่เราต้องใช้ Node.js มีมาให้ครบอยู่แล้ว ทั้งการอ่าน Argument, การอ่านเขียนไฟล์ และการสร้างเซิร์ฟเวอร์

การรู้จัก npm ยังสำคัญมากอยู่ดี เพราะโปรเจกต์จริงเกือบทุกตัวที่คุณจะเจอต่อจากนี้ล้วนใช้มัน แต่สำหรับแอปเล็ก ๆ แบบนี้ การไม่พึ่งแพ็กเกจภายนอกเลยจะช่วยให้คุณเห็นชัดว่าอะไรคือความสามารถของ Node.js เองจริง ๆ

สรุป

โดยสรุปแล้ว NPM คือเครื่องมือทรงพลังที่ช่วยให้เราจัดการโมดูลจากภายนอกในโปรเจกต์ Node.js ได้ เราสามารถติดตั้งแพ็กเกจ จัดการ Dependency รัน Script และ Import Module ได้ผ่าน NPM ด้วยความสามารถเหล่านี้ เราจึงสามารถขยายขีดความสามารถของแอปพลิเคชัน Node.js และทำให้มันมีประสิทธิภาพและใช้งานได้ดียิ่งขึ้น
