Module คืออะไร?

ใน Node.js Module คือชิ้นส่วนของโค้ดที่สมบูรณ์ในตัวเอง ซึ่งทำหน้าที่อย่างใดอย่างหนึ่งโดยเฉพาะ มันอาจเป็นฟังก์ชัน, Object หรือชุดความสามารถที่สามารถนำไปใช้ในส่วนอื่น ๆ ของแอปพลิเคชันได้

ใน Node.js มี Module อยู่ 3 ประเภท ได้แก่ Internal Module, Module ที่ผู้ใช้สร้างเอง และ Module จากภายนอกผ่าน npm

Internal Modules

Internal Module คือ Module ที่มีมาให้พร้อมกับ Node.js อยู่แล้ว และเข้าถึงได้ด้วยฟังก์ชัน require โดยไม่ต้องติดตั้งเพิ่ม ตัวอย่างเช่น Module http ที่มีมาให้ในตัว ใช้สำหรับสร้าง Web Server:

const http = require('http');

http.createServer(function (req, res) {
  res.writeHead(200, {'Content-Type': 'text/plain'});
  res.end('Hello World!');
}).listen(8080);

ในตัวอย่างนี้ เราใช้ฟังก์ชัน require() เพื่อโหลด Module http แล้วนำมาสร้าง Web Server ที่คอยรับ Request ที่ Port 8080

Module ที่ผู้ใช้สร้างเอง (User-created Modules)

Module ที่ผู้ใช้สร้างเองคือ Module ที่คุณเขียนขึ้นมาเอง และสามารถนำเข้าไปใช้ในแอปพลิเคชันได้ด้วยฟังก์ชัน require ตัวอย่างเช่น คุณสามารถสร้าง Module ที่ Export ฟังก์ชันสำหรับบวกเลขสองจำนวน:

// math.js

function add(a, b) {
  return a + b;
}

module.exports = add;

แล้วนำไปใช้ในไฟล์อื่น:

// index.js

const add = require('./math');

console.log(add(2, 3)); // ผลลัพธ์: 5

ในตัวอย่างนี้ เราสร้าง Module ชื่อ math.js ที่ Export ฟังก์ชันชื่อ add ออกมา จากนั้นเราใช้ฟังก์ชัน require() เพื่อโหลดฟังก์ชัน add จาก Module math.js มาใช้บวกเลขสองจำนวน

Module จากภายนอก (Third-party Modules)

Module จากภายนอกผ่าน npm คือ Module ที่นักพัฒนาคนอื่นสร้างขึ้น และสามารถดาวน์โหลดได้จาก npm Registry ผ่านตัวจัดการแพ็กเกจ npm ตัวอย่างเช่น คุณสามารถใช้ Module axios เพื่อส่ง HTTP Request:

const axios = require('axios');

axios.get('https://jsonplaceholder.typicode.com/users')
  .then(function (response) {
    console.log(response.data);
  })
  .catch(function (error) {
    console.log(error);
  });

ในตัวอย่างนี้ เราใช้ฟังก์ชัน require() เพื่อโหลด Module axios แล้วนำมาส่ง HTTP GET Request ไปยัง API ของ jsonplaceholder

การ Export Module

ในการ Export Module ออกจากไฟล์ คุณต้องใช้ module.exports หรือ Keyword export ซึ่งจะทำให้ Module นั้นพร้อมใช้งานในส่วนอื่น ๆ ของแอปพลิเคชัน ตัวอย่างเช่น คุณสามารถสร้าง Module ที่ Export Object ออกมา:

// logger.js

const logger = {
  log: function(message) {
    console.log(message);
  }
};

module.exports = logger;

แล้วนำไปใช้ในไฟล์อื่น:

// index.js

const logger = require('./logger');

logger.log('Hello, world!'); // ผลลัพธ์: Hello, world!

ในตัวอย่างนี้ เราสร้าง Module ชื่อ logger.js ที่ Export Object ซึ่งมีฟังก์ชัน log อยู่ข้างใน จากนั้นเราใช้ฟังก์ชัน require() เพื่อโหลด Module logger.js มาใช้แสดงข้อความ

การ Import Module

ใน Node.js เวอร์ชันใหม่ ๆ คุณสามารถใช้คำสั่ง import เพื่อ Import Module ได้ด้วย คำสั่งนี้คล้ายกับฟังก์ชัน require() แต่มีความแตกต่างบางอย่างทั้งในเรื่องรูปแบบการเขียนและพฤติกรรม ตัวอย่างเช่น คุณสามารถ Import แบบระบุชื่อ (Named Export) ได้:

// math.js

export function add(a, b) {
  return a + b;
}

แล้วนำไปใช้ในไฟล์อื่น:

// index.js

import { add } from './math';

console.log(add(2, 3)); // ผลลัพธ์: 5

ในตัวอย่างนี้ เราสร้าง Module ชื่อ math.js ที่ Export ฟังก์ชันแบบระบุชื่อว่า add จากนั้นเราใช้คำสั่ง import เพื่อโหลดฟังก์ชัน add จาก Module math.js มาใช้บวกเลขสองจำนวน

สรุป

Module เป็นส่วนสำคัญของการพัฒนาด้วย Node.js และการเข้าใจวิธีสร้าง, Import และ Export Module เป็นสิ่งจำเป็นอย่างยิ่งต่อการสร้างแอปพลิเคชันที่มีประสิทธิภาพและขยายขนาดได้
