Module คืออะไร?

ใน Node.js Module คือโค้ดหนึ่งส่วนที่แยกหน้าที่ชัดเจน อาจเป็นฟังก์ชัน, Object หรือชุดความสามารถที่ส่วนอื่นของแอปนำไปใช้ต่อได้

ใน Node.js มี Module อยู่ 3 ประเภท ได้แก่ Internal Module, Module ที่ผู้ใช้สร้างเอง และ Module จากภายนอกผ่าน npm

Internal Modules

Internal Module ติดมากับ Node.js จึงเรียกใช้ผ่าน require ได้เลยโดยไม่ต้องติดตั้งเพิ่ม ตัวอย่างเช่น http ใช้สร้าง Web Server:

const http = require('http');

http.createServer(function (req, res) {
  res.writeHead(200, {'Content-Type': 'text/plain'});
  res.end('Hello World!');
}).listen(8080);

โค้ดนี้โหลด http ด้วย require() แล้วสร้าง Web Server ที่รอรับ Request ทาง Port 8080

Module ที่ผู้ใช้สร้างเอง (User-created Modules)

Module ที่เราสร้างเองก็คือไฟล์โค้ดที่แยกออกมาแล้วเปิดให้ไฟล์อื่นโหลดผ่าน require ตัวอย่างนี้สร้าง Module ที่ Export ฟังก์ชันบวกเลขสองจำนวน:

// math.js

function add(a, b) {
  return a + b;
}

module.exports = add;

แล้วนำไปใช้ในไฟล์อื่น:

// index.js

const add = require('./math');

console.log(add(2, 3)); // ผลลัพธ์: 5

math.js Export ฟังก์ชัน add ส่วนอีกไฟล์ใช้ require() โหลดฟังก์ชันนั้นมาบวกเลข

Module จากภายนอก (Third-party Modules)

Module จากภายนอกคือแพ็กเกจที่นักพัฒนาคนอื่นเผยแพร่ไว้ใน npm Registry เราติดตั้งผ่าน npm แล้วนำมาใช้ได้ เช่น axios สำหรับส่ง HTTP Request:

const axios = require('axios');

axios.get('https://jsonplaceholder.typicode.com/users')
  .then(function (response) {
    console.log(response.data);
  })
  .catch(function (error) {
    console.log(error);
  });

ตัวอย่างนี้โหลด axios ด้วย require() แล้วส่ง HTTP GET Request ไปยัง API ของ jsonplaceholder

การ Export Module

หากต้องการเปิดให้ไฟล์อื่นใช้โค้ดของเรา ให้ Export ด้วย module.exports หรือ Keyword export ตัวอย่างนี้ Export Object หนึ่งตัว:

// logger.js

const logger = {
  log: function(message) {
    console.log(message);
  }
};

module.exports = logger;

แล้วนำไปใช้ในไฟล์อื่น:

// index.js

const logger = require('./logger');

logger.log('Hello, world!'); // ผลลัพธ์: Hello, world!

logger.js Export Object ที่มีฟังก์ชัน log แล้วอีกไฟล์ก็โหลด Module นี้ด้วย require() เพื่อแสดงข้อความ

การ Import Module

ใน Node.js เวอร์ชันใหม่ ๆ คุณสามารถใช้คำสั่ง import เพื่อ Import Module ได้ด้วย คำสั่งนี้คล้ายกับฟังก์ชัน require() แต่มีความแตกต่างบางอย่างทั้งในเรื่องรูปแบบการเขียนและพฤติกรรม ตัวอย่างเช่น คุณสามารถ Import แบบระบุชื่อ (Named Export) ได้:

// math.js

export function add(a, b) {
  return a + b;
}

แล้วนำไปใช้ในไฟล์อื่น:

// index.js

import { add } from './math';

console.log(add(2, 3)); // ผลลัพธ์: 5

ในตัวอย่างนี้ เราสร้าง Module ชื่อ math.js ที่ Export ฟังก์ชันแบบระบุชื่อว่า add จากนั้นเราใช้คำสั่ง import เพื่อโหลดฟังก์ชัน add จาก Module math.js มาใช้บวกเลขสองจำนวน

สรุป

Module ช่วยให้เราแยกโค้ดตามหน้าที่และนำกลับมาใช้ซ้ำได้ เมื่อเข้าใจการสร้าง, Import และ Export แล้ว การจัดระเบียบแอป Node.js ขนาดใหญ่ก็จะง่ายขึ้นมาก
