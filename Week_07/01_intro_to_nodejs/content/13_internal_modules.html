Internal Modules (โมดูลที่มากับ Node.js)

Internal Module ใน Node.js หมายถึง Module ที่มีมาให้ในตัวและพร้อมใช้งานภายในสภาพแวดล้อมของ Node.js Module เหล่านี้เป็นส่วนหนึ่งของแกนหลัก (Core) ของ Node.js และมอบความสามารถกับเครื่องมือหลากหลายที่คุณนำไปใช้ในแอปพลิเคชันได้ทันที โดยไม่ต้องติดตั้งแพ็กเกจจากภายนอกเพิ่มเติม

Internal Module ที่มีให้ใช้งาน

Node.js มี Internal Module ให้ใช้งานหลายตัว รวมถึง (แต่ไม่จำกัดเพียง):

  • fs — ใช้สำหรับการทำงานกับระบบไฟล์
  • http — ใช้สำหรับสร้าง HTTP Server และ Client
  • path — ใช้สำหรับทำงานกับ Path ของไฟล์
  • os — ใช้สำหรับดึงข้อมูลที่เกี่ยวข้องกับระบบปฏิบัติการ
  • crypto — ใช้สำหรับงานด้านการเข้ารหัส

วิธีใช้งาน

ในการใช้ Module เหล่านี้ในแอปพลิเคชัน Node.js ของคุณ คุณต้อง Import เข้ามาด้วยฟังก์ชัน require() ตัวอย่างเช่น หากต้องการใช้ Module fs เพื่ออ่านไฟล์ในแอปของคุณ ให้เขียนแบบนี้:

const fs = require('fs');
fs.readFile('file.txt', (err, data) => {
  if (err) throw err;
  console.log(data);
});

ตั้งแต่ Node.js เวอร์ชัน 13 เป็นต้นไป คุณสามารถใช้รูปแบบ ES6 Module เพื่อ Import Internal Module ได้เช่นกัน

import fs from 'fs';

ส่วนใน Node.js V18 คุณสามารถระบุให้ชัดเจนว่ากำลัง Import Core Module หรือ Internal Module ได้แบบนี้:

import fs from 'node:fs'

การใช้ Prefix node: ไม่ได้เปลี่ยนพฤติกรรมของการ Import แต่อย่างใด มันเป็นเพียงวิธีระบุให้ชัดเจนว่า Module นี้เป็น Core Module ไม่ใช่ Module จากภายนอก

สรุป

โดยสรุปแล้ว Internal Module ใน Node.js คือ Module ที่มีมาให้ในตัว ซึ่งมอบความสามารถและเครื่องมือที่หลากหลาย คุณสามารถ Import มันเข้ามาได้ทั้งด้วยฟังก์ชัน require() หรือด้วยรูปแบบ ES6 Module ขึ้นอยู่กับเวอร์ชันของ Node.js ที่คุณใช้ และประเภทของ Module ที่คุณต้องการ Import
