Internal Modules (โมดูลที่มากับ Node.js)

Internal Module คือ Module ที่ติดมากับ Node.js และเป็นส่วนหนึ่งของแกนหลัก (Core) เราจึงเรียกใช้เครื่องมือเหล่านี้ในแอปได้ทันทีโดยไม่ต้องติดตั้งแพ็กเกจเพิ่ม

Internal Module ที่มีให้ใช้งาน

Internal Module ที่ใช้กันบ่อยมีดังนี้:

  • fs — ใช้สำหรับการทำงานกับระบบไฟล์
  • http — ใช้สำหรับสร้าง HTTP Server และ Client
  • path — ใช้สำหรับทำงานกับ Path ของไฟล์
  • os — ใช้สำหรับดึงข้อมูลที่เกี่ยวข้องกับระบบปฏิบัติการ
  • crypto — ใช้สำหรับงานด้านการเข้ารหัส

วิธีใช้งาน

เรานำ Module เหล่านี้เข้ามาใช้ด้วย require() ได้ ตัวอย่างนี้โหลด fs เพื่ออ่านไฟล์:

const fs = require('fs');
fs.readFile('file.txt', (err, data) => {
  if (err) throw err;
  console.log(data);
});

ตั้งแต่ Node.js เวอร์ชัน 13 เป็นต้นไป คุณสามารถใช้รูปแบบ ES6 Module เพื่อ Import Internal Module ได้เช่นกัน

import fs from 'fs';

ส่วนใน Node.js V18 คุณสามารถระบุให้ชัดเจนว่ากำลัง Import Core Module หรือ Internal Module ได้แบบนี้:

import fs from 'node:fs'

Prefix node: ไม่ได้เปลี่ยนวิธีทำงาน เพียงช่วยให้คนอ่านเห็นทันทีว่านี่คือ Core Module ไม่ใช่แพ็กเกจจากภายนอก

สรุป

สรุปคือ Internal Module ช่วยให้เราเข้าถึงความสามารถพื้นฐานของ Node.js ได้ทันที จะโหลดด้วย require() หรือรูปแบบ ES Modules ก็เลือกให้ตรงกับระบบ Module ที่โปรเจกต์ใช้อยู่
