การเขียน Unit Test ด้วย Jest

Jest คือ Framework สำหรับการทดสอบ JavaScript ที่ได้รับความนิยม มันมอบวิธีการเขียนเทสต์และรันเทสต์ที่เรียบง่าย

จำได้ไหมว่าในบทที่ 19 เราตั้งใจแยกฟังก์ชันจัดการ Array ออกจากฟังก์ชันอ่านเขียนไฟล์ ตอนนี้แหละที่เราจะได้เก็บเกี่ยวผลของการแยกนั้น เพราะ addTodo, markDone และ removeTodo ไม่ยุ่งกับไฟล์เลย เราจึงทดสอบมันได้ตรง ๆ แค่ส่ง Array เข้าไปแล้วดูว่าได้ Array อะไรออกมา ไม่ต้องเตรียมไฟล์ ไม่ต้องลบไฟล์ทิ้งหลังเทสต์เสร็จ

ติดตั้ง Jest

npm i -D jest

Flag -D ย่อมาจาก --save-dev หมายความว่าแพ็กเกจนี้จำเป็นตอนพัฒนาเท่านั้น ไม่ได้จำเป็นตอนที่ผู้ใช้เอาแอปเราไปใช้จริง มันจะถูกบันทึกไว้ใน devDependencies แยกออกจาก dependencies

ต่อไปให้เพิ่ม Script ลงใน package.json:

"scripts": {
  "test": "node --experimental-vm-modules node_modules/jest/bin/jest.js"
}

ปกติเราเขียนแค่ "test": "jest" ก็พอ แต่เพราะโปรเจกต์เราใช้ import / export แบบ ES Modules ซึ่ง Jest ยังรองรับได้ไม่เต็มที่ เราจึงต้องเปิด Flag ตัวนี้ให้มัน ตรงนี้ไม่ต้องจำ Copy ไปวางได้เลย

เขียนเทสต์

ให้สร้างโฟลเดอร์ tests ไว้ที่ Root แล้วสร้างไฟล์ todos.test.js:

import { addTodo, markDone, removeTodo } from '../src/todos.js'

test('addTodo เพิ่มรายการใหม่เข้าไปใน Array', () => {
  const todos = []
  const result = addTodo(todos, 'ซื้อนม')

  expect(result).toHaveLength(1)
  expect(result[0].text).toBe('ซื้อนม')
  expect(result[0].done).toBe(false)
})

test('markDone เปลี่ยน done ของรายการที่ตรงกับ id เป็น true', () => {
  const todos = [
    { id: 1, text: 'ซื้อนม', done: false },
    { id: 2, text: 'อ่านหนังสือ', done: false },
  ]
  const result = markDone(todos, 2)

  expect(result[0].done).toBe(false)
  expect(result[1].done).toBe(true)
})

test('removeTodo ลบรายการที่ตรงกับ id ออกไป', () => {
  const todos = [
    { id: 1, text: 'ซื้อนม', done: false },
    { id: 2, text: 'อ่านหนังสือ', done: false },
  ]
  const result = removeTodo(todos, 1)

  expect(result).toHaveLength(1)
  expect(result[0].id).toBe(2)
})

โครงสร้างของเทสต์

ทุกเทสต์มีรูปแบบเหมือนกันหมด 3 ขั้นตอน:

  1. เตรียมข้อมูล — สร้าง Array ที่เราอยากทดสอบขึ้นมาเอง
  2. เรียกฟังก์ชัน — เอา Array นั้นส่งเข้าไปแล้วรับผลลัพธ์
  3. ตรวจผลลัพธ์ — ใช้ expect เช็คว่าได้ตามที่คาดไว้หรือไม่

ฟังก์ชัน test รับสองอย่างคือชื่อเทสต์ที่อธิบายว่ากำลังทดสอบอะไร กับฟังก์ชันที่มีโค้ดเทสต์อยู่ข้างใน ส่วน expect ใช้คู่กับ Matcher เพื่อบอกว่าเราคาดหวังอะไร เช่น toBe เช็คว่าเท่ากันเป๊ะ ๆ และ toHaveLength เช็คความยาวของ Array

สังเกตว่าเทสต์ของ markDone เราไม่ได้เช็คแค่ว่ารายการที่ 2 เปลี่ยนเป็น true แต่เช็คด้วยว่ารายการที่ 1 ยังเป็น false อยู่ เพราะถ้าเราเผลอเขียนโค้ดผิดจนมันเปลี่ยนทุกตัวเป็นเสร็จหมด เทสต์ตัวนี้จะจับได้

รันเทสต์

npm test

Jest จะหาไฟล์ที่ลงท้ายด้วย .test.js ให้เองอัตโนมัติแล้วรันทั้งหมด ผลลัพธ์จะออกมาประมาณนี้:

Test Suites: 1 passed, 1 total
Tests:       3 passed, 3 total
Snapshots:   0 total
Time:        0.157 s
Ran all test suites.

ลองแกล้งทำให้เทสต์พังดูก็ได้ เช่น เข้าไปแก้ removeTodo ใน src/todos.js จาก !== เป็น === แล้วรัน npm test อีกครั้ง Jest จะบอกทันทีว่าเทสต์ไหนพัง คาดหวังอะไร และได้อะไรมาแทน อย่าลืมแก้กลับด้วยล่ะ
