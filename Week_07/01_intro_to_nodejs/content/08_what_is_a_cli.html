CLI คืออะไร?

Command-Line Interface (CLI) คือหน้าติดต่อโปรแกรมแบบข้อความ เราสั่งงานด้วยการพิมพ์คำสั่งแทนการกดปุ่มบนหน้าจอ นักพัฒนาและผู้ดูแลระบบจึงนิยมใช้ CLI กับงานที่ต้องทำเร็ว ๆ หรือทำซ้ำบ่อย ๆ

การใช้คำสั่ง CLI บน Bash

คำสั่ง Bash พื้นฐานตรงไปตรงมา: ใช้ ls ดูไฟล์ในโฟลเดอร์, cd ย้ายโฟลเดอร์ และ rm ลบไฟล์ เรายังเติม Flag และ Argument เพื่อระบุรายละเอียดให้แต่ละคำสั่งได้ด้วย

Flag และ Argument

Flag คือตัวเลือกที่ปรับพฤติกรรมของคำสั่ง เช่น เติม -a หลัง ls เพื่อให้แสดงไฟล์ที่ซ่อนไว้

ส่วน Argument คือข้อมูลที่ส่งให้คำสั่ง เช่น mkdir ต้องรับชื่อโฟลเดอร์ที่เราต้องการสร้างเป็น Argument

การสร้าง CLI ด้วย Node.js

การสร้าง CLI ด้วย Node.js เป็นทางเลือกยอดนิยมของนักพัฒนา เพราะช่วยให้คุณสร้าง CLI ของตัวเองขึ้นมาเพื่อทำงานเฉพาะทางได้ ในโปรเจกต์ขนาดใหญ่ที่มีคำสั่งและ Flag เยอะมาก ๆ นักพัฒนามักใช้ไลบรารีจากภายนอกอย่าง commander หรือ yargs มาช่วยอ่านค่า Argument ให้

แต่ในคอร์สนี้เราจะเขียนส่วนนั้นเองทั้งหมด เพราะแอปของเรามีแค่ไม่กี่คำสั่ง และการลงมือทำเองจะทำให้คุณเห็นชัดว่าจริง ๆ แล้วไลบรารีพวกนั้นทำอะไรให้เราบ้าง ซึ่งเอาเข้าจริงมันไม่ได้ซับซ้อนอย่างที่คิด

ติดตั้งแบบ Global หรือ Local?

ตอนติดตั้ง CLI เราเลือกได้ว่าจะติดตั้งแบบ Global หรือ Local แบบ Global เรียกใช้ได้จากทุกโฟลเดอร์ในเครื่อง ส่วนแบบ Local จะผูกอยู่กับโปรเจกต์ที่ติดตั้งไว้

การติดตั้ง CLI

เราใช้ npm ติดตั้ง CLI ที่เผยแพร่ไว้ในแพ็กเกจของ Node.js ได้ ตัวอย่างนี้ติดตั้ง create-react-app แบบ Global:

npm install -g create-react-app
