แนะนำคอร์สเรียน

ยินดีต้อนรับสู่คอร์ส Node.js เบื้องต้น! เราจะเริ่มตั้งแต่ Node.js คืออะไร มีที่มาอย่างไร ไปจนถึงการติดตั้งและใช้งานจริง

จากนั้นเราจะลองสร้าง Command Line Interface (CLI), ทำความรู้จัก npm และ Module, อ่านเขียนไฟล์, ติดตั้ง Module ผ่าน npm, เขียนเทสต์ด้วย Jest และสร้าง HTTP Server ขนาดเล็กที่รับ Request และเปิดหน้าเว็บได้

แทนที่จะเรียนแต่ทฤษฎี เราจะค่อย ๆ นำทุกเรื่องมาประกอบเป็นแอป Todo แบบ CLI พร้อมหน้าเว็บง่าย ๆ สำหรับดูผลลัพธ์

เนื้อหาที่จะได้เรียน

เราจะเรียนพื้นฐาน Node.js ไปพร้อมกับสร้างแอป Todo ที่ทำงานผ่าน CLI คุณจะเพิ่มรายการ ดูงานที่ค้างอยู่ และติดตามความคืบหน้าได้จาก Terminal โดยตรง

วิธีเรียนคอร์สนี้

แนะนำให้เปิดบทเรียนนี้ควบคู่กับวิดีโอหรือเวิร์กช็อป แล้วเรียนตามจังหวะนี้:

  1. ผู้สอนจะแนะนำแนวคิด (Concept) หนึ่งเรื่อง
  2. ผู้สอนจะเขียนโค้ดสาธิตตัวอย่างของแนวคิดนั้นให้ดูสด ๆ
  3. จากนั้นเราจะนำสิ่งที่เรียนมาต่อยอดพัฒนาแอป Todo ของเราให้สมบูรณ์ยิ่งขึ้น

ลองพิมพ์โค้ดตามระหว่างดูตัวอย่างและต่อยอดแอป Todo หากช่วงไหนตามไม่ทันก็ไม่เป็นไร คุณยังเปิดดูโค้ดฉบับสมบูรณ์ใน Repository เพื่อเทียบหรือทบทวนภายหลังได้เสมอ

สิ่งที่คุณจะได้รับ

  • คุณจะเข้าใจว่า Node.js คืออะไร
  • คุณจะมีพื้นฐานที่แน่นพอที่จะต่อยอดไปเรียนรู้การสร้างแอปพลิเคชันที่ใช้งานได้จริง

ประเด็นสำคัญ

เมื่อเรียนจบ คุณจะเข้าใจพื้นฐาน Node.js มากพอที่จะเริ่มสร้างแอปจริงและเรียนเรื่องที่ลึกขึ้นต่อได้ ไม่ว่าจะเพิ่งเริ่มเขียนโปรแกรมหรือมีประสบการณ์มาแล้ว คอร์สนี้จะช่วยให้เห็นภาพว่า Node.js ทำอะไรได้และควรหยิบมาใช้เมื่อไร
