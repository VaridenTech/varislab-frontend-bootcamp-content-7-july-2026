โปรแกรม Node.js แรกของคุณ (Hello World)

มาเขียนโปรแกรม Node.js ตัวแรกกันเลย โปรแกรม Node.js หน้าตาเป็นอย่างไร? ง่ายมาก—มันก็คือไฟล์ JavaScript ที่เราคุ้นเคยนั่นเอง

console.log('hello world')

เมื่อมีไฟล์แล้ว ขั้นต่อไปคือรันมันด้วย Node CLI เปิด Terminal แล้วพิมพ์:

node index.js

Node CLI จะรันไฟล์ JavaScript ตาม Path ที่ระบุ เท่านี้โปรแกรมแรกของคุณก็ทำงานแล้ว

ถ้าทุกอย่างถูกต้อง คุณจะเห็น hello world ใน Terminal เพราะ Console ของโปรแกรม Node.js จะแสดงผลตรงนั้น

ลองทำแบบฝึกหัด

ลองสร้างไฟล์ index.js แล้วเขียนโค้ดให้แสดงชื่อของคุณทาง Console จากนั้นรันไฟล์ด้วย Node CLI

ดูเฉลย 
// index.js
console.log('สวัสดี ผมชื่อ Scott')

จากนั้นรันด้วยคำสั่ง:

node index.js
