การเขียนฟังก์ชัน CRUD สำหรับ Todo

CRUD ย่อมาจาก Create, Read, Update และ Delete ซึ่งเป็นการทำงานพื้นฐาน 4 อย่างที่แทบทุกแอปต้องมี ในแอปของเรามันตรงกับคำสั่งที่เราวางไว้พอดี:

  • Create — เพิ่มรายการใหม่ (คำสั่ง add)
  • Read — ดูรายการทั้งหมด (คำสั่ง list)
  • Update — แก้ไขรายการที่มีอยู่ ในที่นี้คือทำเครื่องหมายว่าเสร็จแล้ว (คำสั่ง done)
  • Delete — ลบรายการทิ้ง (คำสั่ง remove)

แนวคิดสำคัญ: ฟังก์ชันที่ไม่ยุ่งกับไฟล์

ก่อนจะเขียนโค้ด มีเรื่องหนึ่งที่อยากให้สังเกต ฟังก์ชันที่เราจะเขียนต่อไปนี้จะไม่อ่านและไม่เขียนไฟล์เลย มันแค่รับ Array เข้ามา แล้วคืน Array ใหม่กลับไปเท่านั้น

ฟังก์ชันแบบนี้เรียกว่า Pure Function ซึ่งมีข้อดีคือ:

  • อ่านง่าย เพราะดูแค่ตัวมันเองก็รู้ว่าทำอะไร ไม่ต้องไปตามดูว่าไฟล์ข้างนอกมีอะไรอยู่
  • ทดสอบง่ายมาก เดี๋ยวในบทที่ 22 เราจะเขียนเทสต์ให้ฟังก์ชันพวกนี้ แล้วคุณจะเห็นว่ามันง่ายแค่ไหน

ส่วนงานอ่านเขียนไฟล์จริง ๆ เราแยกไปไว้ที่ readTodos กับ saveTodos ที่เขียนไว้แล้วในบทที่แล้ว

เขียนต่อในไฟล์ todos.js

ให้เขียนโค้ดต่อไปนี้ต่อท้ายไฟล์ src/todos.js ที่เราสร้างไว้ในบทที่แล้ว:

// --- ส่วนที่แก้ไข Array เฉย ๆ ---

const nextId = (todos) => {
  if (todos.length === 0) return 1
  return Math.max(...todos.map(todo => todo.id)) + 1
}

export const addTodo = (todos, text) => {
  const todo = { id: nextId(todos), text, done: false }
  return [...todos, todo]
}

export const markDone = (todos, id) => {
  return todos.map(todo => todo.id === id ? { ...todo, done: true } : todo)
}

export const removeTodo = (todos, id) => {
  return todos.filter(todo => todo.id !== id)
}

คำอธิบายโค้ด

  • nextId คำนวณ ID ของรายการถัดไป ถ้ายังไม่มีรายการเลยก็เริ่มที่ 1 ถ้ามีแล้วก็หา ID ที่มากที่สุดแล้วบวกหนึ่ง ที่ต้องทำแบบนี้เพราะถ้าเราใช้ todos.length + 1 เฉย ๆ พอผู้ใช้ลบรายการไปแล้ว ID จะซ้ำกันได้ ส่วน ... ที่อยู่ใน Math.max(...) คือ Spread Operator ที่กระจาย Array ออกมาเป็น Argument ทีละตัว เพราะ Math.max รับตัวเลขทีละตัว ไม่ได้รับ Array
  • addTodo สร้าง Object ของรายการใหม่ แล้วคืน Array ใหม่ที่มีของเดิมทั้งหมดบวกตัวใหม่ต่อท้าย สังเกตว่าเราใช้ [...todos, todo] ไม่ใช่ todos.push(todo) เพราะเราไม่อยากไปแก้ Array เดิม แต่อยากสร้างอันใหม่ขึ้นมาแทน
  • markDone ใช้ map วนดูทุกรายการ ถ้าเจอตัวที่ ID ตรงกันก็คืน Object ใหม่ที่ done เป็น true ส่วนตัวอื่นคืนกลับไปเหมือนเดิม
  • removeTodo ใช้ filter เก็บเฉพาะรายการที่ ID ไม่ตรงกับที่ระบุ ผลลัพธ์คือ Array ที่ไม่มีรายการนั้นแล้ว

เมธอด map, filter และ Spread Operator เหล่านี้คือตัวเดียวกันกับที่เราใช้ตอนจัดการ State ใน React นั่นเอง หลักการเหมือนกันเป๊ะ คือไม่แก้ของเดิม แต่สร้างของใหม่ขึ้นมาแทน

แล้ว Read ล่ะ? เราไม่ต้องเขียนฟังก์ชันเพิ่มเลย เพราะ readTodos ที่เขียนไว้แล้วก็คืน Array ทั้งหมดมาให้อยู่แล้ว
