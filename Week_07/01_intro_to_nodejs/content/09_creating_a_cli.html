การสร้าง CLI ด้วย Node.js

แอปที่เราจะสร้างกัน

ตลอดคอร์ส เราจะค่อย ๆ ต่อแอป Todo ที่ใช้งานผ่าน Terminal ทีละส่วน เมื่อเรียนจบ CLI ตัวนี้จะทำสิ่งต่อไปนี้ได้:

todo add "ซื้อนม"     # เพิ่มรายการใหม่
todo list             # ดูรายการทั้งหมด
todo done 3           # ทำเครื่องหมายว่าเสร็จแล้ว
todo remove 3         # ลบรายการทิ้ง
todo web              # เปิดดูรายการบน Browser

ทั้งหมดนี้เราจะเขียนด้วย Node.js ล้วน ๆ โดยไม่ติดตั้งแพ็กเกจภายนอกเลยสักตัว

พื้นฐานของ CLI

เริ่มด้วยการสร้างโปรเจกต์ Node.js ใหม่ผ่าน npm CLI:

npm init

init จะสร้าง package.json ไว้ที่ Root ของโฟลเดอร์ที่รันคำสั่ง ยังไม่ต้องกังวลว่าไฟล์นี้ทำอะไร เดี๋ยวเราจะกลับมาอธิบายอีกครั้ง

ต่อไปสร้าง index.js ที่ Root เพื่อเป็นไฟล์หลักของ CLI แล้วใส่ console.log ไว้ทดสอบก่อน

บทนี้เราจะเริ่มจากงานง่ายที่สุด คือรับข้อความสำหรับรายการใหม่ สิ่งที่ต้องเตรียมมีสามอย่าง:

  1. คำสั่งที่ใช้ได้ใน Terminal
  2. ความสามารถที่ทำให้คำสั่งนั้นรับ Argument ได้
  3. การนำค่าของ Argument นั้นมาใช้สร้างรายการใหม่

การลงทะเบียนชื่อคำสั่ง

เริ่มจากการสร้างคำสั่งที่เราจะใช้ใน Terminal ก่อน วิธีทำคือเราต้องลงทะเบียนชื่อคำสั่งไว้ใน package.json:

{
  "name": "todo",
  "type": "module",
  "bin": {
    "todo": "./index.js"
  }
}

ชื่อใต้ Field bin จะกลายเป็นคำสั่งที่เราใช้เรียก CLI จาก Terminal จะตั้งชื่ออะไรก็ได้ แต่ในคอร์สนี้เราเลือก todo

ค่าที่อยู่คู่กันคือ Path ของไฟล์ JavaScript เมื่อผู้ใช้เรียก todo Node.js จึงรู้ว่าต้องรันไฟล์ไหน

ส่วน "type": "module" เป็นการบอก Node.js ว่าเราจะเขียนโค้ดด้วย import / export แบบสมัยใหม่ ซึ่งเป็นแบบเดียวกับที่เราใช้ตอนเขียน React เดี๋ยวเราจะพูดถึงเรื่องนี้อย่างละเอียดในบทที่ 11

Hashbang

เครื่องของเราอาจติดตั้งตัวแปลภาษาหลายตัว เช่น Python, Ruby และ Node.js ระบบปฏิบัติการจึงต้องมีคำใบ้ว่าควรใช้ตัวไหนรันไฟล์นี้ ให้เพิ่มบรรทัดต่อไปนี้ไว้บนสุดของไฟล์ JavaScript:

#!/usr/bin/env node

บรรทัดนี้เรียกว่า Hashbang เป็นคอมเมนต์พิเศษที่บอกระบบปฏิบัติการให้ใช้ Node.js เป็นตัวแปลภาษาสำหรับสคริปต์นี้

การสร้าง Symlink ด้วย npm link

ต่อไปเราต้องทำให้ CLI เรียกใช้จากเครื่องได้ ระหว่างพัฒนาเราไม่จำเป็นต้องติดตั้งแบบ Global แต่สร้าง Symlink แทนได้

Symlink หรือ Symbolic Link คือไฟล์อ้างอิงที่ชี้ไปยังไฟล์หรือโฟลเดอร์จริง เมื่อสร้าง Symlink ให้ CLI แล้ว เราจะเรียก todo จากโฟลเดอร์ไหนในเครื่องก็ได้ โดยไม่ต้องย้ายเข้าไปยังโฟลเดอร์ที่เก็บโค้ดก่อน

การสร้าง Symlink ทำได้ด้วยคำสั่ง npm link ซึ่งจะสร้าง Symlink จากแพ็กเกจ npm ที่ติดตั้งแบบ Global ไปยังโค้ดที่เก็บอยู่ในเครื่อง ให้รันคำสั่ง:

npm link

ตอนนี้เราน่าจะรันคำสั่ง todo ใน Terminal และเห็นผลลัพธ์จาก Log ของเราได้แล้ว ลองดูสิ!

todo

Logic ของรายการ Todo

ตอนนี้เรามี CLI ที่ใช้งานได้แล้ว มาเริ่มสร้าง Logic กันเลย ตอนนี้เราต้องการรับข้อความบางอย่างจาก Terminal มาเป็นรายการใหม่ ส่วนจะเอาข้อมูลนั้นไปทำอะไรต่อนั้นค่อยว่ากันทีหลัง ตอนนี้แค่ทำให้มั่นใจว่าเราอ่านค่านั้นได้ก่อน

วิธีทำคือเราสามารถเข้าถึงข้อมูลผ่าน process ได้ ดังนั้นในไฟล์ index.js ของเรา:

// index.js
const text = process.argv[2]
const newTodo = {
  id: 1,
  text,
  done: false,
}
console.log('รายการใหม่ของคุณ', newTodo)

โค้ดด้านบนตั้งสมมติฐานว่าอะไรก็ตามที่คุณพิมพ์ต่อท้ายคำสั่ง todo จะถือเป็นข้อความของรายการ จากนั้นมันจะนำข้อความนั้นมาสร้างเป็น Object ใหม่แล้วแสดงผลออกมา ง่ายมาก ดังนั้นคำสั่งจะเป็นแบบนี้:

todo "ซื้อนม"

จะได้ผลลัพธ์:

รายการใหม่ของคุณ { id: 1, text: 'ซื้อนม', done: false }

สังเกตว่าผมใส่ข้อความไว้ในเครื่องหมายคำพูด เพื่อไม่ให้ Terminal คิดว่าแต่ละคำคือ Argument ตัวใหม่ แต่ให้มองว่าข้อความทั้งก้อนคือ Argument ตัวเดียว

สังเกตอีกอย่างว่า Object ของเรามีแค่ 3 Field เท่านั้น คือ id ไว้อ้างอิงตอนสั่ง done หรือ remove, text คือข้อความ และ done คือสถานะว่าทำเสร็จหรือยัง เท่านี้พอสำหรับแอปของเรา

ก้าวต่อไป

แบบนี้ก็ดูดีแล้ว แต่ยังมีปัญหาอยู่สองข้อ ข้อแรกคือรายการของเราหายไปทุกครั้งที่โปรแกรมจบ เราจึงต้องหาที่เก็บมันไว้ ข้อสองคือตอนนี้ CLI ของเราทำได้อย่างเดียวคือเพิ่มรายการ แต่เราอยากได้ list, done และ remove ด้วย

ก่อนจะไปถึงตรงนั้น เราควรรู้จักวิธีแบ่งโค้ดออกเป็นไฟล์ย่อย ๆ ก่อน ไม่อย่างนั้นทุกอย่างจะกองรวมกันอยู่ใน index.js ไฟล์เดียว แล้ว Module คืออะไรล่ะ? เราจะพูดถึงเรื่องนี้ในบทถัดไป!
