Browser vs. Node.js: ความแตกต่าง

JavaScript รันได้ทั้งใน Browser และบนเซิร์ฟเวอร์ผ่าน Node.js แม้จะใช้ภาษาเดียวกัน แต่เครื่องมือและสิ่งที่โค้ดเข้าถึงได้ในสองสภาพแวดล้อมนี้ไม่เหมือนกัน

Global Object

ใน Browser ตัว Global Object คือ window ส่วน Node.js ใช้ global หากอยากดู Global Object ใน Browser ให้ใช้:

console.log(window);

ส่วนบน Node.js เราใช้:

console.log(global);

Modules

บน Browser เราสามารถ Import Module ได้โดยใช้แท็ก script พร้อมกำหนด Attribute type เป็น module และกำหนด Attribute src เป็น Path ของไฟล์ Module ตัวอย่างเช่น:

<script type="module" src="./module.js"></script>

จากนั้นไฟล์หลักก็ Import ฟังก์ชันที่ Export ไว้มาใช้ได้ ตัวอย่างนี้นำ sayHello จาก module.js เข้ามา:

import { sayHello } from './module.js';
sayHello();

ฝั่ง Node.js เราโหลด Module ด้วย require หรือ import:

import { module } from './module.js';

DOM

Browser มี Document Object Model (DOM) ที่ช่วยให้เราโต้ตอบกับ HTML Element ได้ ตัวอย่างเช่น หากต้องการเปลี่ยนข้อความของ HTML Element บน Browser เราใช้:

document.getElementById('elementId').innerHTML = 'New text';

แต่ใน Node.js ไม่มี DOM ดังนั้นเราจึงไม่สามารถเข้าถึงหรือแก้ไข HTML Element ได้

Server vs. Website

Node.js ถูกใช้เป็นหลักในการสร้างแอปพลิเคชันฝั่งเซิร์ฟเวอร์ ในขณะที่ Browser ถูกใช้สำหรับแสดงเว็บไซต์ ตัวอย่างเช่น เราสามารถสร้างเซิร์ฟเวอร์อย่างง่ายใน Node.js ได้ดังนี้:

const http = require('http');

const server = http.createServer((req, res) => {
  res.write('Hello World!');
  res.end();
});

server.listen(3000);

ในทางกลับกัน บน Browser เราจะสร้างเว็บไซต์ด้วย HTML, CSS และ JavaScript

Console

Object console ทำงานเหมือนกันทั้งบน Browser และ Node.js ตัวอย่างเช่น หากต้องการแสดงข้อความบน Browser เราใช้:

console.log('Hello World!');

เช่นเดียวกัน บน Node.js เราก็ใช้:

console.log('Hello World!');

ประเด็นสำคัญ

สรุปคือภาษา JavaScript เหมือนเดิม แต่ Browser กับ Node.js มี API และหน้าที่ต่างกัน หากคุณเขียน JavaScript เป็นอยู่แล้ว การเริ่มใช้ Node.js จะไม่ไกลเกินเอื้อม

จำให้ได้ว่าโค้ดกำลังรันอยู่ที่ไหน แล้วคุณจะเลือกใช้ Global Object, Module และ API ได้ถูกกับสภาพแวดล้อมนั้น
