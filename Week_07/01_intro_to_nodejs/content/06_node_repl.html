การใช้งาน Node REPL

Node.js มีเครื่องมือชื่อ REPL (Read-Eval-Print-Loop) ให้เราพิมพ์ JavaScript ใน Terminal แล้วดูผลลัพธ์ได้ทันที โดยไม่ต้องสร้างไฟล์ก่อน

นึกภาพว่า REPL คือ Command-line Interface สำหรับ JavaScript เราพิมพ์โค้ดทีละบรรทัดแล้วเห็นคำตอบตรงนั้นเลย จึงเหมาะกับการลองโค้ดสั้น ๆ หรือตรวจว่าแนวคิดหนึ่งทำงานอย่างที่คิดหรือไม่

วิธีเริ่มใช้งาน

เริ่มใช้งานได้ง่าย ๆ แค่เปิด Terminal แล้วพิมพ์ node เมื่อเห็น Prompt ของ Node REPL ก็เริ่มพิมพ์ JavaScript ได้เลย

ตัวอย่างการใช้งาน Node REPL

// การคำนวณพื้นฐาน
> 2 + 2
4

// การจัดการข้อความ (String)
> 'hello, world'.toUpperCase()
'HELLO, WORLD'

// การประกาศตัวแปร
> var x = 10
undefined
> x
10

// การใช้งานฟังก์ชัน
> function add(a, b) { return a + b }
undefined
> add(3, 5)
8

ข้อดีและข้อจำกัด

REPL เหมาะกับการลองไอเดียเร็ว ๆ, Debug โค้ดสั้น ๆ หรือทำต้นแบบก่อนย้ายโค้ดเข้าโปรเจกต์จริง

แต่ REPL ไม่ได้แทน IDE หรือ Text Editor เพราะไม่ได้ออกแบบมาสำหรับโค้ดขนาดใหญ่และไม่มีเครื่องมือช่วยครบเท่า ดังนั้นใช้มันเป็นกระดาษทดเล็ก ๆ ระหว่างพัฒนาจะเหมาะที่สุด

สรุปสั้น ๆ: ถ้าอยากรู้ว่า JavaScript บรรทัดหนึ่งให้ผลอะไร เปิด REPL แล้วลองได้ทันที
