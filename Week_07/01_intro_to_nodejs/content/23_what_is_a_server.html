Server คืออะไร?

ในบริบทของ Node.js นั้น Server คือโปรแกรมที่คอยรับ Request ที่เข้ามาทางเครือข่าย และตอบสนองต่อ Request เหล่านั้นด้วยการรันโค้ดหรือส่งข้อมูลกลับไป Server เป็นรากฐานสำคัญของสถาปัตยกรรมเว็บแอปพลิเคชัน และทำให้เกิดการสื่อสารระหว่าง Client (เช่น แอปมือถือหรือเว็บไซต์) กับฐานข้อมูลหรือบริการ Backend อื่น ๆ

ตัวอย่าง Server อย่างง่าย

นี่คือตัวอย่างของ Server อย่างง่ายที่เขียนด้วย Node.js ซึ่งคอยรับ Request ที่ Port 3000 และตอบกลับทุก Request ที่เข้ามาด้วยข้อความ "Hello, World!":

const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader('Content-Type', 'text/plain');
  res.end('Hello, World!');
});

server.listen(3000, () => {
  console.log('Server running on port 3000');
});

Server ต่างจาก Client อย่างไร

ความแตกต่างที่สำคัญอย่างหนึ่งระหว่าง Server กับแอปฝั่ง Client อย่างแอปมือถือหรือเว็บไซต์ คือ Server มีหน้าที่จัดการข้อมูลและสถานะ (State) ในขณะที่ Client มีหน้าที่นำเสนอข้อมูลนั้นให้ผู้ใช้เห็น Server จะทำงานอยู่ตลอดเวลาและพร้อมตอบสนอง Request เสมอ ในขณะที่ Client จะทำงานเฉพาะตอนที่ผู้ใช้กำลังโต้ตอบกับมันเท่านั้น

ความแตกต่างสำคัญอีกอย่างคือ โดยทั่วไป Server จะทำงานอยู่บนเครื่องคนละเครื่องกับแอปฝั่ง Client สิ่งนี้ทำให้ Server สามารถรับผิดชอบงานที่ต้องใช้การประมวลผลหนัก รวมถึงจัดการการจัดเก็บและเรียกดูข้อมูล ในขณะที่แอปฝั่ง Client สามารถมุ่งเน้นไปที่การมอบประสบการณ์การใช้งานที่ลื่นไหลให้ผู้ใช้

สรุป

โดยรวมแล้ว Server เป็นส่วนประกอบที่สำคัญอย่างยิ่งของเว็บแอปพลิเคชันสมัยใหม่ และเป็นแกนหลักของการสื่อสารระหว่าง Client กับบริการต่าง ๆ ในฝั่ง Backend
