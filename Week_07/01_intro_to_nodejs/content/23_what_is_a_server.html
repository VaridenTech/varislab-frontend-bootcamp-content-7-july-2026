Server คืออะไร?

Server คือโปรแกรมที่รอรับ Request ผ่านเครือข่าย แล้วรันโค้ดหรือส่งข้อมูลกลับไป มันทำหน้าที่เป็นตัวกลางระหว่าง Client เช่น แอปมือถือหรือเว็บไซต์ กับฐานข้อมูลและบริการ Backend อื่น ๆ

ตัวอย่าง Server อย่างง่าย

ตัวอย่างนี้สร้าง Server ขนาดเล็กด้วย Node.js รอรับ Request ที่ Port 3000 และตอบทุก Request ด้วยข้อความ "Hello, World!":

const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader('Content-Type', 'text/plain');
  res.end('Hello, World!');
});

server.listen(3000, () => {
  console.log('Server running on port 3000');
});

Server ต่างจาก Client อย่างไร

โดยทั่วไป Server ดูแลข้อมูลและสถานะ (State) ส่วน Client อย่างแอปมือถือหรือเว็บไซต์นำข้อมูลมาแสดงให้ผู้ใช้ Server มักเปิดรอ Request อยู่ตลอด ขณะที่ Client ทำงานตามการโต้ตอบของผู้ใช้

Server มักรันอยู่คนละเครื่องกับ Client จึงรับงานประมวลผล การจัดเก็บ และการเรียกดูข้อมูลไว้ส่วนกลางได้ ส่วน Client ก็โฟกัสกับการแสดงผลและประสบการณ์ใช้งาน

สรุป

พูดง่าย ๆ คือ Client เป็นฝ่ายขอ ส่วน Server เป็นฝ่ายรับคำขอและตอบกลับ บทถัดไปเราจะสร้าง Server ของแอป Todo ด้วยตัวเอง
