ประวัติความเป็นมาของ Node.js

เรื่องราวของ Node.js

รู้จักกับ Node.js

Node.js ทำให้เรารัน JavaScript นอกเว็บ Browser ได้ Ryan Dahl สร้างมันขึ้นในปี 2009 ก่อนที่ชุมชนนักพัฒนาจะเข้ามาช่วยกันดูแลและพัฒนาต่อเรื่อยมา

จุดกำเนิดของ Node.js

ตอนนั้น Ryan Dahl มองว่าเทคโนโลยีฝั่งเซิร์ฟเวอร์ยังรับมือกับการเชื่อมต่อจำนวนมากได้ไม่ดีนัก เขาจึงสร้าง Node.js เพื่อใช้พัฒนาแอปพลิเคชันเครือข่าย (Network Application) ที่ขยายระบบได้ง่ายและรองรับงานจำนวนมากพร้อมกัน

Node.js เวอร์ชันแรก

Node.js เปิดตัวในปี 2009 โดยใช้ V8 JavaScript Engine ที่ Google สร้างให้ Chrome เป็นหัวใจหลัก รุ่นแรกยังมี Core Module ไม่มาก มีเพียงเครื่องมือสำคัญอย่าง HTTP Server, File System และ Stream

การเติบโตของ Node.js

Node.js ได้รับความนิยมอย่างรวดเร็ว เพราะรองรับการเชื่อมต่อพร้อมกันได้มากและมี Throughput สูง ที่สำคัญ นักพัฒนา Frontend ยังใช้ JavaScript ที่คุ้นเคยมาทำงานฝั่งเซิร์ฟเวอร์ได้ด้วย เมื่อผู้ใช้เพิ่มขึ้น ชุมชนก็เติบโตตาม และมี Module กับ Framework ใหม่ ๆ ออกมาช่วยงานแทบทุกด้าน

Node.js ในปัจจุบัน

ทุกวันนี้ Node.js เป็นแพลตฟอร์มที่เสถียรและใช้งานกันอย่างแพร่หลาย ตั้งแต่โปรเจกต์เล็กไปจนถึงระบบเครือข่ายของบริษัทขนาดใหญ่ ชุมชนก็ยังคงสร้าง Module และ Framework ใหม่ ๆ ออกมาอย่างต่อเนื่อง

ในโปรเจกต์จริง เรามักใช้ Node.js ร่วมกับฐานข้อมูล (Database), Framework ฝั่ง Frontend และบริการคลาวด์ เพื่อประกอบเป็นเว็บแอปพลิเคชันแบบ Full-stack
