การสืบค้นข้อมูลใน MongoDB

ตอนนี้เราได้ใส่เอกสารจำนวนมากลงในฐานข้อมูลของเราแล้ว ก็ถึงเวลาค้นหาฐานข้อมูลของเราเพื่อดึงข้อมูลออกมา มีหลายเหตุผลและวิธีการในการสืบค้นฐานข้อมูล คุณสามารถสืบค้นฐานข้อมูลเพื่อรับบันทึกเฉพาะ เช่น หากคุณกำลังค้นหาวัตถุผู้ใช้เพื่อแสดงหน้าโปรไฟล์ หรือคุณอาจค้นหาหลาย ๆ อย่างพร้อมกัน เช่น หากผู้ใช้กำลังค้นหาสัตว์เลี้ยงและคุณต้องการแสดงผลลัพธ์ห้ารายการ

ค้นหาหนึ่ง

เริ่มต้นด้วยการสืบค้นขั้นพื้นฐาน เรียกใช้สิ่งนี้ในคอนโซล

db.pets.findOne();

คำสั่งนี้จะค้นหาและคืนเอกสารแรกที่ตรงกับเงื่อนไข แต่ในกรณีนี้เราไม่ได้ระบุเงื่อนไขใด ๆ จึงมีความหมายประมาณว่า "ขอเอกสารอะไรก็ได้หนึ่งรายการ" คุณจึงอาจได้เอกสารแรกที่เคยเพิ่มลงในฐานข้อมูลกลับมา ซึ่งในตัวอย่างนี้คือสุนัขพันธุ์ฮาวานีสชื่อลูน่า

เอาล่ะ สมมติว่าเราต้องการค้นหารายการ 1337 ที่เราใส่ไว้ในฐานข้อมูล ลองสิ่งนี้:

db.pets.findOne({ index: 1337 });

นี่จะค้นหารายการหนึ่งให้คุณ (ซึ่งมีเพียงรายการเดียวเท่านั้น) โดยที่ดัชนีมีค่าเท่ากับ 1337 เอาล่ะ อีกอย่าง มาหาอันหนึ่งที่เป็นสุนัขชื่อ Spot

db.pets.findOne({ name: "Spot", type: "dog" });

หา

จนถึงตอนนี้เรากำลังมองหาการค้นหาเพียงบันทึกเดียวเท่านั้น หากคุณต้องการค้นหาเอกสารทั้งหมดที่ตรงกับข้อความค้นหาของคุณ คุณจะต้องใช้ find แทน findOne มาลองดูกัน

db.pets.find({ type: "dog" });

สังเกตว่านี่ให้ผลลัพธ์เพียงยี่สิบเท่านั้น สิ่งที่ MongoDB ทำโดยค่าเริ่มต้นคือส่งผลลัพธ์ให้คุณครั้งละยี่สิบผลลัพธ์เท่านั้นในรูปแบบของสิ่งที่เรียกว่า ตัววนซ้ำ หรือ เคอร์เซอร์ ตัววนซ้ำจะให้คุณครั้งละยี่สิบบันทึก และช่วยให้คุณสามารถวนซ้ำผลลัพธ์ของคุณได้ บ่อยครั้งนี่เป็นรูปแบบที่มีประโยชน์ เพราะในทางทฤษฎีแล้วคุณอาจต้องการวนซ้ำคอลเลกชันทั้งหมดของคุณ และสิ่งนี้จะทำให้คุณสามารถทำมันทีละชิ้นได้

ลองทำซ้ำตอนนี้ เรียกใช้สิ่งนี้:

it
it
it

คุณจะสังเกตว่าแต่ละครั้งได้รับเอกสารชุดใหม่อีกยี่สิบรายการ คำสั่ง it จะบอกให้เคอร์เซอร์จากคำค้นหาล่าสุดดึงผลลัพธ์ชุดถัดไปออกมา

นับ จำกัด และ toArray

เอาล่ะ เรามาลองทำดังนี้:

db.pets.countDocuments({ type: "dog" }); // probably pretty big number
db.pets.find({ type: "dog" }).limit(40);
it; // after this the cursor will end

countDocuments ช่วยให้คุณทราบได้ว่ามีบางสิ่งอยู่กี่รายการ limit บอกให้เคอร์เซอร์รู้ว่าคุณต้องการหยุดเมื่อใด แต่ถ้าคุณต้องการได้รับทุกสิ่งทั้งหมดในคราวเดียวล่ะ? ลอง toArray

db.pets.find({ type: "dog" }).limit(40).toArray();

นี่จะเป็นการดัมพ์ทุกอย่างออกไปในอาเรย์ ซึ่งดีถ้าคุณต้องการทุกอย่างพร้อมกัน มีหลายสิ่งหลายอย่างที่คุณสามารถทำได้เพื่อกำหนดวิธีการส่งคืนข้อมูล แต่คุณสามารถค้นหาได้อย่างง่ายดายเมื่อคุณต้องการ

ตัวดำเนินการแบบสอบถาม

จะเป็นอย่างไรหากเราต้องการค้นหาแมวสูงอายุทั้งหมดในชุดข้อมูลของเรา MongoDB จะให้คุณทำเช่นนั้น! มาลองสิ่งนี้กัน

db.pets.countDocuments({ type: "cat", age: { $gt: 12 } });

โปรดทราบว่าคุณสามารถใช้ ตัวดำเนินการสืบค้น เหล่านี้ได้ทุกที่ที่คุณระบุการสืบค้น เช่น findOne, find ฯลฯ สิ่งที่คุณจะสนใจเป็นหลักคือ

  • \$gt - มากกว่า
  • \$gte - มากกว่าหรือเท่ากับ
  • \$lt - น้อยกว่า
  • \$lte - น้อยกว่าหรือเท่ากับ
  • \$eq - เท่ากับ (ปกติไม่จำเป็น)
  • \$ne - ไม่เท่ากับ
  • \$in - มีค่าอยู่ในอาร์เรย์ (MongoDB สามารถจัดเก็บอาร์เรย์และวัตถุได้เช่นกัน!)
  • \$nin - ไม่มีค่าในอาร์เรย์

หากคุณต้องการเห็น Fidos ทั้งหมดที่ไม่ใช่สุนัข คุณสามารถทำได้:

db.pets.find({
  type: { $ne: "dog" },
  name: "Fido",
});

ตัวดำเนินการเชิงตรรกะ

ก้าวไปอีกขั้น คุณสามารถดำเนินการเชิงตรรกะได้เช่นกัน สมมติว่าคุณต้องการหานกอายุระหว่าง 4 ถึง 8 ปี

db.pets.find({
  type: "bird",
  $and: [{ age: { $gte: 4 } }, { age: { $lte: 8 } }],
});

คุณมี $or, $nor และ \$ไม่พร้อมใช้งานสำหรับคุณ โปรดทราบว่า $not และ $ne นั้นแตกต่างกัน อย่างแรกคือตัวดำเนินการเชิงตรรกะ และอย่างหลังคือ !==

ผู้ประกอบการพิเศษ

สิ่งเหล่านี้จะไม่มีประโยชน์ในตอนนี้ แต่ฉันแค่อยากแจ้งให้คุณทราบว่าคุณสามารถสืบค้นตามประเภท (ดูว่ามีบางอย่างที่เป็นตัวเลข อาร์เรย์ วัตถุ ฯลฯ) ด้วย $type และคุณสามารถสืบค้นได้ว่าเอกสารมีช่องหรือไม่พร้อมกับ $exists

ยังมีอีกมากมายที่คุณสามารถทำได้เช่นกัน MongoDB ยังมี ตัวดำเนินการเชิงพื้นที่ ดังนั้นคุณจึงสามารถสอบถามได้ว่าจุดสองจุดบนโลกอยู่ใกล้กันหรือไม่!

เรียงลำดับ

บ่อยครั้งคุณจะต้องดำเนินการประเภทต่างๆ กับข้อความค้นหาของคุณ สมมติว่าคุณกำลังสร้างหน้าค้นหาสัตว์เลี้ยงเหล่านี้ (เพื่อสื่อถึงสิ่งที่เรากำลังจะทำ!) บางทีผู้ที่ค้นหาในเว็บไซต์ของคุณอาจเป็นคนที่มีจิตใจดีและต้องการรับเลี้ยงสุนัขสูงวัยบางตัว พวกเขาสามารถพูดเรียงตามอายุจากมากไปน้อย

db.pets.find({ type: "dog" }).sort({ age: -1 });

-1 หมายถึง จากมากไปน้อย และอย่างที่คุณคงเดาได้ 1 หมายถึง จากน้อยไปมาก

การคาดการณ์

สุดท้ายนี้ เพื่อสรุปบทเรียนเล็กๆ น้อยๆ ของเราที่สอบถาม (ยังมีอะไรอีกมากมายที่คุณสามารถทำได้) เรามาพูดถึงการคาดการณ์กันดีกว่า วิธีที่ง่ายที่สุดในการใช้การคาดการณ์คือการจำกัดฟิลด์ที่คุณส่งคืน

db.pets.find({ type: "dog" }, { name: 1, breed: 1 });

1 หมายถึง "รวมสิ่งนี้ไว้ด้วยอย่างแน่นอน" ในกรณีนี้ เราจะรวมเฉพาะชื่อและสายพันธุ์เท่านั้น หากคุณทิ้งบางสิ่งไว้ (เช่น อายุ) มันก็จะไม่เข้ากับการเดินทาง โปรดสังเกตว่า _id มาพร้อมด้วย หากคุณไม่ต้องการสิ่งนั้น คุณจะต้องยกเว้นมันอย่างชัดเจน สิ่งนี้คล้ายกับการฉายภาพที่เราพูดคุยกับ Postgres

db.pets.find({ type: "dog" }, { name: 1, breed: 1, _id: 0 });
db.pets.find({ type: "dog" }, { name: true, breed: true, _id: false }); // note that true and false work too

นอกจากนี้ยังใช้งานได้เพื่อยกเว้นฟิลด์ต่างๆ ซึ่งหมายความว่ารวมทุกสิ่งที่ฉันไม่ได้ยกเว้นไว้ด้วย

db.pets.find({ type: "dog" }, { _id: 0 });
