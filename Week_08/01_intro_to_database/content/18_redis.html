เริ่มต้นใช้งาน Redis

เริ่ม Redis ผ่าน Docker ด้วยคำสั่งต่อไปนี้

docker run -dit --rm --name=my-redis -p 6379:6379 redis:8.6-trixie
docker exec -it my-redis redis-cli

คำสั่งที่สองจะพาเข้าสู่ Interactive Shell ของ Redis จากนั้นเริ่มด้วยการเขียนและอ่านค่าพื้นฐาน

SET และ GET

SET name "Brian Holt"
GET name

คำสั่ง Redis ส่วนใหญ่เรียบง่ายในลักษณะนี้ เราส่งชื่อคำสั่ง เช่น GET หรือ SET ตามด้วย Key เช่น name และ Value เช่น String "Brian Holt"

การตั้งชื่อ Key

การใช้ชื่อแบน ๆ อย่าง name ไม่เหมาะกับระบบจริง PostgreSQL มี Table และ MongoDB มี Collection สำหรับแยกกลุ่มข้อมูล แต่ Redis รวมทุกอย่างไว้ด้วยกันและใช้ Key เป็นตัวแบ่ง เราจึงต้องออกแบบระบบชื่อที่ทั้งแยกข้อมูลและค้นคืนได้ง่าย

แนวทางมาตรฐานคือใช้ : แบ่ง Namespace เช่นข้อมูลผู้ใช้ btholt, sarah_edo และ scotups อาจอยู่ที่ user:btholt, user:sarah_edo และ user:scotups ส่วนข้อมูลการชำระเงินใช้ payment:scotups หรือเพิ่มหลายระดับเป็น user:address:btholt Redis มองทั้งหมดเป็น String Key และไม่บังคับรูปแบบให้เรา

บางระบบใช้ / เป็นตัวแบ่ง แต่ควรใช้ : ตามมาตรฐานชุมชน เพราะเครื่องมือบางชนิดอาศัยรูปแบบนี้ Key ของ Redis รองรับ Binary และยาวได้ถึง 512 MB แต่ไม่ควรใช้ Binary ขนาดใหญ่โดยตรง เพราะเปรียบเทียบช้า หากจำเป็นอาจ Hash รูปภาพด้วย MD5 แล้วใช้ผล Hash เป็น Key

INCR, DECR, INCRBY และ DECRBY

การเพิ่มหรือลดตัวเลขอย่างรวดเร็วเป็นงานที่พบบ่อย เช่น การนับ Page View

SET visits 0
INCR visits
INCR visits
INCR visits
DECR visits

ทุกครั้งที่ผู้ใช้เปิดหน้าเว็บ แอปส่ง INCR ไปยัง Redis ได้ทันทีโดยไม่ต้องอ่านค่าปัจจุบันก่อน ส่วน DECR ใช้ลดค่าทีละหนึ่ง

ถ้าต้องเพิ่มหรือลดมากกว่าหนึ่ง ให้ใช้คำสั่งที่ลงท้ายด้วย BY

INCRBY score:seahawks 6
DECRBY score:broncos 3

MSET และ MGET

เราสามารถเขียนหรืออ่านหลาย Key ในคำสั่งเดียว

MSET score:seahawks 43 score:broncos 8
MGET score:seahawks score:broncos

หากต้องทำงานหลายรายการพร้อมกัน Redis ยังมี Pipeline และ Transaction ซึ่งอยู่นอกขอบเขตบทนำนี้

EXISTS

EXISTS ตรวจว่า Key มีอยู่หรือไม่ จึงช่วยป้องกันการทำงานซ้ำ ตัวอย่างเช่นโปรแกรมสำรวจเขาวงกตที่ต้องจำว่าเคยผ่านพิกัดใดแล้ว

SET plane:0:0 visited
EXISTS plane:1:0
SET plane:1:0 visited
EXISTS plane:0:0
EXISTS plane:1:1
SET plane:1:1 visited

โปรแกรมตรวจแต่ละตำแหน่ง หากเคยไปแล้วก็ลองตำแหน่งถัดไป EXISTS จะคืนค่าจริงหรือเท็จตามการมีอยู่ของ Key

DEL

เมื่อต้องลบข้อมูลออกจาก Cache อย่างชัดเจน ให้ใช้ DEL

SET greeting hello
EXISTS greeting
DEL greeting
EXISTS greeting
