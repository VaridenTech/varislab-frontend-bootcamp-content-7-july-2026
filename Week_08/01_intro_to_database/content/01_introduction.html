แนะนำคอร์สฐานข้อมูล

นี่เป็นการแก้ไขครั้งที่สองของบทแนะนำฐานข้อมูลฉบับสมบูรณ์ คุณไม่จำเป็นต้องทำ v1 - นี่เป็นเพียงเวอร์ชันอัปเดตเท่านั้น!

ยินดีต้อนรับ! สวัสดี! นี่คือบทนำที่สมบูรณ์เกี่ยวกับฐานข้อมูล v2 ฉันตื่นเต้นมากที่จะแบ่งปันความรู้บางอย่างที่ฉันได้รับจากการทำงานในสาขานี้กับคุณ การรู้วิธีใช้ฐานข้อมูลอย่างเหมาะสมจะช่วยให้คุณมีความก้าวหน้าในอาชีพการงาน ทั้งจากมุมมองของความสามารถในการประสบความสำเร็จมากขึ้นในแอปของคุณ และจากมุมมองของความสามารถในการสัมภาษณ์งานที่จำเป็นต้องใช้ฐานข้อมูลได้ดี และถ้าฉันพูดตามตรง ฉันคิดว่าการเรียนรู้วิธีและใช้ฐานข้อมูลเหล่านี้สนุกมาก เป็นความรู้สึกที่ยอดเยี่ยมที่ได้โยนข้อมูลบางอย่างลงในฐานข้อมูลใดฐานข้อมูลหนึ่งเหล่านี้ จากนั้นจึงสามารถดึงข้อมูลและข้อมูลเชิงลึกโดยใช้เทคนิคและความสามารถการสืบค้นที่หลากหลาย

หลักสูตรนี้เหมาะสำหรับใคร?

หลักสูตรนี้เหมาะสำหรับทุกคนที่ต้องการทำความเข้าใจฐานข้อมูลประเภทต่างๆ ที่มีให้เลือก วิธีใช้งานบางส่วน และเมื่อใดจึงควรเลือกฐานข้อมูล

เพื่อให้ได้รับประโยชน์สูงสุดจากหลักสูตรนี้ คุณควรจะคุ้นเคยกับพรอมต์บรรทัดคำสั่งและการเขียนโปรแกรมเล็กน้อย หากคุณไม่คุ้นเคยกับพรอมต์บรรทัดคำสั่ง ฉันสอนหลักสูตรนี้ที่นี่ ว่าหากคุณทำสิ่งนั้นจะช่วยให้คุณพร้อมสำหรับหลักสูตรนี้มากกว่า หากคุณไม่คุ้นเคยกับการเขียนโปรแกรม ฉันมีหลักสูตรเกี่ยวกับเรื่องนั้นด้วย

ตัวอย่างการเขียนโปรแกรมทั้งหมดจะอยู่ใน JavaScript พร้อมด้วย Node.js แต่ถ้าคุณเขียนโค้ดเป็นอย่างอื่น เช่น Python หรือ Ruby ตัวอย่างโค้ดเหล่านี้น่าจะดูคุ้นเคยเพียงพอจนคุณสบายดี โค้ดจะไม่เป็นจุดสนใจของกลุ่มตัวอย่าง แต่การโต้ตอบของฐานข้อมูลจะเน้นที่

ฉันเป็นใคร?

ฉันชื่อ Brian Holt เป็นวิศวกรและผู้จัดการผลิตภัณฑ์ ฉันเขียนโค้ดมาตลอดชีวิต ต้องขอบคุณพ่อและพี่ชายของฉัน และฉันเป็นนักพัฒนามืออาชีพมาเป็นเวลาหนึ่งทศวรรษแล้ว จริงๆ แล้ว น่าตลกดีที่พ่อของฉันเคยทำงานหนึ่งในฐานข้อมูลขนาดใหญ่ OG นั่นคือ IBM DB2 มันค่อนข้างยุ่งยากสำหรับฉันที่จะเข้ามาสอนหลักสูตรเกี่ยวกับฐานข้อมูลเมื่อคำนึงถึงเรื่องนั้น แน่นอนว่าเราจะมุ่งเน้นไปที่ฐานข้อมูลโอเพ่นซอร์ส!

ฉันตื่นเต้นที่จะแบ่งปันประสบการณ์ของฉันในการใช้ฐานข้อมูลที่ฉันได้รับจากการทำงานในบริษัทต่างๆ เช่น Reddit, Netflix, LinkedIn, Microsoft, Stripe, Snowflake, Neon และ Databricks ฉันต้องเขียน SQL เป็นจำนวนมากในช่วงต้นอาชีพของฉัน (จาก MySQL เป็นหลัก) และสิ่งนี้ช่วยฉันได้ตลอดอาชีพการงานเท่านั้น ฉันยังเป็นผู้ใช้ MongoDB รุ่นแรกๆ และได้เข้าร่วม MongoDB Days แรกๆ ในซานฟรานซิสโก เชื่อหรือไม่ว่านั่นเป็นการประชุมด้านเทคนิคครั้งแรกของฉัน (ตั้งแต่นั้นมาฉันได้เข้าร่วมกิจกรรมมากกว่า 100 รายการ)

เมื่อฉันไม่ทำงานหรือสร้างเนื้อหา ฉันพยายามหนีจากคีย์บอร์ด ฉันสนุกกับการเล่นสโนว์บอร์ด ออกกำลังกาย เบียร์ท้องถิ่น กาแฟ เดินทางรอบโลก เล่นกับสุนัขฮาวานีส Luna ที่น่ารักของฉัน ออกไปเที่ยวกับภรรยาที่น่าทึ่งและลูกสองคน และทำให้ฉันโดนเตะตูดที่ Overwatch ฉันหลงใหลในผู้คนและช่วยให้พวกเขาเติมเต็มศักยภาพของตนเอง มีประสบการณ์ในท้องถิ่นที่น่าตื่นตาตื่นใจไม่ว่าฉันจะอยู่ที่ไหน และได้ดื่มเครื่องดื่มกับคนที่ฉันรัก

ขอขอบคุณเป็นพิเศษกับ Frontend Masters

ฉันอยากจะขอบคุณ Marc และทีมงาน Frontend Masters ทั้งหมดอย่างชัดเจน นอกจากจะเป็นครอบครัวสำหรับฉันแล้ว คนเหล่านี้ยังเป็นคนที่ยอดเยี่ยมที่สุดที่ฉันเคยพบอีกด้วย คุณกำลังอ่านหรือดูหลักสูตรนี้เนื่องจากการทำงานหนักของพวกเขาเพื่อทำให้โลกแห่งเทคโนโลยีเข้าถึงได้ง่ายขึ้น โดยมีผู้สอนคุณภาพสูงที่สอนในสิ่งที่พวกเขารู้ดีที่สุด ฉันอยากจะขอบคุณพวกเขาสำหรับการสร้างแพลตฟอร์ม รวบรวมชุมชนนักพัฒนาที่แสวงหาความรู้ และให้แรงจูงใจและเป็นเวทีในการพูดคุยกับพวกคุณทุกคน ความมีน้ำใจอย่างหนึ่งก็คือในขณะที่วิดีโออยู่บนแพลตฟอร์ม (และฉันคิดว่าพวกเขาคุ้มค่ากับเงินที่เสียไปในการรับชม) พวกเขาให้ฉันเผยแพร่เว็บไซต์และเนื้อหานี้เป็นโอเพ่นซอร์สเพื่อให้ทุกคนสามารถรับความรู้ได้
