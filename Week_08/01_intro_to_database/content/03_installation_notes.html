การติดตั้งเครื่องมือฐานข้อมูล

คอร์สนี้จะพาเราใช้งาน MongoDB, PostgreSQL และ Redis เครื่องมือทั้งหมดติดตั้งได้บน macOS, Windows และ Linux โดยเนื้อหาจะอธิบายขั้นตอนสำหรับ macOS และ Windows เป็นหลัก ส่วนผู้ใช้ Linux สามารถปรับคำสั่งให้เข้ากับ distro ที่ใช้อยู่ได้

ถ้าระหว่างเรียนเจอผลลัพธ์ไม่ตรงกับตัวอย่าง ให้เช็กเวอร์ชันของเครื่องมือก่อน เพราะ syntax และพฤติกรรมของ Query อาจเปลี่ยนไปในแต่ละเวอร์ชัน คอร์สนี้ใช้เวอร์ชันต่อไปนี้

  • MongoDB เวอร์ชัน 8.2.5
  • PostgreSQL เวอร์ชัน 18.1
  • Redis v8.6.0

ไม่จำเป็นต้องตรงกันทุกเลขเวอร์ชันย่อย แค่ใช้เวอร์ชันใกล้เคียงกันก็เพียงพอแล้ว โดยเลือกวิธีติดตั้งได้ดังนี้

Docker

ตัวอย่างในคอร์สจะใช้ Docker เราจะมีคำสั่งให้รันตามในแต่ละบท ดังนั้นแม้ยังไม่คุ้นเคยกับ Container ก็เริ่มได้ เพียงติดตั้ง Docker Desktop แล้วทำตามคำสั่ง หากอยากปูพื้นฐานเพิ่มเติม ดูได้จาก คอร์ส Container นี้

Package Manager

อีกทางเลือกคือใช้ Package Manager เช่น Homebrew บน macOS หรือ winget และ Chocolatey บน Windows ขณะที่เขียนบทนี้ winget มีเฉพาะ MongoDB และ PostgreSQL ส่วน Homebrew กับ Chocolatey มีเครื่องมือที่เราต้องใช้ครบกว่า

บน Linux ให้ใช้ Package Manager ของ distro ที่ใช้อยู่ได้เลย

ดาวน์โหลด Binary มาติดตั้งเอง

ถ้าไม่อยากใช้ Docker หรือ Package Manager ก็ดาวน์โหลดจากเว็บไซต์ของแต่ละโครงการได้โดยตรง พยายามเลือกเวอร์ชันให้ใกล้กับรายการด้านล่างเพื่อให้ผลลัพธ์ตรงกับบทเรียน

  • MongoDB – เวอร์ชัน 8.2.5
  • PostgreSQL - เวอร์ชัน 18.1
  • Redis - v8.6.0

Cloud

ถ้าเครื่องรันฐานข้อมูลเองไม่ได้ เช่น ใช้ Chromebook หรือ iPad คุณสามารถเลือกบริการ Cloud ที่มี Free Tier แล้วเชื่อมต่อจากระยะไกลแทนได้ วิธีนี้ต้องตั้งค่า Connection String, Firewall และ Network เพิ่มเติม จึงอาจซับซ้อนกว่าการรันในเครื่องเล็กน้อย

เวอร์ชัน Node.js

ตัวอย่างบางส่วนจะรันด้วย Node.js คอร์สนี้ใช้ LTS เวอร์ชัน 24.13.1 แต่เวอร์ชันใหม่ใกล้เคียงกันก็น่าจะใช้ได้ ติดตั้งได้จาก เว็บไซต์ Node.js หรือใช้ Version Manager อย่าง nvm
