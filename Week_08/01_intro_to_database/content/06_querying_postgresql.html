การสืบค้นข้อมูลใน PostgreSQL

คุณจะพบว่า SQL มีความลึกมาก มีหลายคนที่งานส่วนใหญ่ก็แค่เขียน SQL แต่มาดูข้อมูลพื้นฐานที่นี่กันดีกว่า สิ่งแรกที่ฉันต้องการทำคือแทรกข้อมูลจำลองลงในฐานข้อมูลผู้ใช้ของเรา

คลิกที่นี่ สำหรับชุดตัวอย่างตารางสำหรับฐานข้อมูลของคุณ สิ่งที่แบบสอบถามนี้จะทำคือปล่อยตารางที่มีอยู่ทั้งหมดของคุณแล้วตั้งค่าใหม่ คุณสามารถรันใหม่ได้ทุกเมื่อเพื่อรับสำเนาตารางใหม่ของคุณ คุณสามารถคัดลอกสิ่งทั้งหมดนี้อย่างแท้จริงและวางลงในการเชื่อมต่อบรรทัดคำสั่งของคุณกับ PostgreSQL (psql) และมันก็ใช้งานได้ มีวิธีที่สง่างามกว่าในการโหลดจากบรรทัดคำสั่ง แต่เราอยู่ใน Docker และมันน่ารำคาญ ดังนั้นฉันจึงคัดลอก/วางมัน อาจใช้เวลา 90 วินาทีในการรัน

เลือก

เริ่มจาก SELECT กันก่อน นี่คือวิธีค้นหาสิ่งต่าง ๆ ในฐานข้อมูล SQL เรามารันคำสั่ง SELECT จากส่วนก่อนหน้าของเราอีกครั้งแล้วพูดถึงมัน

SELECT * FROM users;

สิ่งนี้จะได้รับทุกฟิลด์ (ซึ่งก็คือความหมายของ * หรือที่รู้จักในชื่อ wildcard) จากฐานข้อมูลผู้ใช้ นี่จะเป็นผู้ใช้ 1,000 คน

จำกัด

มาเลือกผู้ใช้น้อยลงกัน

SELECT * FROM users LIMIT 10;

วิธีนี้จะกำหนดขอบเขตลงไปว่าคุณได้รับบันทึกจำนวนเท่าใดจนถึงเพียง 10 รายการ

การฉายภาพ

ตอนนี้ขอแค่บางคอลัมน์เท่านั้น ไม่ใช่ทั้งหมด (จำการคาดการณ์ได้ไหม)

SELECT username, user_id FROM users LIMIT 15;

โดยทั่วไป เป็นความคิดที่ดีที่จะเลือกเฉพาะคอลัมน์ที่คุณต้องการเท่านั้น ฐานข้อมูลเหล่านี้บางส่วนสามารถมีได้มากกว่า 50 คอลัมน์ โอเค เราได้เห็นการอ่านขั้นพื้นฐานแล้ว

ที่ไหน

เรามาค้นหาบันทึกที่เฉพาะเจาะจงกัน

SELECT username, email, user_id FROM users WHERE user_id=150;
SELECT username, email, user_id FROM users WHERE last_login IS NULL LIMIT 10;

อันแรกจะให้ผู้ใช้หนึ่งรายซึ่งมี user_id เท่ากับ 150 ส่วนอันที่สองจะให้ผู้ใช้ 10 รายที่ไม่เคยเข้าสู่ระบบ

และบวกคณิตศาสตร์วันที่

จะเป็นอย่างไรหากเราต้องการดูว่าพวกเขาไม่ได้เข้าสู่ระบบและถูกสร้างขึ้นมานานกว่าหกเดือนแล้วหรือไม่

SELECT username, email, user_id, created_on FROM users WHERE last_login IS NULL AND created_on < NOW() - interval '6 months'  LIMIT 10;
  • สิ่งนี้จะแสดงคำหลัก AND ซึ่งคุณสามารถค้นหาเงื่อนไขได้หลายข้อ
  • ตัวอย่างนี้มีการคำนวณวันเวลาเล็กน้อย โดยนำค่า created_on ซึ่งเป็น timestamp ไปเปรียบเทียบกับ NOW() (เวลาปัจจุบันของเซิร์ฟเวอร์) ลบด้วยช่วงเวลาหกเดือน ผลลัพธ์คือผู้ใช้ที่ยังไม่เคยเข้าสู่ระบบและสร้างบัญชีไว้นานเกินหกเดือนแล้ว

สั่งซื้อโดย

จะเป็นอย่างไรหากต้องการค้นหาบัญชีที่เก่าแก่ที่สุด? ลองใช้การเรียงลำดับ

SELECT user_id, email, created_on FROM users ORDER BY created_on LIMIT 10;

สำหรับบัญชีใหม่ล่าสุด เพียงเพิ่ม DESC (คุณสามารถใส่ ASC ด้านบนได้ มันเป็นเพียงนัย)

SELECT user_id, email, created_on FROM users ORDER BY created_on DESC LIMIT 10;

นับ(*)

สงสัยว่าเรามีบันทึกจำนวนเท่าใดในฐานข้อมูลของเรา?

SELECT COUNT(*) FROM users;

นี่จะบอกคุณว่าเรามีผู้ใช้ในฐานข้อมูลทั้งหมดกี่คน * แสดงว่าเรากำลังดูแถวผลรวม หากเราต้องการดูจำนวนผู้ใช้ที่เคยเข้าสู่ระบบ (เนื่องจาก COUNT จะละเว้นค่า NULL)

SELECT COUNT(last_login) FROM users;

อัปเดตการกลับมา

สมมติว่า user_id 1 เข้าสู่ระบบแล้ว เราจำเป็นต้องเข้าไปในบันทึกของพวกเขาและอัปเดต Last_login นี่คือวิธีที่เราจะทำอย่างนั้น

UPDATE users SET last_login = NOW() WHERE user_id = 1 RETURNING *;

เครื่องมือที่เรารู้อยู่แล้ว! สมมติว่า user_id 2 เลือกที่จะอัปเดตชื่อเต็มและอีเมล

UPDATE users SET full_name= 'Brian Holt', email = 'lol@example.com' WHERE user_id = 2 RETURNING *;
  • คุณเพียงคั่นด้วยลูกน้ำเพื่อทำหลายชุด
  • ตรวจสอบให้แน่ใจว่าคุณใช้เครื่องหมายคำพูดเดี่ยว เครื่องหมายคำพูดคู่ทำให้เกิดข้อผิดพลาด
  • RETURNING * เป็นส่วนเสริมที่เลือกใช้ได้ โดยมีความหมายว่า "ให้อัปเดตข้อมูล แล้วคืนแถวที่อัปเดตแล้วกลับมาให้ฉัน"

ลบ

สิ่งนี้ได้ผลตามที่คุณคาดหวังโดยพิจารณาจากสิ่งที่เราเคยทำมาก่อน

DELETE FROM users WHERE user_id = 1000;
