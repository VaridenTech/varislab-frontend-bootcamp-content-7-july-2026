Aggregation ใน MongoDB

MongoDB รองรับทั้ง Aggregation Pipeline และ MapReduce แนวคิดของ MapReduce คือใช้ฟังก์ชัน Map แปลงข้อมูลแต่ละรายการ แล้วใช้ Reduce รวมผลให้เป็นชุดข้อมูลที่เล็กลง แต่สำหรับงานทั่วไป Aggregation Pipeline มักทำงานได้ดีและดูแลโค้ดง่ายกว่า

MongoDB มี Aggregation Pipeline สำหรับกรอง แปลง จัดกลุ่ม และสรุปข้อมูลเป็นขั้นตอน วิธีนี้มักอ่านง่ายและดูแลต่อได้สะดวก เพราะแต่ละ Stage มีหน้าที่ชัดเจน

จะเป็นอย่างไรถ้าเราต้องการทราบว่าเรามีลูกสุนัข สุนัขโตเต็มวัย และสุนัขสูงอายุจำนวนเท่าใดในคอลเลคชันสัตว์เลี้ยงของเรา? มาลองกันดูครับ

db.pets.aggregate([
  {
    $bucket: {
      groupBy: "$age",
      boundaries: [0, 3, 9, 15],
      default: "very senior",
      output: {
        count: { $sum: 1 },
      },
    },
  },
]);
  • ด้วยไปป์ไลน์การรวม คุณจัดเตรียมขั้นตอนของสิ่งที่ต้องทำ ในกรณีนี้ เรามีขั้นตอนเดียวเท่านั้น ได้แก่ สัตว์เลี้ยงในถังอายุ 0-2 ปี 3-8 ปี 9-14 ปี (ขอบเขตสุดท้ายไม่รวมอยู่ด้วย ดังนั้นจึงไม่รวม 15 ตัว) และ "อาวุโสมาก" (ซึ่งเป็นที่เก็บข้อมูลเริ่มต้น)
  • ด้วยผลลัพธ์ คุณกำลังกำหนดสิ่งที่คุณต้องการส่งผ่านไปยังขั้นตอนถัดไป ในกรณีนี้ เราเพียงต้องการสรุปผลโดยเพิ่ม 1 ในการนับทุกครั้งที่เราเห็นสัตว์เลี้ยงที่ตรงกับถัง

นี่คือสัตว์เลี้ยงทั้งหมด เราต้องการแค่สุนัข มาเพิ่มอีกขั้นกัน

db.pets.aggregate([
  {
    $match: {
      type: "dog",
    },
  },
  {
    $bucket: {
      groupBy: "$age",
      boundaries: [0, 3, 9, 15],
      default: "very senior",
      output: {
        count: { $sum: 1 },
      },
    },
  },
]);

Stage $match กรองให้เหลือเฉพาะ Pet ที่เป็นสุนัขก่อนส่งต่อไปยัง Stage ถัดไป

สุดท้าย จะเป็นอย่างไรหากเราต้องการเรียงลำดับผลลัพธ์ตามกลุ่มที่มีสัตว์เลี้ยงมากที่สุด?

db.pets.aggregate([
  {
    $match: {
      type: "dog",
    },
  },
  {
    $bucket: {
      groupBy: "$age",
      boundaries: [0, 3, 9, 15],
      default: "very senior",
      output: {
        count: { $sum: 1 },
      },
    },
  },
  {
    $sort: {
      count: -1,
    },
  },
]);

เราต่อ Stage เพิ่มทีละขั้นจนได้ข้อมูลสรุปที่ต้องการ Aggregation ทำได้อีกหลายรูปแบบ ดูรายการ Stage ทั้งหมดได้จาก เอกสาร MongoDB

Aggregation เป็น Feature ที่ทรงพลังมาก ใช้ได้ตั้งแต่ทำรายงานทั่วไปไปจนถึงวิเคราะห์รูปแบบผิดปกติ เช่น ตรวจพฤติกรรม Fraud ในระบบ Marketplace
