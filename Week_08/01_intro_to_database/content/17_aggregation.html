Aggregation ใน MongoDB

MongoDB มีฟีเจอร์สนุกๆ ที่เรียกว่า aggregation มีสองวิธีในการทำไปป์ไลน์การรวมและการลดแผนที่ Map-reduce เป็นสิ่งที่คุณคาดหวังอย่างแน่นอนหากคุณมาจากพื้นฐานการเขียนโปรแกรมเชิงฟังก์ชัน โดยคุณจัดเตรียมฟังก์ชัน map ให้กับ MongoDB ซึ่งจะเรียกใช้ทุกรายการในอาร์เรย์ จากนั้นจึงเพิ่มฟังก์ชันลดเพื่อรวมคอลเลกชันของคุณเป็นชุดข้อมูลที่เล็กลง

MongoDB ยังมีแนวคิดเกี่ยวกับไปป์ไลน์การรวมกลุ่มที่มีแนวโน้มที่จะทำงานได้ดีกว่าและยังสามารถบำรุงรักษาได้ง่ายกว่าอีกด้วย ด้วยสิ่งเหล่านี้ คุณจะจัดเตรียมอ็อบเจ็กต์การกำหนดค่าให้กับไปป์ไลน์ aggregation

จะเป็นอย่างไรถ้าเราต้องการทราบว่าเรามีลูกสุนัข สุนัขโตเต็มวัย และสุนัขสูงอายุจำนวนเท่าใดในคอลเลคชันสัตว์เลี้ยงของเรา? มาลองกันดูครับ

db.pets.aggregate([
  {
    $bucket: {
      groupBy: "$age",
      boundaries: [0, 3, 9, 15],
      default: "very senior",
      output: {
        count: { $sum: 1 },
      },
    },
  },
]);
  • ด้วยไปป์ไลน์การรวม คุณจัดเตรียมขั้นตอนของสิ่งที่ต้องทำ ในกรณีนี้ เรามีขั้นตอนเดียวเท่านั้น ได้แก่ สัตว์เลี้ยงในถังอายุ 0-2 ปี 3-8 ปี 9-14 ปี (ขอบเขตสุดท้ายไม่รวมอยู่ด้วย ดังนั้นจึงไม่รวม 15 ตัว) และ "อาวุโสมาก" (ซึ่งเป็นที่เก็บข้อมูลเริ่มต้น)
  • ด้วยผลลัพธ์ คุณกำลังกำหนดสิ่งที่คุณต้องการส่งผ่านไปยังขั้นตอนถัดไป ในกรณีนี้ เราเพียงต้องการสรุปผลโดยเพิ่ม 1 ในการนับทุกครั้งที่เราเห็นสัตว์เลี้ยงที่ตรงกับถัง

นี่คือสัตว์เลี้ยงทั้งหมด เราต้องการแค่สุนัข มาเพิ่มอีกขั้นกัน

db.pets.aggregate([
  {
    $match: {
      type: "dog",
    },
  },
  {
    $bucket: {
      groupBy: "$age",
      boundaries: [0, 3, 9, 15],
      default: "very senior",
      output: {
        count: { $sum: 1 },
      },
    },
  },
]);

การใช้ขั้นตอนการรวมกลุ่ม $match ทำให้เราสามารถยกเว้นสัตว์เลี้ยงทุกตัวที่ไม่ใช่สุนัขได้

สุดท้าย จะเป็นอย่างไรหากเราต้องการเรียงลำดับผลลัพธ์ตามกลุ่มที่มีสัตว์เลี้ยงมากที่สุด?

db.pets.aggregate([
  {
    $match: {
      type: "dog",
    },
  },
  {
    $bucket: {
      groupBy: "$age",
      boundaries: [0, 3, 9, 15],
      default: "very senior",
      output: {
        count: { $sum: 1 },
      },
    },
  },
  {
    $sort: {
      count: -1,
    },
  },
]);

อย่างที่คุณเห็น คุณเพียงเพิ่มขั้นตอนเพิ่มเติมในการรวมกลุ่มจนกว่าคุณจะรวบรวมข้อมูลเชิงลึกที่คุณกำลังมองหา มีหลายสิ่งที่คุณสามารถทำได้ ดังนั้น นี่คือลิงก์ไปยังขั้นตอนการรวมกลุ่มที่มีอยู่ทั้งหมด

นี่เป็นหนึ่งในส่วนที่สนุกที่สุดเกี่ยวกับ MongoDB อย่างแน่นอน ฉันเคยใช้ฟีเจอร์การรวมกลุ่มของ MongoDB เพื่อจับผู้ฉ้อโกงในแอปคลาสสิฟายด์ของเรา!
