เริ่มต้นใช้งาน MongoDB

MongoDB เป็นหนึ่งใน NoSQL Database ที่ได้รับความนิยมมากที่สุด และถูกใช้งานตั้งแต่โปรเจกต์ขนาดเล็กไปจนถึงระบบที่รับข้อมูลปริมาณมาก

ก่อนที่จะมีใครบอกว่า "MongoDB ทำข้อมูลหาย" เหตุการณ์นั้นเกิดขึ้นนานมากแล้วและได้รับการแก้ไขไปนานแล้วเช่นกัน ปัจจุบันเรื่องนี้ไม่ใช่ข้อกังวลอีกต่อไป MongoDB สามารถใช้งานในระบบจริงได้อย่างปลอดภัย ตัวอย่างเช่น Stripe เติบโตจากศูนย์จนประมวลผลธุรกรรมมูลค่า 100 พันล้านดอลลาร์ด้วย MongoDB

เริ่ม MongoDB

ถ้าใช้ Docker ให้เริ่ม MongoDB ด้วยคำสั่งต่อไปนี้

docker run --name test-mongo -dit -p 27017:27017 --rm mongo:8.2.5

docker exec -it test-mongo mongosh

ซึ่งจะเรียกใช้คอนเทนเนอร์ MongoDB ใหม่ในเวอร์ชัน 8.2.5 และเรียกว่า test-mongo เพื่อให้เราสามารถอ้างอิงตามชื่อได้ จากนั้นในคำสั่งที่สองให้รันคำสั่ง mongosh ภายในคอนเทนเนอร์ test-mongo เพื่อให้เราสามารถทำสิ่งต่างๆ ภายในคอนเทนเนอร์ได้ คอนเทนเนอร์ mongo (ซึ่งเป็นคอนเทนเนอร์อย่างเป็นทางการที่ Docker รวบรวมเข้าด้วยกัน) รัน MongoDB โดยอัตโนมัติ ดังนั้นเราจึงไม่จำเป็นต้องทำอะไรเลย เราเพียงแค่ต้องเชื่อมต่อภายในคอนเทนเนอร์และรันคำสั่งของเราจากภายในคอนเทนเนอร์ ณ จุดนี้ คุณควรถูกปล่อยลงในเชลล์ MongoDB แบบโต้ตอบ มาทำความรู้จักกับ MongoDB กันเถอะ!

Database และ Collection

MongoDB หนึ่ง Server มีหลาย Database และแต่ละ Database มีหลาย Collection ให้คิดว่า Collection คล้าย Table ใน PostgreSQL โดยทั่วไปควรเก็บข้อมูลที่เกี่ยวข้องกันไว้ใน Database เดียวกันแต่แยก Collection ตามชนิด เช่น User กับ Notification อาจอยู่ Database เดียวกัน ส่วนข้อมูลคนละระบบอาจแยก Database เพื่อให้ดูแลและ Scale แยกกันได้ อย่างไรก็ตามไม่มีกฎตายตัว ต้องเลือกตามขอบเขตและปริมาณงานของระบบ

Collection คือกลุ่มของ Document โดยทั่วไปหนึ่ง Document ควรแทนสิ่งหนึ่งอย่าง เช่น Collection users มีหนึ่ง Document ต่อผู้ใช้หนึ่งคน อย่านำข้อมูลคนละประเภทอย่าง User กับ Product ไปปนใน Collection เดียว ควรแยก Collection ตามหน้าที่ให้ชัดเจน

Collection ยังตั้งเป็น Capped Collection ได้ เช่น จำกัดไว้ 100 Document แล้วลบรายการเก่าสุดเมื่อเพิ่มรายการที่ 101 และรองรับ Index ซึ่งเราจะเรียนในบทถัดไป

เพิ่ม Document แรก

ใน MongoDB Shell รัน show dbs เพื่อดู Database ทั้งหมด แล้วใช้ use <database name> เพื่อเลือกหรือสร้าง Database สำหรับตัวอย่างให้รัน use adoption จากนั้นลองรัน db จะเห็นว่า Database ปัจจุบันคือ adoption

สร้าง Collection ชื่อ pets ด้วยคำสั่ง db.pets.insertOne({name: "Luna", type: "dog", breed: "Havanese", age: 14}) แล้วมาดูแต่ละส่วนกัน

db อ้างอิงถึงฐานข้อมูลที่คุณเลือกด้วย use adoption หากคุณต้องการใช้ฐานข้อมูลอื่น คุณเพียงแค่ use เป็นอย่างอื่น

pets คือชื่อ Collection ถ้ายังไม่มี MongoDB จะสร้างให้ตอน Insert ครั้งแรก ถ้ามีอยู่แล้วก็เพิ่ม Document เข้า Collection เดิม

insertOne เพิ่มครั้งละหนึ่ง Document ดู Method อื่นของ Collection ได้ด้วย db.pets.help() และเพราะ MongoDB Shell ใช้ JavaScript เครื่องหมาย () ตรงนี้ก็คือการเรียก Function ตามปกติ

{name: "Luna", type: "dog", breed: "Havanese", age: 14} คือ Object ที่จะเก็บเป็น Document ตัวอย่างนี้ใช้ String กับ Number แต่ MongoDB รองรับ BSON Type อีกหลายแบบ ดูทั้งหมดได้จาก เอกสาร BSON

ลองรัน db.pets.count() จะได้ 1 เพราะตอนนี้มี Pet หนึ่งตัว จากนั้นรัน db.pets.findOne() จะได้ Document ของ Luna กลับมา บทถัดไปจะลงรายละเอียดเรื่อง Query เพิ่มเติม

ต่อไปเราจะเพิ่มข้อมูลให้ครบ 10,000 Document เนื่องจาก MongoDB Shell ใช้ JavaScript เราจึงสร้าง Array ของ Object ด้วยโค้ดแล้ว Insert ทีเดียวได้ วางโค้ดนี้ลงใน Shell

db.pets.insertMany(
  Array.from({ length: 10000 }).map((_, index) => ({
    name: [
      "Luna",
      "Fido",
      "Fluffy",
      "Carina",
      "Spot",
      "Beethoven",
      "Baxter",
      "Dug",
      "Zero",
      "Santa's Little Helper",
      "Snoopy",
    ][index % 11],
    type: ["dog", "cat", "bird", "reptile"][index % 4],
    age: (index % 18) + 1,
    breed: [
      "Havanese",
      "Bichon Frise",
      "Beagle",
      "Cockatoo",
      "African Gray",
      "Tabby",
      "Iguana",
    ][index % 7],
    index: index,
  }))
);

โค้ดนี้สร้าง Pet 10,000 ตัวใน Array และใช้ Modulo ทำให้ทุกคนได้ชุดข้อมูลเหมือนกัน จากนั้นลองรัน db.pets.count() ควรได้ผลลัพธ์ 10,000 เมื่อข้อมูลพร้อมแล้วเราเริ่ม Query กันได้
