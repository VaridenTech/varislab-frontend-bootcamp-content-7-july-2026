บทเรียนฐานข้อมูลทั้งหมด

เรียนรู้ฐานข้อมูลห้ารูปแบบผ่าน PostgreSQL, MongoDB, Neo4j, Redis และ DuckDB ตั้งแต่แนวคิดพื้นฐานจนถึงการเชื่อมต่อกับ Node.js

เริ่มต้น

  1. แนะนำคอร์สฐานข้อมูล
  2. การติดตั้งเครื่องมือฐานข้อมูล
  3. คำศัพท์พื้นฐานเกี่ยวกับฐานข้อมูล

SQL และ PostgreSQL

  1. รู้จักฐานข้อมูล SQL
  2. เริ่มต้นใช้งาน PostgreSQL
  3. การสืบค้นข้อมูลใน PostgreSQL
  4. คำสั่ง SQL ที่ซับซ้อน
  5. การใช้ JSON ใน PostgreSQL
  6. Index ใน PostgreSQL
  7. สร้างแอป Node.js ด้วย PostgreSQL
  8. การค้นหาแบบเวกเตอร์

NoSQL และ MongoDB

  1. รู้จักฐานข้อมูล NoSQL
  2. เริ่มต้นใช้งาน MongoDB
  3. การสืบค้นข้อมูลใน MongoDB
  4. การเพิ่ม แก้ไข และลบข้อมูลใน MongoDB
  5. Index ใน MongoDB
  6. Aggregation ใน MongoDB
  7. สร้างแอป Node.js ด้วย MongoDB

Graph Database และ Neo4j

  1. รู้จักฐานข้อมูลแบบกราฟ
  2. เริ่มต้นใช้งาน Neo4j
  3. การใช้ Neo4j Browser
  4. คำสั่ง Neo4j ที่ซับซ้อน
  5. Index ใน Neo4j
  6. สร้างแอป Node.js ด้วย Neo4j

Key-Value Store และ Redis

  1. รู้จักฐานข้อมูลแบบ Key-Value
  2. เริ่มต้นใช้งาน Redis
  3. ตัวเลือกคำสั่ง Redis
  4. ชนิดข้อมูลใน Redis
  5. แนวคิด Redis เพิ่มเติม
  6. สร้างแอป Node.js ด้วย Redis

Columnar Database และ DuckDB

  1. ฐานข้อมูลแบบ Columnar
  2. เริ่มต้นใช้งาน DuckDB

สรุป

  1. สรุปการเลือกใช้ฐานข้อมูล
