การติดตั้งเครื่องมือฐานข้อมูล

ในหลักสูตรนี้ เราจะใช้ฐานข้อมูลที่แตกต่างกันสี่ฐานข้อมูล ได้แก่ MongoDB, PostgreSQL, Neo4j และ Redis นี่คือแพ็คเกจซอฟต์แวร์ที่คุณจะต้องดาวน์โหลดและเปิดใช้งาน และคุณมีหลายทางเลือกในการทำเช่นนั้น ทั้งหมดนี้ใช้งานได้บน macOS, Windows และ Linux ฉันจะอธิบายอย่างละเอียดถึงวิธีดำเนินการบน macOS และ Windows และฉันคิดว่าเพื่อน Linux ทุกคนสามารถปรับคำแนะนำ macOS ได้ด้วยตนเอง

ในทุกกรณี หากคุณมีปัญหาที่ฉันไม่พบ คุณอาจต้องตรวจสอบให้แน่ใจว่าคุณได้รับเวอร์ชันเดียวกันกับที่ฉันใช้อยู่ หากคุณไม่ทำเช่นนั้น คุณอาจประสบปัญหาเนื่องจากไวยากรณ์และการสืบค้นสามารถเปลี่ยนจากเวอร์ชันหนึ่งไปอีกเวอร์ชันหนึ่งได้ นี่คือเวอร์ชันที่ฉันใช้สำหรับหลักสูตรนี้

  • MongoDB เวอร์ชัน 8.2.5
  • PostgreSQL เวอร์ชัน 18.1
  • Neo4j 2026.01.4-ชุมชนทริกซี่
  • Redis v8.6.0
  • DuckDB เวอร์ชัน 1.5.0

ฉันแน่ใจว่าตัวเลือกการติดตั้งทั้งหมดของฉันจะทำให้คุณมีเวอร์ชันรองที่คล้ายกันกับฉัน

นี่คือตัวเลือกบางส่วนของคุณ:

นักเทียบท่า

นี่จะเป็นวิธีที่ฉันจะทำ (ยกเว้น DuckDB) และฉันจะแสดงคำสั่ง Docker ที่ถูกต้องให้คุณเรียกใช้ในลักษณะนี้ หากคุณไม่คุ้นเคยกับ Docker และคอนเทนเนอร์ ฉันมีหลักสูตรที่นี่ ที่จะช่วยให้คุณดำเนินการเรื่องนี้ได้อย่างรวดเร็ว แม้ว่าคอนเทนเนอร์จะไม่คุ้นเคยกับคุณมากนัก แต่ถ้าคุณติดตั้ง Docker และปฏิบัติตามคำสั่ง ทุกอย่างก็ควรจะใช้งานได้ ไปที่นี่ เพื่อติดตั้ง Docker Desktop ซึ่งจะจัดการทุกสิ่งที่คุณต้องการ

ผู้จัดการแพ็คเกจ

อีกทางเลือกที่ดีคือการติดตั้งฐานข้อมูลจากตัวจัดการแพ็คเกจ หากคุณใช้ macOS นั่นจะเป็น homebrew บน macOS และหากคุณใช้ Windows อาจเป็น winget (ซึ่งยังอยู่ในการแสดงตัวอย่างสำหรับสาธารณะ ดังนั้นอาจทำงานได้ไม่ดีนัก) หรือ Chocolatey ในขณะที่เขียน winget มีเพียง MongoDB และ PostgreSQL เท่านั้น Homebrew และ Chocolatey มีฐานข้อมูลที่จำเป็นทั้งหมด

สำหรับ Linux คุณจะใช้ package manager ของ distro อะไรก็ได้ หากคุณใช้ Linux เป็นเดสก์ท็อป ฉันคิดว่าคุณรู้วิธีทำเช่นนั้น

ดาวน์โหลดและติดตั้งไบนารี่ด้วยตัวเอง

คุณสามารถไปที่เว็บไซต์ทั้งหมดแล้วติดตั้งด้วยตัวเอง! ฉันชอบทำสิ่งนี้ผ่านผู้จัดการแพ็คเกจ แต่ไม่มีเหตุผลที่คุณไม่สามารถทำเช่นนี้ได้หากต้องการ นี่คือ URL ที่ถูกต้องทั้งหมดสำหรับคุณ ตรวจสอบให้แน่ใจว่าคุณดาวน์โหลดเวอร์ชันที่ฉันแสดงไว้ ไม่เช่นนั้นคุณอาจประสบปัญหา (อาจไม่ใช่เวอร์ชันปัจจุบัน)

  • MongoDB – เวอร์ชัน 8.2.5
  • PostgreSQL - เวอร์ชัน 18.1
  • Neo4j - 2026.01.4-ชุมชนทริกซี่
  • แดง - v8.6.0
  • DuckDB - v1.5.0

โซลูชั่นคลาวด์

ฉันจะโยนสิ่งนี้ออกไปหากเป็นไปได้หากคอมพิวเตอร์ของคุณไม่สามารถเรียกใช้ฐานข้อมูลได้ Chromebook และ iPad อาจมีปัญหานี้ ฐานข้อมูลทั้งหมดเหล่านี้ทำงานบนคลาวด์ และคุณอาจได้รับเวอร์ชันทดลองใช้ฟรีของแต่ละฐานข้อมูลที่ทำงานบนคลาวด์ และเพียงเชื่อมต่อกับฐานข้อมูลเหล่านี้จากระยะไกล นี่อาจเป็นเรื่องยากเพราะจะต้องจัดการสตริงการเชื่อมต่อและกฎไฟร์วอลล์และอื่นๆ มากมาย ฉันจะให้คุณค้นหาสิ่งเหล่านี้ด้วยตัวคุณเองเนื่องจากฉันมีความขัดแย้งทางผลประโยชน์เล็กน้อยที่นี่ซึ่งที่คุณเลือก (ณ ปัจจุบันฉันทำงานให้กับ Azure คลาวด์ของ Microsoft)

เวอร์ชัน Node.js

เราจะเรียกใช้ตัวอย่างโค้ดบางส่วนด้วย Node.js สิ่งสำคัญน้อยกว่าที่คุณเลือก Node.js เวอร์ชันตราบใดที่คุณอยู่เหนือเวอร์ชัน 10 ฉันจะใช้ LTS ล่าสุดสำหรับหลักสูตรนี้ v24.13.1 อย่าลังเลที่จะติดตั้งผ่าน เว็บไซต์ หรือผ่านตัวจัดการเวอร์ชันบางประเภท เช่น nvm

นิติศาสตร์มหาบัณฑิต

หากคุณสามารถทำได้ การใช้ LLM เช่น ChatGPT, Claude หรือ Gemini กับหลักสูตรนี้จะดีมาก ฉันจัดทำบันทึกหลักสูตรเหล่านี้ทั้งหมดเป็นเอกสารข้อความขนาดยักษ์ที่คุณสามารถโหลดลงใน LLM ของคุณโดยตรง เพื่อให้คุณสามารถถามเกี่ยวกับหลักสูตรได้
