Index ใน MongoDB

การทำงานนี้คล้ายคลึงกับวิธีการทำงานใน PostgreSQL มาก ดังนั้นเราจะอธิบายเรื่องนี้อย่างรวดเร็ว

explain

MongoDB มี Method explain() สำหรับดู Execution Plan คล้าย EXPLAIN ของ PostgreSQL ลองเริ่มจาก Query ง่าย ๆ

db.pets.find({ name: "Fido" });

Query นี้ต้องตรวจทุก Document ใน Collection ลองใช้ explain() เพื่อดูรายละเอียด

db.pets.find({ name: "Fido" }).explain("executionStats");

ให้ดู Strategy กับจำนวน Document ที่ตรวจ ในกรณีนี้ MongoDB ใช้ COLLSCAN และไล่ดูทุก Document คล้าย Sequential Scan ของ PostgreSQL เราจึงควรเพิ่ม Index

สร้าง Index

db.pets.createIndex({ name: 1 });
db.pets.find({ name: "Fido" }).explain("executionStats");
db.pets.find({ name: "Fido" }).count();
db.pets.getIndexes();

หลังเพิ่ม Index Query จะเร็วขึ้น และจำนวน Document ที่ตรวจใกล้เคียงกับจำนวนผลลัพธ์มากกว่าเดิม ดู Index ที่มีอยู่ทั้งหมดได้ด้วย getIndexes()

Compound Index

ถ้า Query ใช้หลาย Field ร่วมกันบ่อย เช่น type กับ breed เราสร้าง Compound Index ที่รวมทั้งสอง Field ได้ สำหรับ Query รูปแบบนี้มักเร็วกว่า Index แยกสองตัว

db.pets.createIndex({ type: 1, breed: 1 });

Unique Index

เช่นเดียวกับ PostgreSQL เราใช้ Unique Index บังคับให้ค่าไม่ซ้ำกันได้

db.pets.createIndex({ index: 1 }, { unique: true });

ถ้าสร้าง Unique Index แล้วเจอ Error เรื่อง Key ซ้ำ ต้องแก้หรือลบข้อมูลซ้ำก่อน เมื่อสร้างสำเร็จ คำสั่งที่พยายาม Insert ค่าซ้ำต่อไปนี้จะล้มเหลว

db.pets.insertOne({ name: "Doggo", index: 10 });

เนื่องจาก index: 10 มีอยู่แล้ว เพื่อเป็นโบนัส ตอนนี้ฟิลด์นี้ได้รับการจัดทำดัชนีแล้ว ดังนั้นการสืบค้นจึงรวดเร็ว:

db.pets.find({ index: 1337 }).explain("executionStats");

คราวนี้ MongoDB ตรวจเพียงหนึ่ง Document เท่านั้น

Text Index

MongoDB มี Full-Text Search ในตัว คล้าย tsvector/tsquery ของ PostgreSQL เริ่มจากสร้าง Text Index ให้ Field ที่ต้องการค้นหา

db.pets.createIndex({
  type: "text",
  breed: "text",
  name: "text",
});

แต่ละ Collection มี Text Index ได้เพียงหนึ่งตัว ถ้าต้องค้นหาหลาย Field ต้องรวม Field เหล่านั้นไว้ใน Text Index เดียวกัน

ตอนนี้ค้นหาโดยใช้ตัวดำเนินการ $text:

db.pets.find({ $text: { $search: "dog Havanese Luna" } });

Query นี้คืนทุก Document ที่ Match แต่ยังไม่ได้เรียงตาม Relevance ถ้าต้องการผลลัพธ์ที่ตรงที่สุดก่อน ให้เพิ่ม Text Score

db.pets
  .find({ $text: { $search: "dog Havanese Luna" } })
  .sort({ score: { $meta: "textScore" } });

หากต้องการดูคะแนนจริง:

db.pets
  .find(
    { $text: { $search: "dog Havanese Luna" } },
    { score: { $meta: "textScore" } },
  )
  .sort({ score: { $meta: "textScore" } });

ตัวดำเนินการ "" และ - ก็ทำงานที่นี่เช่นกัน วิธีค้นหา Lunas ทั้งหมดที่ไม่ใช่แมว:

db.pets
  .find({ $text: { $search: "-cat Luna" } })
  .sort({ score: { $meta: "textScore" } });

Operator $text ยังมีตัวเลือกอีกมาก ดูต่อได้จาก เอกสาร MongoDB
