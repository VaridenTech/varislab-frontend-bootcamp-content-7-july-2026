Index ใน MongoDB

การทำงานนี้คล้ายคลึงกับวิธีการทำงานใน PostgreSQL มาก ดังนั้นเราจะอธิบายเรื่องนี้อย่างรวดเร็ว

อธิบาย

เช่นเดียวกับ EXPLAIN ของ PostgreSQL MongoDB มีเมธอด explain() ลองดูคำถามง่ายๆ:

db.pets.find({ name: "Fido" });

แบบสอบถามนี้ทำสิ่งที่ขี้ขลาดตาขาว: จะดู ทุกบันทึก ในฐานข้อมูล มาดูกันว่าคำอธิบายบอกเราอย่างไร:

db.pets.find({ name: "Fido" }).explain("executionStats");

สองสิ่งที่ควรสังเกตที่นี่คือกลยุทธ์ที่ใช้และจำนวนบันทึกที่ตรวจสอบ ในกรณีนี้ จะดูบันทึก _ทุกรายการในฐานข้อมูลของเรา และใช้กลยุทธ์ COLLSCAN เช่นเดียวกับการสแกนตามลำดับใน PostgreSQL ไม่ดี! มาสร้างดัชนีกันเถอะ

สร้างดัชนี

db.pets.createIndex({ name: 1 });
db.pets.find({ name: "Fido" }).explain("executionStats");
db.pets.find({ name: "Fido" }).count();
db.pets.getIndexes();

สังเกตว่ามันเร็วขึ้น—ในกรณีของฉันประมาณ 300% จำนวนบันทึกที่ตรวจสอบตอนนี้ตรงกับการนับ คุณสามารถตรวจสอบดัชนีที่มีอยู่ได้ตลอดเวลาโดยใช้ getIndexes()

ดัชนีผสม

หากคุณใช้สองคีย์ร่วมกันบ่อยครั้ง เช่น ประเภทและพันธุ์ คุณอาจพิจารณาใช้ดัชนีผสม ซึ่งจะทำให้ดัชนีของทั้งสองสิ่งมารวมกัน ในกรณีเฉพาะที่คุณกำลังสอบถามกับสิ่งเหล่านั้นร่วมกัน มันจะทำงานได้ดีกว่าดัชนีที่แยกกันสองตัว

db.pets.createIndex({ type: 1, breed: 1 });

ดัชนีที่ไม่ซ้ำ

เช่นเดียวกับใน PostgreSQL คุณสามารถบังคับใช้เอกลักษณ์ด้วยดัชนี:

db.pets.createIndex({ index: 1 }, { unique: true });

หากคุณได้รับข้อผิดพลาดเกี่ยวกับคีย์ที่ซ้ำกัน คุณจะต้องลบคีย์ที่ซ้ำกันออกก่อนแล้วลองอีกครั้ง เมื่อจัดทำดัชนีแล้ว สิ่งนี้จะล้มเหลว:

db.pets.insertOne({ name: "Doggo", index: 10 });

เนื่องจาก index: 10 มีอยู่แล้ว เพื่อเป็นโบนัส ตอนนี้ฟิลด์นี้ได้รับการจัดทำดัชนีแล้ว ดังนั้นการสืบค้นจึงรวดเร็ว:

db.pets.find({ index: 1337 }).explain("executionStats");

สังเกตว่าจะตรวจสอบเพียงระเบียนเดียวเท่านั้น!

ดัชนีข้อความ

MongoDB มีการค้นหาข้อความแบบเต็มในตัว คล้ายกับ tsvector/tsquery ของ PostgreSQL (ซึ่งเราไม่ได้ทำ แต่เราพูดถึงตอนที่เราทำการค้นหาเวกเตอร์) คุณสร้างดัชนีข้อความในช่องที่คุณต้องการค้นหา:

db.pets.createIndex({
  type: "text",
  breed: "text",
  name: "text",
});

แต่ละคอลเลกชันสามารถมีดัชนีข้อความได้เพียงรายการเดียวเท่านั้น ดังนั้นโปรดตรวจสอบให้แน่ใจว่าคุณกำลังจัดทำดัชนีฟิลด์ทั้งหมดที่คุณต้องการ

ตอนนี้ค้นหาโดยใช้ตัวดำเนินการ $text:

db.pets.find({ $text: { $search: "dog Havanese Luna" } });

สิ่งนี้จะจับคู่ "ใดๆ" แต่ไม่ได้จัดเรียงตามความเกี่ยวข้อง เพื่อให้ได้แมตช์ที่แม่นยำที่สุดก่อน:

db.pets
  .find({ $text: { $search: "dog Havanese Luna" } })
  .sort({ score: { $meta: "textScore" } });

หากต้องการดูคะแนนจริง:

db.pets
  .find(
    { $text: { $search: "dog Havanese Luna" } },
    { score: { $meta: "textScore" } },
  )
  .sort({ score: { $meta: "textScore" } });

ตัวดำเนินการ "" และ - ก็ทำงานที่นี่เช่นกัน วิธีค้นหา Lunas ทั้งหมดที่ไม่ใช่แมว:

db.pets
  .find({ $text: { $search: "-cat Luna" } })
  .sort({ score: { $meta: "textScore" } });

ยังมีอะไรอีกมากสำหรับโอเปอเรเตอร์ $text ซึ่งฉันจะปล่อยให้คุณ สำรวจในเอกสาร

การค้นหาเวกเตอร์ยังสามารถทำได้ด้วย MongoDB - ดูเอกสารที่นี่ หากคุณต้องการเรียนรู้เพิ่มเติม
