การเพิ่ม แก้ไข และลบข้อมูลใน MongoDB

แทรก insertOne และ insertMany

คุณพบ insert ที่จุดเริ่มต้นของส่วนนี้แล้ว แต่ฉันแค่อยากจะแยกแยะ insertOne และ insertMany ให้คุณ insert ทำหน้าที่ของทั้ง insertMany และ insertOne เป็นหลัก: ถ้าคุณให้อาร์เรย์กับมัน มันจะแทรกหลาย ๆ อัน และถ้าคุณให้วัตถุกับมัน มันจะแทรกอันหนึ่ง update เลิกใช้แล้วจริงๆ แต่ฉันยังคงเห็นมันในเอกสาร ดังนั้นฉันจึงต้องการรวมมันไว้ด้วย เมธอด insertOne และ insertMany นั้นดี เพราะถ้าคุณเผลอใส่วัตถุผิด (เช่น ให้วัตถุเมื่อคุณตั้งใจจะให้อาร์เรย์) มันจะทำให้เกิดข้อผิดพลาดและทำให้คุณแก้ไขมันได้ ด้วยการแทรก คุณมีโอกาสสูงที่จะทำสิ่งผิด และเมื่อเลิกใช้แล้ว ก็อย่าใช้มัน มันถูกลบออกไปโดยสิ้นเชิงใน SDK

โดยทั่วไปแล้วจะใช้ insertOne และ insertMany สิ่งนี้ยังใช้กับ Delete vs DeleteMany/deleteOne, update vs updateMany/updateOne เป็นต้น

อัพเดท

เมื่อคุณอัปเดต คุณจะต้องระบุตัวกรองและสิ่งที่คุณต้องการอัปเดต ลองทำตัวอย่างกัน

db.pets.updateOne(
  { type: "dog", name: "Luna", breed: "Havanese" },
  { $set: { owner: "Brian Holt" } },
);

วัตถุแรกคือแบบสอบถาม นี่เป็นแบบสอบถามประเภทเดียวกับที่คุณใช้ใน .find() อย่างที่สองคือวัตถุอัปเดตของคุณ ที่นี่คุณมีตัวเลือกสองสามตัวสำหรับตัวดำเนินการอัพเดตต่างๆ เรามาลองอันอื่นกันดีกว่า สมมติว่าวันนี้เป็นวันเกิด สุนัขทุกตัว เราจะเพิ่มอายุของพวกเขาทั้งหมดด้วยการอัพเดตเพียงครั้งเดียวได้อย่างไร

db.pets.updateMany({ type: "dog" }, { $inc: { age: 1 } });

การทำเช่นนี้จะทำให้อายุของสุนัขทุกตัวเพิ่มขึ้น 1 ตัว มีการอัปเดตประเภทอื่นๆ อีกมากมาย แต่คุณสามารถดูเอกสารได้ นี่คือตัวดำเนินการอัปเดตที่มีอยู่

น่าสังเกตว่ามีพารามิเตอร์พิเศษที่คุณสามารถ updateOne และ updateMany พร้อมตัวเลือกเพิ่มเติมได้ เรากำลังจะพูดถึงหนึ่งในนั้นในหัวข้อถัดไป ตื่นเถอะ

โปรดทราบว่ายังมีการแทนที่หนึ่งเช่นกัน การทำงานเหมือนกับ updateOne แต่จะลบฟิลด์ใด ๆ ที่คุณละเว้นในเอกสารการอัพเดตของคุณที่มีอยู่แล้วในเอกสาร

หงุดหงิด

MongoDB มีแนวคิดเรื่อง "upserting" นี่เป็นคำผสมของคำว่า update และ insert และหมายถึง "แทรกเอกสารใหม่ด้วยสิ่งเหล่านี้ หากคุณไม่พบเอกสารที่มีอยู่ด้วย" เช่น บางทีคุณอาจต้องการสร้างผู้ใช้ใหม่ด้วยที่อยู่อีเมลหากคุณยังไม่มี และหากมีอยู่ คุณต้องการอัปเดตด้วยข้อมูลใหม่

มาดูวิธีการทำกัน สมมติว่าคุณต้องการค้นหาสุนัขชื่อ "Sudo" และอัปเดตเจ้าของเป็น "Sarah Drasner" หากมีอยู่ (ในกรณีของเราไม่ใช่) และสร้างบันทึกใหม่หากไม่มี

db.pets.updateOne(
  {
    type: "dog",
    name: "Sudo",
    breed: "Wheaten",
  },
  {
    $set: {
      type: "dog",
      name: "Sudo",
      breed: "Wheaten",
      age: 5,
      index: 10000,
      owner: "Sarah Drasner",
    },
  },
  {
    upsert: true,
  },
);

เราเล่นเรื่องนี้เร็วและขี้เกียจนิดหน่อย เราควรตรวจสอบให้แน่ใจจริงๆ ว่าเรากำลังค้นหาออบเจ็กต์ที่ไม่ซ้ำใครโดยอิงจากคีย์เฉพาะบางประเภท (เราจะพูดถึงเรื่องนั้นในขั้นตอนต่อไป) แต่ใช่ ตรวจสอบให้แน่ใจว่าคุณได้จัดเตรียมเอกสารทั้งหมดด้วยการใส่ upsert ไม่เช่นนั้นคุณจะได้รับเอกสารที่ไม่สมบูรณ์ที่ด้านแทรกของ upsert

ลบ

การลบทำงานเกือบจะเหมือนกันในการค้นหา ยกเว้นแต่แทนที่จะส่งคืนเอกสาร จะเป็นการลบทิ้ง มีทั้ง deleteOne และ deleteMany อยู่ (เช่นเดียวกับ delete ซึ่งเลิกสนับสนุนและเลิกใช้แล้ว) สมมติว่าคุณต้องการลบสัตว์เลื้อยคลาน Havanese ทั้งหมดเนื่องจากไม่สมเหตุสมผล

db.pets.deleteMany({ type: "reptile", breed: "Havanese" });

ค้นหาและ*

ในบางครั้งคุณจำเป็นต้องค้นหาเอกสาร and อัปเดต/ลบ/แทนที่พร้อมกัน แทนที่จะต้องทำสองคำสั่งและทำให้มีสภาวะการแข่งขันของบางสิ่งที่แก้ไขเอกสารของคุณในระหว่างนี้ มีคำสั่งสามคำสั่งที่จะช่วยให้คุณทำเช่นนั้นได้ ได้แก่ findOneAndUpdate, findOneAndReplace และ findOneAndDelete โดยพื้นฐานแล้วงานเหล่านี้เหมือนกับ updateOne, แทนที่ One และ DeleteOne พวกมันเพิ่งส่งคืนในตอนท้าย

โปรดทราบว่ามันจะส่งคืนเอกสารเหมือนเดิม before อัปเดต/แทนที่/ลบ ไม่ใช่หลังจากนั้น

BulkWrite

โดยเฉพาะอย่างยิ่งเมื่อคุณเขียนโค้ด บางครั้งคุณจำเป็นต้องเรียกใช้ชุดคำสั่งทั้งหมดในคราวเดียว นั่นอาจเป็นส่วนแทรกหลายรายการหรืออาจมีการอัปเดตและลบเล็กน้อย แทนที่จะทำการสืบค้น รอ แล้วดำเนินการต่อไปตามลำดับ ฯลฯ คุณสามารถทำสิ่งที่เรียกว่า BulkWrite ได้ BulkWrite ช่วยให้คุณสามารถจัดคิวอาร์เรย์ของการสืบค้น และจะดำเนินการสืบค้นเหล่านั้นตามลำดับที่คุณระบุให้กับ MongoDB เป็นไปได้แต่แปลกๆ ที่จะทำใน mongo CLI เชลล์ ดังนั้นเราจะพูดถึงมันเมื่อเราเขียนโค้ดแล้ว พอจะพูดได้ว่าเป็นเพียงสิ่งที่เรากำลังทำอยู่ แต่แทนที่จะเป็นออบเจ็กต์คิวรีเดียว คุณกลับจัดเตรียมอาร์เรย์ของออบเจ็กต์คิวรีเดียวกันเหล่านั้น
