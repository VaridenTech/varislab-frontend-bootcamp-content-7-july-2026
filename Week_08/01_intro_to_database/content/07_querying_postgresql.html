การสืบค้นข้อมูลใน PostgreSQL

SQL เป็นหัวข้อที่ลงลึกได้มาก แต่บทนี้จะเริ่มจากคำสั่งพื้นฐานที่ใช้บ่อย ก่อนอื่นเราต้องเติมข้อมูลตัวอย่างลงใน Database

ดาวน์โหลด SQL ตัวอย่างชุดนี้ แล้ววางลงใน psql ได้เลย Script จะลบ Table เดิม สร้างใหม่ และเพิ่มข้อมูลตัวอย่าง จึงรันซ้ำได้เมื่อต้องการเริ่มต้นใหม่ ขั้นตอนนี้อาจใช้เวลาประมาณ 90 วินาที

SELECT

เริ่มจาก SELECT ซึ่งใช้ค้นหาและอ่านข้อมูลจาก SQL Database ลองรันคำสั่งจากบทที่แล้วอีกครั้ง

SELECT * FROM users;

* คือ Wildcard ที่หมายถึงทุก Field Query นี้จึงดึงข้อมูลผู้ใช้ครบทั้ง 1,000 คนและทุก Column

LIMIT

ถ้าไม่อยากได้ผลลัพธ์ทั้งหมด ให้จำกัดจำนวน Row ที่คืนกลับมา

SELECT * FROM users LIMIT 10;

LIMIT 10 ทำให้ Query คืนมาไม่เกิน 10 Record

Projection

นอกจากจำกัดจำนวน Row แล้ว เรายังเลือกเฉพาะ Column ที่ต้องใช้ได้

SELECT username, user_id FROM users LIMIT 15;

ควรเลือกเฉพาะ Column ที่ต้องใช้ เพราะ Table จริงอาจมีหลายสิบ Column การส่งข้อมูลที่ไม่ใช้กลับมาจะเปลืองทั้งเวลาและ Network

WHERE

WHERE ใช้กรองเฉพาะ Record ที่ตรงตามเงื่อนไข

SELECT username, email, user_id FROM users WHERE user_id=150;
SELECT username, email, user_id FROM users WHERE last_login IS NULL LIMIT 10;

Query แรกคืนผู้ใช้ที่มี user_id เท่ากับ 150 ส่วน Query ที่สองคืนผู้ใช้ 10 คนที่ยังไม่เคยเข้าสู่ระบบ

AND และการคำนวณวันที่

ถ้าต้องการหาเฉพาะบัญชีที่ไม่เคยเข้าสู่ระบบและสร้างมานานกว่าหกเดือน เรารวมสองเงื่อนไขเข้าด้วยกันได้

SELECT username, email, user_id, created_on FROM users WHERE last_login IS NULL AND created_on < NOW() - interval '6 months'  LIMIT 10;
  • AND ใช้กำหนดว่าผลลัพธ์ต้องผ่านทุกเงื่อนไข
  • ตัวอย่างนี้มีการคำนวณวันเวลาเล็กน้อย โดยนำค่า created_on ซึ่งเป็น timestamp ไปเปรียบเทียบกับ NOW() (เวลาปัจจุบันของเซิร์ฟเวอร์) ลบด้วยช่วงเวลาหกเดือน ผลลัพธ์คือผู้ใช้ที่ยังไม่เคยเข้าสู่ระบบและสร้างบัญชีไว้นานเกินหกเดือนแล้ว

ORDER BY

ถ้าต้องการหาบัญชีที่เก่าที่สุด ให้เรียงผลลัพธ์ตามวันที่สร้าง

SELECT user_id, email, created_on FROM users ORDER BY created_on LIMIT 10;

ถ้าต้องการบัญชีใหม่ล่าสุดให้เพิ่ม DESC ส่วน ASC คือการเรียงจากน้อยไปมากและเป็นค่าเริ่มต้น จึงไม่จำเป็นต้องเขียนก็ได้

SELECT user_id, email, created_on FROM users ORDER BY created_on DESC LIMIT 10;

COUNT(*)

ถ้าต้องการรู้ว่ามีกี่ Record ให้ใช้ COUNT

SELECT COUNT(*) FROM users;

COUNT(*) นับทุก Row ถ้าต้องการนับเฉพาะผู้ใช้ที่เคยเข้าสู่ระบบ ให้ใช้ COUNT(last_login) เพราะ COUNT จะไม่นับค่า NULL

SELECT COUNT(last_login) FROM users;

UPDATE และ RETURNING

สมมติว่าผู้ใช้หมายเลข 1 เพิ่งเข้าสู่ระบบ เราต้องอัปเดต last_login ของ Record นั้น

UPDATE users SET last_login = NOW() WHERE user_id = 1 RETURNING *;

เรายังอัปเดตหลาย Field พร้อมกันได้ เช่น เปลี่ยนชื่อและอีเมลของผู้ใช้หมายเลข 2

UPDATE users SET full_name= 'Varis Dara', email = 'lol@example.com' WHERE user_id = 2 RETURNING *;
  • คั่นแต่ละ Field ด้วยเครื่องหมายจุลภาคเมื่อต้องการกำหนดหลายค่า
  • String ใน SQL ใช้ Single Quote ถ้าใช้ Double Quote จะถูกตีความเป็นชื่อ Identifier และทำให้เกิด Error
  • RETURNING * เป็นส่วนเสริมที่เลือกใช้ได้ โดยมีความหมายว่า "ให้อัปเดตข้อมูล แล้วคืนแถวที่อัปเดตแล้วกลับมาให้ฉัน"

DELETE

DELETE ใช้ลบ Row ที่ตรงกับเงื่อนไข รูปแบบคล้ายกับ Query ที่เราเพิ่งใช้

DELETE FROM users WHERE user_id = 1000;
