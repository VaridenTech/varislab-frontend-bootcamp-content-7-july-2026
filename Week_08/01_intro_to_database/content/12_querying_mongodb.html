การสืบค้นข้อมูลใน MongoDB

เมื่อมีข้อมูลแล้ว ขั้นต่อไปคือ Query ออกมาใช้งาน เราอาจหา Document เดียว เช่น User สำหรับหน้า Profile หรือหาหลาย Document เช่น Pet ห้าตัวที่ตรงกับเงื่อนไขค้นหา

findOne

เริ่มจาก Query พื้นฐาน รันคำสั่งนี้ใน MongoDB Shell

db.pets.findOne();

findOne คืน Document แรกที่ตรงเงื่อนไข เมื่อไม่ใส่ Filter จึงมีความหมายว่า “ขอ Document หนึ่งรายการ” ตัวอย่างนี้มักได้ Luna สุนัขพันธุ์ Havanese ที่เพิ่มไว้ก่อน

สมมติว่าต้องการหา Document ลำดับที่ 1337 จากชุดข้อมูล ลองใช้ Filter นี้

db.pets.findOne({ index: 1337 });

Query นี้หา Document ที่ Field index เท่ากับ 1337 ต่อไปลองหา Pet ที่เป็นสุนัขและชื่อ Spot

db.pets.findOne({ name: "Spot", type: "dog" });

find

findOne คืน Document แรกที่ตรงเงื่อนไข ถ้าต้องการทุก Document ให้ใช้ find แทน

db.pets.find({ type: "dog" });

Shell แสดงผลครั้งละ 20 Document ผ่าน Cursor แทนการโหลดผลลัพธ์ทั้งหมดพร้อมกัน วิธีนี้ช่วยให้ไล่อ่าน Collection ขนาดใหญ่ทีละชุดโดยไม่ใช้ Memory มากเกินไป

ลองดึงผลลัพธ์ชุดถัดไปด้วยคำสั่งนี้

it
it
it

ทุกครั้งที่รัน it Cursor จาก Query ล่าสุดจะดึงผลลัพธ์ชุดถัดไปอีก 20 Document

count, limit และ toArray

ต่อไปลองนับและจำกัดจำนวนผลลัพธ์

db.pets.countDocuments({ type: "dog" }); // probably pretty big number
db.pets.find({ type: "dog" }).limit(40);
it; // after this the cursor will end

countDocuments นับจำนวน Document ที่ตรง Filter ส่วน limit จำกัดจำนวนที่ Cursor จะคืน ถ้าต้องการรับทั้งหมดเป็น Array ในครั้งเดียวให้ใช้ toArray

db.pets.find({ type: "dog" }).limit(40).toArray();

toArray โหลดผลลัพธ์ทั้งหมดมาไว้ใน Array เหมาะเมื่อรู้ว่าชุดข้อมูลมีขนาดไม่ใหญ่เกินไป เพราะต้องใช้ Memory เก็บทั้งหมดพร้อมกัน

Query Operator

ถ้าต้องการหาแมวสูงอายุทั้งหมด เราใช้ Operator เปรียบเทียบภายใน Filter ได้

db.pets.countDocuments({ type: "cat", age: { $gt: 12 } });

เราใช้ Query Operator เหล่านี้ได้กับทุก Method ที่รับ Filter เช่น findOne และ find ตัวที่ใช้บ่อยมีดังนี้

  • \$gt - มากกว่า
  • \$gte - มากกว่าหรือเท่ากับ
  • \$lt - น้อยกว่า
  • \$lte - น้อยกว่าหรือเท่ากับ
  • \$eq - เท่ากับ (ปกติไม่จำเป็น)
  • \$ne - ไม่เท่ากับ
  • \$in - ค่าอยู่ใน Array ที่กำหนด
  • \$nin - ไม่มีค่าในอาร์เรย์

ถ้าต้องการ Pet ชื่อ Fido ที่ไม่ใช่สุนัข ให้เขียน Filter แบบนี้

db.pets.find({
  type: { $ne: "dog" },
  name: "Fido",
});

Logical Operator

เรารวมหลายเงื่อนไขด้วย Logical Operator ได้ ตัวอย่างต่อไปหานกอายุระหว่าง 4 ถึง 8 ปี

db.pets.find({
  type: "bird",
  $and: [{ age: { $gte: 4 } }, { age: { $lte: 8 } }],
});

Operator อื่นมี $or, $nor และ $not โดย $not เป็น Logical Operator ส่วน $ne หมายถึงค่าไม่เท่ากัน คล้าย !==

Operator อื่นที่ควรรู้

นอกจากนี้ $type ใช้กรองตาม Data Type เช่น Number, Array หรือ Object และ $exists ใช้ตรวจว่า Document มี Field ที่ระบุหรือไม่

MongoDB ยังมี Geospatial Operator สำหรับ Query ตำแหน่ง เช่น ตรวจว่าสองจุดอยู่ใกล้กันหรือไม่

sort

สมมติว่ากำลังทำหน้าค้นหา Pet และผู้ใช้ต้องการดูสุนัขสูงวัยก่อน เราต่อ sort หลัง Query เพื่อเรียงอายุจากมากไปน้อยได้

db.pets.find({ type: "dog" }).sort({ age: -1 });

-1 หมายถึงเรียงจากมากไปน้อย ส่วน 1 เรียงจากน้อยไปมาก

Projection

Projection ใช้เลือกเฉพาะ Field ที่ต้องการให้ Query คืนกลับมา

db.pets.find({ type: "dog" }, { name: 1, breed: 1 });

ค่า 1 หมายถึงให้รวม Field นั้นไว้ ในตัวอย่างจึงคืนเฉพาะชื่อและสายพันธุ์ ส่วน Field ที่ไม่ระบุจะไม่อยู่ในผลลัพธ์ ยกเว้น _id ที่ MongoDB รวมมาโดยอัตโนมัติ ถ้าไม่ต้องการต้องตั้งเป็น 0 แนวคิดนี้เหมือน Projection ใน PostgreSQL

db.pets.find({ type: "dog" }, { name: 1, breed: 1, _id: 0 });
db.pets.find({ type: "dog" }, { name: true, breed: true, _id: false }); // note that true and false work too

เรายังใช้ Projection แบบตัด Field ออกได้ โดยกำหนด 0 ให้ Field ที่ไม่ต้องการ แล้ว MongoDB จะคืน Field อื่นทั้งหมด

db.pets.find({ type: "dog" }, { _id: 0 });
