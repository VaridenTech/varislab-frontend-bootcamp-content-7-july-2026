Utilities หลักที่ใช้บ่อย

Core Utilities

Tailwind มี utility class หลายพันตัว แต่ในทางปฏิบัติคุณจะใช้แค่กลุ่มเล็ก ๆ ซ้ำ ๆ ตลอด บทนี้จะพาสร้างการ์ดสินค้าหนึ่งใบทีละขั้น โดยใช้ข้อมูลสินค้าจริงจาก dummyjson (สินค้า id 1: Essence Mascara Lash Princess ราคา $9.99) เพื่อให้เห็นหน้าตาใกล้เคียงกับสิ่งที่ My Store จะแสดงจริงในบทที่ 14

1. Spacing — ระยะห่าง

เริ่มจากกล่องเปล่า ๆ ที่มีแค่ระยะห่างภายใน (padding)

function ProductCard() {
  return <div className="p-4">{/* เนื้อหาการ์ด */}</div>;
}

ตัวเลขใน spacing utility ของ Tailwind ไม่ใช่ px แต่อิงกับสเกล 4 หน่วยต่อ 1rem — ตัวเลข 1 หน่วยเท่ากับ 0.25rem เสมอ ดังนั้น p-1 คือ padding: 0.25rem, p-2 คือ 0.5rem, และ p-4 ที่ใช้ข้างบนคือ padding: 1rem พอดี ตัวย่อ m-* ทำหน้าที่เดียวกันกับ margin, gap-* กำหนดระยะห่างระหว่างลูกใน flex/grid และ space-y-* เติม margin-top ให้ลูกทุกตัวยกเว้นตัวแรก — สะดวกมากเวลาเรียงลูกในแนวตั้งโดยไม่ต้องใส่ gap ที่ parent

2. Typography — ตัวอักษร

เพิ่มชื่อสินค้าและแบรนด์เข้าไป

function ProductCard() {
  return (
    <div className="p-4">
      <p className="text-sm text-gray-600">Essence</p>
      <h3 className="text-base font-medium">Essence Mascara Lash Princess</h3>
      <p className="text-sm text-gray-600 line-clamp-2">
        The Essence Mascara Lash Princess is a popular mascara known for its volumizing and lengthening effects.
      </p>
    </div>
  );
}

text-sm, text-base, text-lg, text-xl ไล่ขนาดตัวอักษรตามสเกล (text-sm = 0.875rem, text-base = 1rem) font-medium และ font-semibold คุม font-weight ส่วน text-gray-600 คุมสี ที่น่าสนใจคือ line-clamp-2 ใน CSS ธรรมดาต้องเขียนหลายบรรทัดผสม vendor prefix กว่าจะตัดข้อความยาว ๆ ให้เหลือ 2 บรรทัดแล้วใส่ … ต่อท้าย แต่ Tailwind ย่อทั้งหมดนั้นไว้ใน class เดียว

3. Colors & Surfaces — สีและพื้นผิว

ใส่พื้นหลังให้ตัวการ์ดและราคาสินค้า

<div className="bg-white p-4">
  {/* ... */}
  <p className="text-lg font-semibold text-blue-600">$9.99</p>
</div>

bg-white และ bg-gray-50 คือพื้นหลังที่ใช้บ่อยที่สุดสำหรับพื้นผิวการ์ดกับพื้นหลังหน้า ส่วน text-blue-600 คือสีน้ำเงินของแบรนด์ที่จะใช้เน้นราคา สังเกต modifier /50 ที่ต่อท้ายสีได้ เช่น bg-black/50 คือสีดำแต่มี opacity: 50% — มีประโยชน์มากตอนทำ overlay ป้ายส่วนลดทับบนรูปสินค้า ซึ่งเราจะใช้ตอนประกอบร่างการ์ดฉบับเต็ม

4. Borders & Shadows — ขอบและเงา

<div className="rounded-lg border border-gray-200 bg-white p-4 shadow-sm">
  {/* ... */}
</div>

rounded-lg คือ border-radius ขนาดกลาง ๆ ที่ใช้ได้กับแทบทุกการ์ด border เปิดเส้นขอบหนา 1px แล้ว border-gray-200 กำหนดสีของเส้นนั้น (สังเกตว่า border เปล่า ๆ ไม่มีสีจะได้เส้นสีดำเริ่มต้น จึงต้องระบุสีตามด้วยเสมอ) shadow-sm เป็นเงาบาง ๆ ที่ทำให้การ์ดลอยขึ้นจากพื้นหลังเล็กน้อยโดยไม่ดูหนักเกินไป

5. Flexbox

จัดแถวราคากับคะแนนรีวิวให้อยู่คนละฝั่งของบรรทัดเดียวกัน

<div className="flex items-center justify-between gap-2">
  <p className="text-lg font-semibold text-blue-600">$9.99</p>
  <span className="text-sm text-gray-600">⭐ 2.56</span>
</div>

สาม class นี้ใช้คู่กันบ่อยจนแทบเป็นสูตรสำเร็จ: flex เปิดโหมด flexbox, items-center จัดแนวตั้งให้อยู่กึ่งกลาง, justify-between ดันลูกตัวแรกไปซ้ายสุดตัวสุดท้ายไปขวาสุด และ gap-2 กันไม่ให้ลูกชิดกันเกินไปเวลาที่พื้นที่แคบ

6. Grid

การ์ดหนึ่งใบใช้ flexbox ก็พอ แต่หน้า listing ที่มีการ์ดหลายสิบใบต้องใช้ grid

<div className="grid grid-cols-4 gap-4">
  <ProductCard />
  <ProductCard />
  <ProductCard />
  <ProductCard />
</div>

grid-cols-4 แบ่งพื้นที่เป็น 4 คอลัมน์เท่า ๆ กันในบรรทัดเดียว ส่วน gap-4 ตัวเดียวกันกับที่เพิ่งใช้ใน flexbox ก็ใช้เว้นระยะระหว่างการ์ดในกริดได้เหมือนกัน — ในบทที่ 5 เราจะเปลี่ยนตัวเลขนี้ตามขนาดจอ

7. Sizing

สุดท้ายคุมขนาดของรูปภาพและความกว้างของทั้งหน้า

<div className="mx-auto w-full max-w-7xl p-4">
  <img
    src="https://cdn.dummyjson.com/product-images/beauty/essence-mascara-lash-princess/thumbnail.webp"
    alt="Essence Mascara Lash Princess"
    className="aspect-square w-full rounded-lg object-cover"
  />
</div>

w-full ให้กว้างเต็มพื้นที่ parent ส่วน max-w-7xl คู่กับ mx-auto คือสูตรมาตรฐานสำหรับ “คอนเทนเนอร์หน้าเว็บ” — จำกัดความกว้างสูงสุดไว้ (7xl = 80rem) แล้วดันให้อยู่กึ่งกลางจอด้วย margin ซ้ายขวาอัตโนมัติ ส่วนที่รูปภาพ aspect-square บังคับสัดส่วนกว้าง:สูง เป็น 1:1 เสมอไม่ว่ารูปต้นฉบับจะเป็นสัดส่วนอะไร แล้ว object-cover ครอบตัดรูปให้เต็มกรอบนั้นโดยไม่บิดเบี้ยว — คู่นี้สำคัญมากสำหรับ grid สินค้าที่ต้องการให้ทุกการ์ดสูงเท่ากันแม้รูปต้นฉบับจะไม่เท่ากัน

ประกอบร่างการ์ดฉบับเต็ม

function ProductCard() {
  return (
    <div className="rounded-lg border border-gray-200 bg-white p-4 shadow-sm">
      <div className="relative">
        <img
          src="https://cdn.dummyjson.com/product-images/beauty/essence-mascara-lash-princess/thumbnail.webp"
          alt="Essence Mascara Lash Princess"
          className="aspect-square w-full rounded-lg object-cover"
        />
        <span className="absolute top-2 left-2 rounded bg-black/50 px-2 py-1 text-xs text-white">
          -10%
        </span>
      </div>

      <p className="mt-3 text-sm text-gray-600">Essence</p>
      <h3 className="text-base font-medium">Essence Mascara Lash Princess</h3>
      <p className="text-sm text-gray-600 line-clamp-2">
        The Essence Mascara Lash Princess is a popular mascara known for its volumizing and lengthening effects.
      </p>

      <div className="mt-2 flex items-center justify-between gap-2">
        <p className="text-lg font-semibold text-blue-600">$9.99</p>
        <span className="text-sm text-gray-600">⭐ 2.56</span>
      </div>
    </div>
  );
}

ลองวางโค้ดนี้แทนเนื้อหาใน App.tsx ของ playground แล้วดูผลลัพธ์จริง จากนั้นลองเปลี่ยนตัวเลขไปมา เช่น p-4 เป็น p-8 หรือ text-blue-600 เป็น text-red-600 เพื่อสร้างความคุ้นเคยกับสเกลตัวเลขและชื่อสี

💡 คุณไม่มีทางจำ utility ทุกตัวได้หมด และไม่จำเป็นต้องจำ — เปิด tailwindcss.com/docs คู่กันไว้เสมอแล้วใช้ช่องค้นหาบนเว็บ พิมพ์ชื่อ CSS property ที่ต้องการ (เช่น “line-clamp” หรือ “object-fit”) ก็จะเจอ utility class ที่ตรงกันทันที
