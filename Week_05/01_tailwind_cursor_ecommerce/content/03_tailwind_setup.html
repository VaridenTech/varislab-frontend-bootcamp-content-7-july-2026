บทเรียน 03 · Tailwind CSS พื้นฐาน (Tailwind Fundamentals)

เริ่มใช้ Tailwind v4 กับ Vite

Tailwind Setup

ตอนนี้เข้าใจแนวคิดแล้ว มาติดตั้ง Tailwind จริง ๆ กัน แต่ยังไม่ใช่ในโปรเจกต์ My Store — โปรเจกต์นั้นจะเริ่มในบทที่ 9 ตอนนี้เราจะสร้าง โปรเจกต์ทดลอง (playground) แยกต่างหากสำหรับฝึก utility ต่าง ๆ ในบทที่ 4–6 ก่อน เพื่อไม่ให้การลองผิดลองถูกไปปนกับโค้ดจริง

สร้างโปรเจกต์ทดลอง

npm create vite@latest tailwind-playground -- --template react-ts
cd tailwind-playground
npm install
npm install tailwindcss @tailwindcss/vite

สองคำสั่งแรกสร้างโปรเจกต์ React + TypeScript เปล่า ๆ ด้วย Vite เหมือนที่คุณคุ้นเคยจาก Week_04 ส่วนคำสั่งสุดท้ายติดตั้งตัว Tailwind เองและปลั๊กอินสำหรับ Vite โดยเฉพาะ

ลงทะเบียนปลั๊กอินใน Vite

เปิด vite.config.ts แล้วเพิ่ม tailwindcss() เข้าไปในลิสต์ปลั๊กอิน

// vite.config.ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
});

เปิดใช้งานด้วย CSS บรรทัดเดียว

เปิด src/index.css ลบทุกอย่างที่มีอยู่เดิมออก แล้วเหลือไว้บรรทัดเดียว

/* src/index.css */
@import "tailwindcss";

แค่นี้จริง ๆ — บรรทัดเดียวนี้ทำให้ utility class ทุกตัวของ Tailwind (flex, p-4, bg-blue-600 และอีกหลายพัน) พร้อมใช้งานทันทีในทุกไฟล์ของโปรเจกต์

💡 Tailwind v4 เก็บ config ไว้เป็น CSS ผ่าน @theme (เดี๋ยวเจอในบทที่ 6) ไม่มี ไฟล์ tailwind.config.js และไม่ต้องรัน npx tailwindcss init อีกต่อไป — ถ้าไปเจอบทความหรือวิดีโอสอนที่บอกให้สร้างไฟล์ config แยก หรือให้เขียน @tailwind base; @tailwind components; @tailwind utilities; สามบรรทัด นั่นคือไวยากรณ์ของ Tailwind v3 ซึ่งเก่าแล้วและใช้กับ v4 ไม่ได้

พิสูจน์ว่ามันทำงาน

แทนที่เนื้อหาใน src/App.tsx ด้วยการ์ดกึ่งกลางหน้าจอเล็ก ๆ ที่ใช้แต่ utility class ล้วน ๆ

function App() {
  return (
    <div className="flex min-h-screen items-center justify-center bg-gray-100">
      <div className="rounded-xl bg-white p-8 shadow-md">
        <h1 className="text-2xl font-bold text-blue-600">Tailwind ทำงานแล้ว!</h1>
        <p className="mt-2 text-gray-600">ถ้าเห็นการ์ดสีขาวลอยอยู่กลางพื้นหลังสีเทา แปลว่าสำเร็จ</p>
      </div>
    </div>
  );
}

export default App;

รัน npm run dev แล้วเปิด URL ที่ terminal แสดง (ปกติคือ http://localhost:5173/) ถ้าเห็นการ์ดสีขาวมีเงา ตัวหนังสือสีน้ำเงิน ลอยอยู่กึ่งกลางพื้นหลังสีเทา แปลว่า Tailwind ทำงานถูกต้องแล้ว

ตั้งค่า editor

ติดตั้ง extension ชื่อ Tailwind CSS IntelliSense เพิ่ม เพราะ Cursor เป็น editor ที่ fork มาจาก VS Code จึงใช้ extension ของ VS Code ได้ทั้งหมด extension ตัวนี้ทำสามอย่างที่ช่วยได้มากตลอดสัปดาห์นี้: autocomplete รายชื่อ class ขณะพิมพ์ ขีดเส้นใต้แดงถ้าพิมพ์ผิด และที่มีประโยชน์ที่สุดคือ — เอาเมาส์ไปวางบน class ใด ๆ เช่น px-4 แล้วมันจะโชว์ CSS จริงที่ class นั้นแปลออกมา (padding-left: 1rem; padding-right: 1rem;) ให้ทันทีโดยไม่ต้องเปิด docs
